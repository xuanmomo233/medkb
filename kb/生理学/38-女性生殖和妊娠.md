## 雌孕激素来源（2022）

- **卵巢卵泡（雌激素）**
  - 内膜细胞：LH 调控胆固醇→孕激素→雄激素；颗粒细胞：FSH 调控雄激素→雌激素，需要芳香化酶 "磕CP刺激香嘴"
  - 雌激素第一次高峰→正反馈使GnRH激增→LH和FSH高峰（2026）
  - 子宫内膜月经期：雌孕激素撤退（2011）；子宫内膜增生期：优势卵泡的FSH阈值最低（2016）
- **卵巢月经黄体（孕激素为主→子宫内膜分泌期）**（1997、2003、2004）← LH高峰→排卵（2002、2009、2024）
- **卵巢妊娠黄体（妊娠早期）** ← hCG（早期胚泡）诊断早期妊娠
- **胎盘（妊娠10周后，2010）**
  - 雌三醇：胎盘+胎儿共同合成（检查E3判断胎儿宫内存活 "一家三口"，2021）
  - 孕激素：维持妊娠期子宫处于静息状态（启动分娩的决定因素是孕激素撤退）

## 雌激素与孕激素对比（1996、1998、2005、2008、2013、2014、2015）

| | 雌激素 | 孕激素 |
|------|------|------|
| 子宫 | 子宫内膜——内膜细胞增生（子宫内膜增厚）<br>子宫平滑肌运动增强（对缩宫素敏感性增高）<br>宫颈黏液增多、稀薄 | 子宫内膜：抑制内膜细胞增生、促进蜕膜化、分泌↑<br>子宫平滑肌运动减弱（对缩宫素敏感性降低）<br>宫颈黏液减少、粘稠 |
| 输卵管 | 输卵管纤毛摆动加强<br>输卵管上皮细胞增生 | 输卵管运动减弱<br>输卵管黏液增加 |
| 阴道 | 阴道上皮细胞增生、角化<br>阴道分泌酸性液体 | 抑制阴道上皮细胞增生、角化程度降低 |
| 乳房 | 导管发育 | 腺泡发育 "孕育泡" |
| 对下丘脑、腺垂体 | 负反馈、正反馈（高浓度） | 负反馈 |
| 月经周期 | 两次高峰：排卵前和排卵后 | 一次高峰：排卵后、更max<br>"低调的人才能走得更远" |
| 升高基础体温 | 无 | 有 |
| "青春期" | 有 | 无 |
| 水钠 | 保（类似醛固酮）"青春期水汪汪" | 排（竞争盐皮质激素受体） |
| 其他 | 血LDL↓、HDL↑<br>扩张血管 | 抑制母体对胎儿的免疫排斥<br>血管和消化道肌张力降低→静脉曲张、便秘 |
