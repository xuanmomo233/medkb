# 心肌电活动和特性

> 考频：心肌电活动和特性（0~2题★★★）｜学科：生理学

- **心肌电活动**（1996、1997、1998、2002、2004、2010、2013、2017、2018、2023、2024、2026）

  | | 心室肌细胞 | 窦房结P细胞 | 浦肯野纤维 |
  |---|---|---|---|
  | 静息/最大复极电位 | -90mV（内向整流IK1） | -65mV（IK1不发达） | >-90mV（IK1更发达） |
  | 0期去极化 | INa（快反应细胞）<br>速度和幅度大→传导快 | ICa-L（慢反应细胞）速度和幅度小→传导慢 | INa（快反应细胞）<br>速度和幅度最大→传导最快 |
  | 1期 | Ito（K⁺外流） | 无 | 较心室肌更明显 |
  | 2期（平台期） | ①ICa-L（钙触发钙释放）<br>②IK1（膜去极化后K⁺外流↓）：利于形成2期<br>③延迟整流IK：利于形成3期<br>④慢失活INa（INa,late）<br>⑤Na-Ca交换（INa-Ca） | 无 | 时程最长 |
  | 3期 | K⁺外流 | K⁺外流 | K⁺外流 |
  | 4期 | 无自动去极化（工作细胞） | 自动去极化最快：IK↓（主要）、If（Na⁺）和ICa-T↑ | 自动去极化最慢：IK↓、If↑（主要） |

- **特性**（1996、2002、2004、2007、2009、2012）
  - 兴奋性——膜电位与阈电位距离：远→兴奋性↓、近→兴奋性↑、过近→兴奋性↓
    在相对不应期和超常期产生新的动作电位：幅度小、速度慢、传导慢、时程和不应期短“逊”
  - 传导性
    - ①0期去极化速度和幅度（主要）↑→传导性↑，影响因素有膜电位、平衡电位（浓度差）、通道（电导）
    - ②邻旁未兴奋细胞的兴奋性↑→传导性↑
    - ③直径↑、闰盘↑、分化程度↑→传导性↑
    - 房室结传导最慢（房室延搁）→避免房室同时收缩
  - 收缩性（工作细胞）
    - ①依赖细胞外Ca²⁺（肌膜/T管膜L型钙通道开放CICR）
    - ②全或无同步收缩（闰盘传导），收缩强度只取决于每个心肌细胞的收缩强度
    - ③不发生完全强直收缩（平台期→有效不应期ERP长→相当于整个收缩期+舒张早期）
    - ④长度-张力曲线无明显降支（连接蛋白使心肌伸展性小）
  - 自律性（自律细胞）
    - ①4期自动去极化速度（主要）↑→自律性↑
    - ②最大复极电位与阈电位距离近→自律性↑
    - 窦房结自律性最高（正常起搏点）：抢先占领、超速驱动压抑（人工起搏突然终止致心搏骤停）
    - 期前兴奋和室性早搏：心室肌有效不应期之后（相对不应期和超常期）、下一次窦房结兴奋传来之前，心室肌受到有效刺激
      代偿间歇：窦房结的兴奋恰好落在期前兴奋的有效不应期（有效不应期长）
- **动作电位时程APD**
  - 缩短动作电位时程“维多利亚的秘密”
    - ①IV类抗心律失常药维拉帕米（抑制ICa-L→缩短平台期）
    - ②迷走神经（ACh）
    - ③IB类抗心律失常药利多卡因
  - 延长动作电位时程——III类抗心律失常药胺碘酮（抑制IK）等
