# 骨骼肌收缩

> 考频：骨骼肌收缩（0~2题★★★）｜学科：生理学

<!-- page_007 -->

- **神经-肌接头传递兴奋（1999、2001、2006、2007、2009、2010、2013、2021）**
  - 突触前膜去极化引起 Ca²⁺内流→释放大量囊泡（出胞）→大量 N2-R（化学门控通道——被 ACh 打开）→Na⁺内流、K⁺外流等→Na⁺内流为主（电-化学驱动力大）→终板膜发生去极化产生终板电位（局部电位）→非终板膜的电压门控钠通道开放→普通肌膜产生动作电位
    - 注：静息状态自发释放 1 个囊泡→小/微终板电位（很多 ACh-很多 N2-R，2012）
  - 筒箭毒碱阻断 N2-R→终板电位去极化减小
  - 新斯的明（胆碱酯酶抑制剂）治疗重症肌无力
  - 新斯的明或有机磷中毒→ACh 大量蓄积→肌束颤动等
  - AP 传导相对不疲劳，但神经-肌接头信息传递会疲劳（递质耗竭）

## 兴奋-收缩耦联及收缩特点（2007、2008、2012、2013、2014、2015、2017、2019、2020、2023、2026）

| | 骨骼肌 | 心室肌 |
|---|---|---|
| 兴奋-收缩耦联关键 | 三联管（T/横管与两侧终池） | 二联管（T/横管与单侧终池） |
| 动作电位 | 0 期-I_Na，无 2 期平台期 | 0 期-I_Na（对 TTX 敏感性低），有 2 期平台期 |
| 兴奋沿横管传至细胞深部<br>激活肌膜/T横管的 L 型钙通道 | 变构→连接肌质网/终池 RYR 受体（拔塞样效应）<br>→顺浓度释放 100%Ca²⁺ | 开放→细胞外 Ca²⁺内流→终池 RYR 受体（钙触发钙释放）<br>→顺浓度释放 80%~90%Ca²⁺ |
| 收缩 | 胞质 Ca²⁺↑（关键钙瞬变）+肌钙蛋白→原肌球蛋白位移<br>→肌动蛋白结合肌球蛋白横桥 "激动个球"<br>→肌丝滑行（暗带不变、明带和 H 带缩短 "暗处不动、观察明处的人"） | 同左 |
| 舒张 | 胞质 Ca²⁺全被纵行肌浆网的钙泵回收 | 胞质 Ca²⁺被肌浆网回收和排出细胞外<br>儿茶酚胺→钙泵对 Ca²⁺亲和力↑→回收 Ca²⁺加快 |
| 收缩特点 | 多运动单位同步等级性收缩<br>几乎完全强直收缩（AP 高频率发放使胞质 Ca²⁺持续↑）<br>长度-张力曲线有明显降支<br>初长度储备小 | 全或无同步收缩（闰盘：双向、快速、低电阻），收缩强度只取决于每个心肌细胞的收缩强度<br>不发生完全强直收缩（平台期→有效不应期长→相当于整个收缩期+舒张早期）<br>长度-张力曲线无明显降支（连接蛋白使心肌伸展性小）<br>初长度储备大 |

- **影响因素**
  - 一定范围前负荷/初长度↑→收缩张力↑（2016、2025）
  - 后负荷↑→收缩张力↑、缩短速度↓（横桥周期变长）、缩短程度/长度↓、缩短起始时间延长（等长收缩时间延长、等张收缩时间缩短，2016、2022、2024）
  - 肌肉收缩能力（收缩性）：胞质 Ca²⁺浓度和肌钙蛋白对 Ca²⁺亲和力（活化的横桥数目）、横桥 ATP 酶活性、肌原纤维肥大等
