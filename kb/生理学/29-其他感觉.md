# 其他感觉

> 考频：其他感觉（0~1题★★★）｜学科：生理学

<!-- page_043 -->


- **平衡觉 - 内耳前庭器官（毛细胞，2026）**
  - 椭圆囊囊斑：水平直线变速运动；球囊囊斑：垂直直线变速运动 → 重力感受器
  - **半规管壶腹嵴：旋转变速运动**
    - ①晕船：受刺激最大的是上/前、后半规管 "皇上皇后请上船"（2008）
    - ②若头开始向左转→内淋巴液向右动→两侧眼球缓慢向右、之后快速向左 "头尾一致、中间不同"
    - | | 运动平面 | 刺激 | 眼震颤（2019） |
      |---|---|---|---|
      | 纵（垂直）轴 | 水平面 | 水平/外半规管 | 水平 |
      | 冠状轴（前后翻滚） | 矢状面 | 后半规管 | 旋转 "拉屎在后面、冲水旋转" |
      | 矢状轴（侧身翻转） | 冠状面 | 上/前半规管 | 垂直 "冠垂直戴上前方" |
- **痛觉（感受器是游离神经末梢）**
  - **快痛**
    - 经Aδ有髓纤维传导（2012）
    - 定位清楚、持续短
  - **慢痛**
    - 经C类无髓纤维传导（1997、2013）
    - 定位不清楚（内脏痛最主要特点）、持续长
- **感觉投射**
  - **中央后回投射规律（2016）**
    - 交叉投射（但头面部为双侧投射）
    - 上下倒置（即下肢代表区在中央后回顶部）
    - 投射区域大小与感觉分辨精细程度相关
  - **丘脑至大脑皮层的单向投射系统（1998、2001、2002、2005、2008、2009、2010）**
    - | | 特异性 | 非特异性 |
      |---|---|---|
      | 投射起始核 | 接替核、联络核 | 髓板内核 "内啡肽" |
      | 投射方式 | 点对点 | 弥散 |
      | 投射范围 | 大脑皮层特定区域 | 大脑皮层广泛区域 |
      | 意义 | 引起各种特定感觉<br>激发大脑皮层发出冲动 | 维持和改变大脑皮层兴奋状态，是特异性投射系统引起特定感觉的基础<br>（依靠脑干网状结构上行唤醒系统：被巴比妥类镇静催眠药阻断） |

- **感受器的一般生理特性**
  - **适宜刺激**（但痛觉感受器无适宜刺激，2018）
  - **适应现象**（但温度敏感神经元、耳蜗微音器电位不适应）
    - **快适应**
      - 皮肤麦斯纳小体和环层小体、嗅觉、味觉（2025）"快维神麦克风还我"
      - 对刺激变化十分敏感、利于机体接受新刺激、以探索新异物体或障碍物
    - **慢适应（多数）**
      - 痛觉感受器不易适应/报警意义（2009）
  - **换能** → 感受器首先把刺激能量转换成感受器电位（局部电位）、最终转换成传入神经的动作电位
  - **编码（信息转移）** → 侧向抑制增强感觉系统的分辨能力、空间两点辨别的基础（2024）

## 教材校注（人卫第10版摘要）

- 感受器可将适宜刺激转换为电信号，并具有适应、编码等一般生理特性；不同感觉系统通过特定传入通路向中枢传递信息。
- 躯体和内脏感觉包括触压、温度、本体及痛觉等。快痛与慢痛在传入纤维和时间特征上不同；感觉投射和中枢处理参与定位、分辨及内脏感觉的形成。
- 椭圆囊、球囊主要感受直线加速度和重力相关刺激，半规管主要感受旋转加速度；嗅觉与味觉由相应化学感受机制启动，并经各自通路传向中枢。
