# 视觉

> 考频：视觉（11题★★★）｜学科：生理学

<!-- page_040 -->


- **入眼光线的折射主要发生在角膜前表面**
- **看近物（1996、1998、2002、2005、2013、2014、2018、2021、2023）**
  - （注）近点：做充分调节所能看清最近物体的距离
    晶状体弹性越好→调节能力越强→近点越近
    老视：晶状体弹性↓→调节能力↓→近点变远→看近物需凸透镜
  - 晶状体调节（最重要）
    - 睫状肌收缩（M-R）→睫状小带/悬韧带松弛→晶状体变凸
    - 使晶状体屈光度变大（折光能力变强）致物像前移至视网膜上
    - 眼科检查用扩瞳药后马托品点眼以评测在排除晶状体调节的影响后眼的折光能力
  - 瞳孔调节反射（近反射）
    - 虹膜环形肌/瞳孔括约肌收缩（M-R）→双侧瞳孔缩小
    - 减少球面像差色像差使成像更清晰
  - 视轴会聚（辐辏反射）
    - 内直肌收缩→物像落在双眼视网膜对称点
    - 形成单视觉以避免复视
- **瞳孔对光反射（2010、2017）**
  - 强光→瞳孔缩小：防止强光损伤视网膜
    弱光→瞳孔变大：防止弱光影响视觉
  - 光照一侧眼→双眼瞳孔同时同程度缩小（互感性对光反射）
  - 中枢在中脑：判断病情程度和麻醉深度
- **折光异常/屈光不正（2007、2012）**

  | | 特点 | 矫正 |
  |---|---|---|
  | 远视 | 眼球前后径过短或折光能力减弱→看近物远物都需调节→调节疲劳、头痛 "想远了就头痛" | 凸透镜 |
  | 近视 | 眼球前后径过长或折光能力过强→近点和远点均变近 | 凹透镜 |
  | 散光 | 角膜或晶状体曲率不等→物像变形或不清楚 | 柱面镜 |
- **青光眼（眼压病理性升高）的治疗药物：β-R 拮抗剂、碳酸酐酶抑制剂、M-R 激动剂**

## 感光细胞：超极化感受器电位（如 cGMP↓→Na⁺内流/暗电流↓）（1997、2003、2004、2008、2009、2011、2015、2016、2026）

| | 视锥细胞 | 视杆细胞 |
|---|---|---|
| 意义 | 明视觉 | 暗视觉 |
| 视色素 | 三种视锥细胞→三种视色素（色觉）<br>受损致色盲色弱 | 一种视色素（视紫红质）<br>肝硬化或VitA↓致夜盲 |
| 分布 | 主要在视网膜中央 | 视网膜周围 |
| 数量 | 少 | 多 |
| 视敏度/视力/分辨力<br>（看清视网膜最小的像） | 单线联系→视敏度高<br>（中央凹只有视锥细胞→设计视力表） | 会聚联系→视敏度低<br>"关了灯全都一个样" |
| 光敏度 | 低 | 高 |
| 对光反应速度 | 快 | 慢 |

## 视觉相关现象

- **明适应和暗适应**

  | | 明适应 | 暗适应 |
  |---|---|---|
  | 概念 | 从暗→明 | 从明→暗 |
  | 本质 | 视锥细胞恢复活动 | 视杆细胞恢复活动 |
  | 适应速度 | 快 | 慢 |
  | 第一阶段看不清<br>第二阶段才看清 | 视杆细胞迅速分解（耀眼感）<br>视锥细胞光敏度低 | 使感知光线的阈值↓：<br>视锥细胞合成视色素<br>视杆细胞合成视色素（主要） |

- **影响视野的大小 "吓李白"**
  - ①感光细胞的分布范围
  - ②面部结构：颞侧>鼻侧、下方>上方
  - ③物体颜色：白色视野最大
- **双眼视觉**
  - ①弥补单眼盲区、扩大视野
  - ②产生立体视觉、3D电影原理
- **电影电视的原理**：视后像（视觉暂留）和视觉融合现象

## 教材校注（人卫第10版摘要）

- 眼的折光系统将光线聚焦于视网膜；看近物时晶状体调节、瞳孔缩小和双眼视轴会聚共同参与，屈光不正可按成像位置和折光状态区分。
- 视杆细胞主要参与暗视觉，视锥细胞主要参与明视觉和色觉。光刺激引发视色素反应并使感光细胞产生超极化型感受器电位；视觉信息随后经视网膜神经网络处理并传向中枢。
- 明适应、暗适应及视野、双眼视觉等现象，分别与感光细胞功能恢复、感光细胞分布及双眼视觉通路有关。
