# 细胞信号转导

> 考频：生理+生化 细胞信号转导（1~3题★★★）｜学科：生理学

<!-- page_008 -->


- **核受体（转录因子）促进基因表达（2003、2005、2006、2012、2013、2018、2022、2026）** → 配体：类固醇激素（醛固酮、糖皮质激素、性激素、钙三醇/活化 VitD）、维甲酸/活化 VitA、甲状腺激素
- **离子通道型受体（2011）** → 配体：谷氨酸、甘氨酸、ACh（N 型）、5-HT、GABA（A/C 型）"骨干已设定"
- **G 蛋白耦联受体**
  - 注：ACh 的 M-R、GABA 的 B-R 是 GPCR（2014）
  - 配体很多
    - 靠 cAMP：CA、ADH、Ang、TSH、ACTH、FSH/LH、胰高血糖素等（2013、2015、2016、2019、2026）
    - 靠 IP₃-Ca²⁺、DG：CA、ADH、Ang、TRH、胃泌素等（2012）
    - 光→视蛋白（GPCR）→G→PDE→cGMP↓→Na⁺通道关闭→暗电流↓→超极化型感受器电位
  - GPCR：七跨膜受体
  - 异三聚体 G 蛋白（1997、2002、2007、2012）→ α-GTP 激活；α-GDP 失活；α-GTP 酶（霍乱抑制 GTP 酶使 G 蛋白持续活化）
  - G 蛋白下游（2004、2005、2006、2008、2010、2014、2022、2024）

| G 蛋白效应器 | 第二信使 | 蛋白激酶 |
|---|---|---|
| AC | cAMP↑ | PKA |
| PLC | IP₃↑-Ca²⁺↑，DG/DAG↑ | PKC、CaMK |
| PDE | cAMP↓、cGMP↓ | |

## 酶联型受体（2007、2008、2010、2014、2015、2020、2021、2023、2025）

| | 配体 | 效应 |
|---|---|---|
| 酪氨酸激酶受体 TKR/RTK | 胰岛素、生长因子如 IGF/EGF "老医生" | 调节细胞增殖等 |
| 酪氨酸激酶结合型受体 TKAR | 瘦素、白介素、EPO、PRL、生长因子、生长激素（可产生 IGF）、干扰素、OT "瘦白……" | 调节细胞增殖等 |

## 细胞信号转导（信号通路示意图）

膜外配体 → 膜受体/通路 → 胞内级联（按图中顺时针/分区）：

- 【促代谢等】CA、促胰高血糖素等；CA、TRH、胃泌素等 → **G 蛋白**（βγ、α-GTP）
  - AC → cAMP → PKA → 效应蛋白
  - PLC → DG → PKC → 效应蛋白
  - PLC → IP₃ → Ca²⁺ → Ca²⁺/CaMK → 效应蛋白
- 【促离子】ACh（N-R）、GABA（A,C-R）、Glu、Gly、5-HT → 生理信号
- 【基因表达】醛固酮、糖皮质激素、性激素、钙三醇、维甲酸、甲状腺激素 → 转录因子 → DNA
- 【增殖等】生长因子、胰岛素 → **TPK**：EGFR、IR-P、IRS-P
  - → PI3K → PIP₃ →（PH）PKB/AKT → 效应蛋白
  - → Grb2（SH₂、SH₃）→ SOS（Pro）→ RAS/小 G 蛋白 → RAF/MAPKKK → MEK/MAPKK → ERK/MAPK → 效应蛋白
- 【增殖等】生长因子、生长激素、EPO、干扰素、白介素等（细胞因子）→ JAK/JAK → STAT → 效应蛋白
- 【炎症应激】TNF 等 → NF-κB → 效应蛋白
- 【增殖等】TGF-β（BMP）→ Ser/ThrK → SMAD → 效应蛋白
- 【拮抗 RAAS 等】钠尿肽 → GC；NO、CO → sGC → cGMP → PKG → 效应蛋白

- **第二信使（1999、2009、2013、2018、2019）**
  - cAMP、cGMP、cGAMP、DG/DAG、Ca²⁺、IP₃、PIP₃ 等
  - GPCR 信号通路 / GC 受体信号通路 / PI3K/AKT 信号通路 → 涉及第二信使
- **蛋白激酶（1997、2017、2018）**
  - 注：磷酸化的蛋白质活性改变，蛋白激酶/蛋白磷酸酶系统构成分子开关
  - 丝/苏氨酸激酶 → PKA、PKB/AKT、PKC、PKG、CaMK、RAF、MAPK、丝/苏氨酸激酶受体等
  - 酪氨酸激酶 → 胰岛素受体、多肽生长因子受体、JAK、SRC、TEC、ZAP、ABL、WEE "老医生爱玩剑直TP"

## 教材校注（人卫第10版摘要）

- 细胞信号转导是生物信息在细胞间或细胞内转换、传递并产生效应的过程；常见途径包括膜受体介导的跨膜转导，以及脂溶性配体通过胞质或核受体调节基因表达。
- GPCR 通过异三聚体 G 蛋白调节效应器，产生 cAMP、IP₃、DG 等第二信使并影响蛋白激酶；受体、G 蛋白、第二信使和效应蛋白属于通路中的不同层级。
- 酶联型受体、离子通道型受体和核受体的结构与信号机制不同。口诀所列配体适合作为记忆线索，判断具体通路时仍应核对受体类型和细胞背景。
