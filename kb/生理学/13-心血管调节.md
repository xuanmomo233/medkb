- **心脏神经**（1999、2004、2006、2007、2012、2013、2024、2025、2026）

  | | 心交感神经 | 心迷走神经 |
  |---|---|---|
  | 递质 | NA/NE | ACh |
  | 效应 | 四正效应（β₁-R） | 四负效应（M-R）：兴奋性↓（超极化）、传导↓、心率↓、心房肌收缩能力↓、心输出量↓<br>①右侧迷走神经：窦房结→心率↓为主<br>②左侧迷走神经：房室交界→房室传导↓为主 |
  | 机制 | 促进ICa-L——2期内流Ca²⁺↑（收缩性↑）<br>0期内流Ca²⁺↑（传导性↑）<br>促进ICa-T和If→4期速度↑（自律性↑） | 抑制ICa-L——2期内流Ca²⁺↓（收缩性↓）<br>0期内流Ca²⁺↓（传导性↓）<br>抑制ICa-T和If→4期速度↓（自律性↓）<br>促进IK-ACh——2期缩短（APD缩短）、2期内流Ca²⁺↓（收缩性↓）<br>4期速度↓（自律性↓）<br>最大复极电位与阈电位距离变远（自律性↓） |

- **血管神经**
  - 除真毛细血管外，多数血管只受交感缩血管纤维单一支配（2007、2019、2020）——密度：皮肤>心和脑；密度：微动脉>后微动脉>毛细血管前括约肌
  - 骨骼肌血管（2014）
    - 交感缩血管纤维（紧张性）——NA→α₁-R
    - 交感舒血管纤维（只参与情绪激动和防御反应）——ACh→M-R
  - 唾液腺、胃肠外分泌腺、脑膜、外生殖器血管
    - 交感缩血管纤维（紧张性）——NA→α₁-R
    - 副交感舒血管纤维（只参与器官血流量）——ACh→M-R
- **神经调节：基本中枢-延髓**（1997）

  | | 压力感受性反射（1999、2002、2008、2009、2014、2021） | 外周化学感受性反射（1998、2014） | 心肺容量感受性反射（2008） |
  |---|---|---|---|
  | 感受器 | 颈动脉窦、主动脉弓（感受血管牵张刺激） | 颈动脉体、主动脉体（感受PO₂↓、PCO₂↑、H⁺↑） | 心房/心室/肺循环大血管内（感受牵张刺激和化学刺激） |
  | 效应 | 维持血压相对稳定（缓冲血压快速波动）<br>破坏反射弧使动脉血压不稳定<br>血压↓→感受器压力↓→传入神经↓→降压反射↓→交感↑、迷走↓→搏出量↑、心率↑、外周阻力↑→血压↑ | 危急情况维持心、脑血供（交感↑、迷走↓） | 血容量↑——交感↓、迷走↑<br>钠尿肽↑（抑制ADH和醛固酮） |
  | 备注 | 双向调节、迅速短暂<br>血压偏离正常越远：调节能力越弱<br>高血压患者调定点上移（重调定） | 主要调节呼吸：加深加快<br>仅严重缺氧、酸中毒、血压过低才调节心血管 | 低压力感受器 |

- **体液调节**
  - **RAS**
    - 肾小球球旁/近球细胞→肾素↑（2009、2017、2020）“用血容量去理顺”
      - 肾动脉灌注压↓（入球小动脉牵张感受器）：血压↓、血容量↓、长期低盐饮食
      - 小管液Na⁺↓（远曲小管致密斑感受器）：血浆Na⁺↓、肾小球滤过Na⁺↓
      - 交感神经↑、儿茶酚胺↑（β₁-R）
      - 缓激肽↑、前列腺素↑、小剂量多巴胺↑“儿茶酚胺还钱吧”
    - Ang→AT₁-R（2010、2011、2016、2019）
      - 全身微动脉收缩（外周阻力↑）、静脉收缩（回心血量↑）（II最强）
      - CRH作用↑
      - 直接促进肾上腺皮质醛固酮↑（III最强）
      - 垂体后叶素ADH/VP和缩宫素/催产素↑（大剂量可缩血管）
      - 促心血管重构
      - 引起口渴和喝水（下丘脑室周器穹窿下器）
      - 交感神经释放递质↑
      - 交感缩血管中枢紧张性↑
      - 中枢对压力感受性反射敏感性↓（改变调定点）
      - 肾素↓
      - “1个重构、1组药物、2个减弱、2个收缩、3个加强、3个释放”
    - ACEI（普利）/ARB（沙坦）拮抗RAAS→慢性心衰、高血压等（2018）
      ACEI→缓激肽降解↓→干咳、血管通透性↑
  - **儿茶酚胺**（1998、2011、2015）
    - Adr：α₁-R=β₁-R=β₂-R
      - 多数血管α₁-R多→血管收缩
      - 骨骼肌和肝血管β₂-R多——小剂量→β₂-R→血管舒张；大剂量→α₁-R更强→血管收缩
    - NA：α₁-R>β₁-R>β₂-R——单用NA：血压↑、心率↓
  - **血管内皮产生的活性物质**
    - 内皮素ET——对各脏器血管几乎有收缩作用、效应持久（血压长期调节）※血压长期调节：肾-体液控制系统等（2009、2025）
      正性肌力、但收缩冠脉、AngII和NA↑
      促心血管重构
      参与心血管凋亡、分化、表型转化
    - EDHF——K⁺外流↑→血管平滑肌超极化→舒血管
    - PGI2——舒血管、抗血小板、抗重构
    - NO（2020）——sGC→cGMP→PKG；舒血管、抗血小板、抗重构
  - **肾上腺髓质素ADM**——舒血管、效应持久；利尿，AngII和醛固酮↓；正性肌力、舒张冠脉、保护心脏

目前最强的缩血管物质：尾升压素

目前最强的舒血管物质：降钙素基因相关肽（针刺皮肤出现红晕：脊髓后根舒血管纤维/轴突反射）
