# 神经元及胶质细胞

> 考频：神经元及胶质细胞（0~1题★★★）｜学科：生理学

<!-- page_045 -->

- **中枢神经元的联系方式**
  - 单线联系：如视锥细胞（分辨力高）
  - 辐散式联系：多见于传入通路 "牵牵小手全身都酥了"
  - 聚合式联系：多见于传出通路 "将全身力量汇于掌心发射"
  - **环式/回返式联系（2011）**
    - 负反馈（回返抑制）：及时终止活动（同一中枢的神经元同步化）
    - 正反馈（后发放/后放电） → 屈肌反射：躲避伤害；突触可塑
- **神经元**
  - **树突棘** → 脑功能可塑性的基础；智障儿童树突棘数量少、形态细长 "接触面小"
  - **电压门控钠通道密度高（阈电位更接近静息电位）**
    - 轴突始段：首先产生动作电位（2014、2019）
    - 有髓神经纤维经郎飞结跳跃式传导：速度快、耗能少
  - **神经纤维传导兴奋** → 双向性（神经元的极性使其在体内为单向）；完整性：如麻醉影响兴奋传导；绝缘性：细胞外液对电流的短路作用；相对不疲劳性：动作电位（VS化学性突触传递因递质耗竭致疲劳）
  - **周围神经纤维的分类（2001）"前后BC、快慢AC"**

    | | 传入纤维 | 传出纤维 |
    |---|---|---|
    | Aα | 本体感觉<br>肌梭Ⅰa和腱器官Ⅰb传入纤维 | 躯体运动（支配梭外肌收缩） |
    | Aβ | 触压觉、本体感觉（Ⅱ "2B"） | |
    | Aγ | | 支配梭内肌收缩 |
    | Aδ | 触压觉、快痛觉、温度觉（Ⅲ） | |
    | B | | 自主神经节前纤维 |
    | C（无髓鞘） | 触压觉、慢痛觉、温度觉（Ⅳ） | 自主神经节后纤维 |

  - **轴浆运输（2011）**
    - 顺向运输
      - 速度最快（驱动蛋白）：膜状细胞器如囊泡、线粒体、分泌颗粒 "lang lin lin 快驱魔"
      - 速度最慢：可溶性成分如微管微丝蛋白、营养因子 "漫威有营养"
      - 脊髓灰质炎、肌萎缩侧索硬化：失去神经的营养作用致肌肉萎缩（2010）
    - 逆向运输
      - 动力蛋白：神经营养因子、病毒、破伤风毒素、辣根过氧化酶 "你神经病疯啦"
- **神经胶质细胞** → 胶质瘢痕中的星形胶质细胞因转运 K⁺ 能力减弱→细胞外液高 K⁺→癫痫
