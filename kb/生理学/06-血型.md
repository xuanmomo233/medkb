# 血型

> 考频：血型（0~1题★★★）｜学科：生理学

<!-- page_010 -->


- **ABO 血型**
  - 天然抗体（最主要）：IgM（冷抗体）分子量大、不能透过胎盘（2013）<br>免疫抗体：IgG（温抗体）分子量小、能透过胎盘 "温哥华天天吃冷面"
  - ①抗原特异性与红细胞膜糖链有关<br>②遵循遗传定律（1998、2010、2022）<br>③容易将 A₂型、A₂B 型血误认 B 型或 O 型 "2B哦"

| | 红细胞凝集原/抗原 | 血清凝集素/抗体 |
|---|---|---|
| A₁型 | H、A、A₁ | 抗 B |
| A₂型 | H、A | 抗 B、抗 A₁ |
| B 型 | H、B | 抗 A |
| A₁B 型 | H、A、A₁、B | |
| A₂B 型 | H、A、B | 抗 A₁ |
| O 型 | H | 抗 A、抗 B |

- **Rh 血型**
  - 多数人红细胞膜 Rh 抗原+（有 D 抗原）（2023）"oh 是 DR"
  - 抗原特异性与红细胞膜蛋白质氨基酸序列有关
  - 无天然抗体；主要抗体 IgG（2012）
  - Rh- 母亲怀 Rh+ 第二胎或 Rh- 接受 Rh+ 第二次输血→溶血（2011）
- **输血原则（1999）**
  - 同型输血；自体输血
  - 成分输血如浓缩红；当失血量＞30%→1/2 浓缩红+1/2 全血
  - 必须进行交叉配血
    - 主侧（供血者红细胞+受血者血清）凝集→不能输血
    - 次侧（受血者红细胞+供血者血清）凝集→慢、少、低

## 教材校注（人卫第10版摘要）

- ABO 血型主要依据红细胞 A、B 抗原判定；常见血清抗体与自身红细胞抗原相对应者不共存。A₂ 亚型可有抗 A₁，不能把抗 A₁泛化到普通 B 型或 O 型。
- Rh 血型临床重点是 D 抗原；血清中没有天然抗 Rh 抗体，致敏后产生的抗体主要为 IgG，可通过胎盘。Rh 阴性受者或孕妇需考虑既往致敏。
- 输血应以同型和交叉配血为原则。教材不支持“万能供血者/受血者”的说法；导图所列失血后固定全血与浓缩红细胞配比不属于本处教材结论。
