# 递质和受体

> 考频：递质和受体（0~2题★★★）｜学科：生理学

<!-- page_047 -->


- **ACh**
  - 多数副交感神经节后纤维 → 少数释放 VIP、NO、GRP 等（肽能纤维） →
    - ①食物经过食管时 LES 舒张：VIP+NO
    - ②胃容受性舒张：VIP+NO
    - ③促进 G 细胞释放胃泌素：胃泌素释放肽/GRP/铃蟾素/蛙皮素
  - **M-R（2005、2007、2009、2024）**
    - "抑制" → 心脏：四负效应→血压↓，腺苷↓→冠脉收缩；少数血管：舒张（但骨骼肌血管-交感神经）
    - "兴奋"（2021） →
      - 虹膜环形肌/瞳孔括约肌收缩：缩瞳
      - 睫状肌收缩：睫状小带/悬韧带松弛→晶状体变凸→屈光度↑→视近物
      - 支气管平滑肌收缩：气道口径↓→气道阻力↑
      - 消化和泌尿活动↑：平滑肌收缩、括约肌舒张（但 LES 收缩）
      - 腺体：分泌↑（但温热性发汗-交感神经）
  - **N-R（通道）** → "兴奋"
    - N₁-R：自主神经节
    - N₁-R：肾上腺髓质→儿茶酚胺↑（交感节前纤维）
    - N₂-R：终板电位（但骨骼肌收缩-运动神经，2026）
- **NA/NE**
  - **α-R**
    - **α₁-R（2010、2011、2026）** → "兴奋" →
      - 皮肤和内脏血管收缩、冠脉和骨骼肌等血管收缩 "受体效应是什么就是什么"
      - 虹膜辐射肌/瞳孔开大肌收缩：扩瞳
      - 消化和泌尿活动↓：括约肌收缩，但少量粘稠唾液↑
      - 精神性发汗、立毛肌收缩、有孕子宫收缩
    - **α₂-R** → 小肠平滑肌舒张等
  - **β-R（2009）**
    - **β₁-R（2010）** → "兴奋" → 心脏：四正效应→血压↑，腺苷↑→冠脉舒张；球旁细胞：肾素↑→RAAS 兴奋→血压↑
    - **β₂-R** → "抑制" →
      - 皮肤和内脏血管舒张、冠脉和骨骼肌血管舒张
      - 睫状肌舒张：睫状小带/悬韧带绷紧→晶状体变扁→屈光度↓
      - 支气管平滑肌舒张：气道口径↑→气道阻力↓
      - 消化和泌尿活动↓：平滑肌舒张
      - 无孕子宫舒张
    - **β₃-R** → 脂肪分解↑→血脂肪酸↑
  - 多数交感神经节后纤维 → 少数释放 ACh（交感胆碱能纤维） →
    - ①骨骼肌血管的交感舒血管纤维
    - ②温热性发汗

## 易错点与阻断剂举例

- **易错点**
  - **骨骼肌血管（2014、2023）** → 交感神经
    - 交感缩血管纤维（紧张性）→ NA→α₁-R
    - 交感舒血管纤维（只参与情绪激动和防御反应）→ ACh→M-R
  - **汗腺（2007）** → 交感神经
    - ACh→M-R→汗腺分泌↑ → 温热性发汗（下丘脑；体温调节）
    - NA→α₁-R→汗腺分泌↑ → 精神性发汗（大脑皮层；精神紧张）
  - **瞳孔**
    - 括约肌（虹膜环形肌）→ ACh→M-R→缩瞳 → 副交感神经
    - 开大肌（虹膜辐射肌）→ NA→α₁-R→扩瞳 → 交感神经
  - **支气管**
    - ACh→M-R→支气管收缩→气道阻力↑ → 副交感神经
    - NA→β₂-R→支气管舒张→气道阻力↓ → 交感神经
  - **消化**
    - 唾液腺：ACh→M-R→大量清稀唾液↑ → 副交感神经；NA→α₁-R→少量粘稠唾液↑ → 交感神经
    - 食管下括约肌 LES（非真正的括约肌）：食物经过食管时→VIP+NO→LES舒张；食物入胃后→ACh→LES收缩 → 副交感神经
    - 平滑肌和括约肌：ACh→M-R→平滑肌收缩、括约肌舒张 → 副交感神经；NA→平滑肌舒张（β₂-R）、括约肌收缩（α₁-R） → 交感神经
- **阻断剂举例**
  - M-R 阻断剂 → 阿托品、后马托品
  - N₁-R 阻断剂 → 六烃季铵、美加明
  - N₂-R 阻断剂（2006）→ 十烃季铵、筒箭毒碱、银环蛇毒、戈拉碘铵
  - α₁-R 阻断剂 → 酚妥拉明、酚苄明、哌唑嗪
  - α₂-R 阻断剂 → 酚妥拉明、酚苄明、育亨宾
  - β₁-R 阻断剂 → 普萘洛尔、美托洛尔、阿替洛尔
  - β₂-R 阻断剂 → 普萘洛尔、丁氧胺

## 易错点（续）

- **交感神经兴奋——应急 "为什么追我"（1998、2000、2003、2004、2013、2014）**
  - 只有交感：多数血管、肾、肾上腺髓质、汗腺、立毛肌
  - 心脏四正效应（β₁-R）
  - 冠脉舒张（心肌 β₁-R→腺苷↑）
  - 防御反应时骨骼肌血管舒张（M-R）
  - 皮肤和内脏血管收缩 "血流重新分配"（α₁-R）
  - 支气管舒张 "大口呼吸"（β₂-R）
  - 消化活动↓ → 平滑肌舒张（β₂-R）、括约肌收缩（α₁-R）；但少量粘稠唾液↑（α₁-R）
  - 泌尿活动↓ → 平滑肌如逼尿肌舒张（β₂-R）、括约肌收缩（α₁-R）；RAAS 兴奋（β₁-R）
  - 汗腺分泌↑ → 温热性发汗（M-R）、精神性发汗（α₁-R）
  - 扩瞳 → 虹膜辐射肌/瞳孔开大肌收缩（α₁-R）"眼睛瞪得像铜铃"
  - 易看远物 → 睫状肌舒张（β₂-R）"看清远处的路"
  - 子宫 → 有孕子宫收缩（α₁-R）"排了宝宝再跑"、无孕子宫舒张（β₂-R）
  - 血糖↑ → 胰岛素↓、糖原分解↑、脂肪分解↑（β₃-R）、蛋白质分解↑、糖异生↑
- **副交感神经（1997、2006、2009、2012、2015、2019）** → 与交感神经对比记忆，并注意小细节；休养生息、储备能量
- （交感与副交感共同点：均使唾液↑；可有紧张性；活动度大小与效应器功能状态相关）
- **胆碱能纤维（释放 ACh）（2002、2016、2023）**
  - ①运动神经
  - ②所有自主神经节前纤维（B 类纤维）
  - ③多数副交感神经节后纤维
  - ④少数交感神经节后纤维（温热性发汗、骨骼肌血管的交感舒血管纤维）
