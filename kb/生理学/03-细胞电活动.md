# 细胞电活动

> 考频：细胞电活动（0~2题★★★）｜学科：生理学

<!-- page_005 -->


- **静息电位（2018、2023）**
  - K⁺浓度差/E_K（主要）
  - 膜对 K⁺和 Na⁺的相对通透性
  - 钠泵活动水平
  - 注：钾漏通道（非门控）对 K⁺通透性最大；静息电位略小于 E_K（2011、2021、2026）
- **动作电位**
  - 仅见于可兴奋细胞：神经元、肌细胞、部分腺细胞（2002）
  - 在静息电位基础上细胞受到有效刺激→电压门控钠通道首先被激活而开放（G_Na↑）→Na⁺在较大驱动力下内流→膜去极化并达阈电位→去极化与 G_Na 形成正反馈→动作电位升支直抵接近 E_Na（2001、2008、2010）G_Na↓（主要）、G_K↑→K⁺在较大驱动力下外流→动作电位降支/复极化
  - **阈电位（产生 AP 的关键）**
    - 细胞外 Ca²⁺ → 若细胞外 Ca²⁺↓钙的膜屏障作用↓→阈电位与膜电位距离近→兴奋性↑
    - 电压门控钠通道的密度 → 首先产生动作电位在轴突始段或第一个郎飞结（2014、2019）；有髓神经纤维经郎飞结跳跃式传导（速度快、耗能少，1997）；糖尿病、多发性硬化症患者脱髓鞘使传导速度减慢、中断
    - 电压门控钠通道的状态（1997、1999、2007、2018）

| | 激活门 | 失活门 | 通道 |
|---|---|---|---|
| 备用/静息态 | 关 | 开 | × |
| 激活态 | 开 | 逐渐关 | √ |
| 失活态（对比：电压门控钾通道无失活态） | 开 | 完全关 | × |

阈强度衡量兴奋性的高低

| | 兴奋性（2006、2007、2016） |
|---|---|
| 绝对不应期（兴奋性 0） | 对应锋电位（AP 标志）去极相和复极相早期 |
| 相对不应期 | ①复极化晚期：失活的电压门控 Na⁺通道正逐渐复活（此时备用通道少）<br>②后超极化/回射期：电压门控 K⁺通道仍未完全关闭、钠泵活动增强→膜电位与阈电位距离远 |

钾失衡对横纹肌的影响

| | 骨骼肌 | 心肌 |
|---|---|---|
| 低钾血症 | 兴奋性↓ | 兴奋性先↑后↓ |
| 高钾血症 | 兴奋性先↑后↓<br>当兴奋性↓时：Na⁺电导↓（去极化阻滞）、K⁺电导↑ | 兴奋性先↑后↓ |

- **局部电位** —— 终板电位、EPSP、IPSP、慢波、感受器电位、发生器电位（1996）

## 兴奋 VS 局部兴奋（1996、1997、1999、2002、2003、2005、2013、2022、2025）

| | 动作电位（兴奋） | 局部兴奋 |
|---|---|---|
| 全或无 | 有 | 无 |
| 刺激 | 有效刺激（阈、阈上刺激）→去极化达阈电位（Na⁺通道大量开放） | 阈下刺激→去极化没有达阈电位（Na⁺通道少量开放） |
| 幅度 | 大，有超射和反极化，一旦产生幅度即达最大 | 小，无超射和反极化，等级性 |
| 不应期 | 有，不能总和<br>（相邻两个锋电位≥绝对不应期，后一次兴奋最早出现在前一次兴奋后的相对不应期，2002、2024） | 无，可以总和<br>总和达阈电位可产生动作电位 |
| 传播距离 | 远，不衰减，局部电流（让细胞膜依次再产生动作电位） | 近，会衰减，电紧张扩布 |

- **离子跨膜流动（2012）**
  - 通透性（电导）
    - 静息状态 K⁺通透性最大（2002）、Ca²⁺通透性最小<br>兴奋状态 Na⁺或 Ca²⁺通透性最大（2002）
    - 去极化↑→G_Na↑、G_K↑<br>G_Na 迅速↑、迅速↓（一过性）<br>G_K 延迟↑（多在 G_Na↓时）
  - 电-化学驱动力
    - ＝膜电位-平衡电位 "磨平"（2016）<br>当＝0→净流动为 0→平衡电位（1999）
    - K⁺化学驱动力（浓度差）由内向外，是直接动力<br>静息状态电场驱动力由外向内（2001）
    - 静息状态 Ca²⁺>Na⁺>K⁺>Cl⁻（2010）→ 多数细胞静息电位等于 ECl
    - 动作电位全过程（2020）
      - Na⁺电-化学驱动力：大→小→大（恢复）
      - K⁺电-化学驱动力：小→大→小（恢复）
      - Na⁺、K⁺平衡电位基本不变

阻断 Na⁺通道（如 TTX）：主要降动作电位幅度
阻断 K⁺通道（如胺碘酮、四乙铵）：主要延动作电位时程（2015）

| | 静息电位 | 动作电位幅度 | 钠泵 | Na⁺内流驱动力 |
|---|---|---|---|---|
| 若细胞外 K⁺↑（2001、2019） | ↓ | ↓ | ↑ | ↓ |
| 若细胞外 Na⁺↑（1996、1997、2014、2019） | 不变或↓ | ↑ | ↓ | ↑ |
| 若钠泵↓（如哇巴因，2009） | ↓ | ↓ | | ↓ |

## 教材校注（人卫第10版摘要）

- 静息电位主要由静息状态下膜对 K⁺的通透性及其跨膜浓度梯度决定；Na⁺、K⁺泵维持离子分布，并对静息电位有贡献。
- 动作电位由膜电导的时序变化产生：上升支主要与 Na⁺或 Ca²⁺内流有关，复极主要与相应通道失活及 K⁺外流有关；具体离子机制随细胞类型而异。
- 动作电位具有全或无和不应期等特征；阈下刺激可产生等级性局部电位，其传播会衰减并可发生时间、空间总和。局部电位不应与动作电位混为一谈。
