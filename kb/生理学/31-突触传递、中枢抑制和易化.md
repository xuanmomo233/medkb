# 突触传递、中枢抑制和易化

> 考频：突触传递、中枢抑制和易化（0~2题★★☆）｜学科：生理学

<!-- page_046 -->


- **电突触** → 双向、低电阻、快速（2015）
- **化学突触**
  - 单向、时间延搁、兴奋节律改变、总和、易疲劳（递质耗竭）、对内环境变化敏感、后发放与反馈（1997、2003、2006、2009）
  - **递质释放的关键：Ca²⁺（2000、2001、2007、2016、2017）** → 动作电位频率/幅度/时程↑、细胞外 Ca²⁺↑或 Mg²⁺↓ →进入轴突 Ca²⁺↑→递质释放↑
  - **影响因素**
    - "蜘蛛着位伤了肉" → 肉毒素影响着位→抑制神经肌接头释放 ACh→柔软性麻痹（2018）；破伤风毒素影响着位→抑制闰绍细胞释放甘氨酸→痉挛性麻痹（2004）；蜘蛛毒影响着位→促进递质不断释放→递质耗竭
    - 有机磷农药、新斯的明抑制胆碱酯酶；抗抑郁药阿米替林抑制突触前膜再摄取递质；利血平抑制囊泡再摄取递质→治疗舞蹈病；禁用帕金森
    - 戈拉碘铵、十烃季铵、银环蛇毒、筒箭毒碱阻断突触后膜 N2-R "拉失射箭"（2023）；重症肌无力（自身抗体破坏 N2-R）→用新斯的明（胆碱酯酶抑制剂）治疗（2021）
  - **突触后电位（局部电位）**
    - **EPSP（2004、2017）** → 兴奋性递质（谷氨酸等）；突触后膜去极化：Na⁺内流↑（主要）、K⁺外流↑ → 突触后神经元兴奋
    - **IPSP（2006）** → 抑制性递质（GABA、甘氨酸等）；突触后膜超极化：Cl⁻内流↑、K⁺外流↑ → 突触后神经元抑制
- **中枢抑制**
  - **突触后抑制（超极化抑制）（2001、2025）**
    - 抑制性中间神经元释放抑制性递质 GABA 等 → 突触后膜超极化（IPSP）
    - 传入侧支/交互抑制：保证伸肌和屈肌等活动协调；回返抑制（环式联系负反馈）：及时终止活动（同一中枢的神经元同步化）。破伤风阻碍闰绍细胞释放甘氨酸致惊厥
  - **突触前抑制/去极化抑制（轴突-轴突，1998、2022）**
    - 进入轴突 Ca²⁺↓→兴奋性递质释放↓→EPSP↓
    - 感觉传入通路多见
