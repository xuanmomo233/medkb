# 能量代谢和体温

> 考频：能量代谢和体温（12题★★★）｜学科：生理学

<!-- page_033 -->


- **热价（2021）**
  - 1g 食物氧化时释放的能量
  - 脂肪热价最高
  - 蛋白质物理热价＞生物热价
- **氧热价（1996、1997、2017）**
  - 食物氧化时消耗 1L 氧产生的热量（氧热价不随耗氧量改变）
  - 糖氧热价最高
- **呼吸商（2007、2014）**
  - 一定时间呼出 CO₂ 与吸入 O₂ 量的比值
  - 糖呼吸商最高
  - 非蛋白混合食物 0.82
    - 长期饥饿 0.8（蛋白质 "王八蛋"）
    - 糖尿病 0.7（脂肪 "七夕织女"）
    - 营养摄入过多（糖 RQ=1、但糖会转化为脂肪致 RQ＞1）
    - 肌肉剧烈活动→酸中毒→肺通气过度 RQ＞1
- **影响能量代谢的因素（2003、2004、2008、2016、2025）**
  - ①肌肉活动（最主要）
  - ②精神紧张（无意识肌紧张等）
  - ③食物特殊动力效应（进食刺激机体额外消耗能量）：蛋白质最高 "健身吃蛋白"，交感神经-褐色脂肪组织
  - ④环境温度＜20℃或＞30℃均导致能量代谢↑
  - （注）骨骼肌收缩对外界做功的这部分最终不转化为热能（2005、2019）
- **基础代谢率（2006、2010、2011、2014、2018、2024）**
  - 清醒、安静、禁食、静卧无肌紧张、无剧烈运动、20~25℃环境温度 "清安禁静25℃"
  - 20.2×耗氧量÷体表面积
  - 升高——甲亢（最明显）、红细胞增多、白血病、伴呼吸困难的心脏病、糖尿病、体温升高 "红夹心升糖"
  - 降低——甲减（最明显）、肾上腺皮质功能减退 Addison 病、垂体功能低下性肥胖、肾病综合征、病理性饥饿
  - BMR 男＞女；年龄越小 BMR 越高 "中年发福"

- **产热（2009、2010、2012、2015、2020、2021、2022、2024）**
  - 主要组织：安静-肝脏 "an-gan"，运动-骨骼肌，寒冷-骨骼肌（但新生儿为褐色脂肪组织）
  - 寒冷
    - 成年人主要是战栗产热——骨骼肌屈肌和伸肌同时不随意收缩（肌肉收缩不做外功）；战栗产热前出现肌紧张
    - 新生儿褐色脂肪组织非战栗/代谢性产热——甲状腺激素使解耦联蛋白成为质子通道（不用于合成 ATP）
  - 调节
    - 体液调节：甲状腺激素（起效慢持续长）、生长激素、儿茶酚胺 "甲生儿"
    - 寒冷→下丘脑战栗中枢→脊髓前角运动神经元（神经调节）
      寒冷→下丘脑 TRH→腺垂体 TSH→甲状腺激素（神经-体液调节）
      寒冷→交感-肾上腺髓质→儿茶酚胺（神经-体液调节）
- **散热（1998、2002、2007、2009、2011、2013、2017、2023）**
  - 高温时皮肤动-静脉吻合支开放→皮肤血流量↑→皮肤温度↑→散热↑
  - 皮肤温度＞环境——
    - ①辐射（最主要 "你就是太阳"）
    - ②传导（冰袋冰帽）
    - ③对流（风扇）
    - ④蒸发（酒精擦浴）
  - 皮肤温度≤环境——蒸发
    - 发汗由汗腺细胞主动分泌，刚开始等渗、最后低渗（醛固酮）
      小汗腺全身几乎都有分布：手掌和足趾最多、躯干分泌能力最强 "汗流浃背"
    - | 温热性发汗 "温泉蛋" | 精神性发汗 |
      |---|---|
      | 交感胆碱能纤维（ACh） | 交感肾上腺素能纤维（NA） |
      | 全身小汗腺参与 | 掌心、足底、前额处小汗腺参与 |
      | 下丘脑 PO/AH 区 | 大脑皮层运动区 |
      | 参与体温调节 | 参与精神紧张、情绪激动 |
    - 不感蒸发——
      - ①通过皮肤和呼吸道黏膜的不感蒸发量 600~700ml/d
      - ②婴幼儿不感蒸发的速率比成人大
  - （注）中暑：调定点不变（非调节性体温升高），它是由于体温调节中枢障碍或散热能力不足
- **体温调定点（正常37℃）（2000、2005、2016、2018）**
  - 视前区-下丘脑前部（PO/AH区）——体温调节中枢；温度敏感神经元（热敏神经元较多）
  - 温度敏感神经元（无适应现象）放电频率决定调定点
    - 当热敏神经元反应曲线斜率↓（调节高温能力即降温能力↓）、或冷敏神经元反应曲线斜率↑（调节低温能力即升温能力↑）→调定点上移（重调定）
    - 微生物感染可致调定点上移：发热初期可寒战、随后发热，发热恢复期出汗
- **体温的生理情况（2008、2015）**
  - 清晨低、午后高，波动不超过 1℃（下丘脑视交叉上核）
  - 排卵日最低（排卵后孕激素致体温调定点升高）
    体温女＞男；年龄越小体温越高（但新生儿不恒定）
