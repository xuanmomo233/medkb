# 肠内吸收

> 考频：肠内吸收（21题★★★★）｜学科：生理学

<!-- page_032 -->

- **抓规律记特殊（2001、2014、2015）**
  - 吸收部位主要在：小肠上部（十二指肠、空肠上段）
    但在回肠：VitB₁₂（需内因子）、胆盐／胆汁酸盐
  - 吸收方式主要在：血液
    但在淋巴液：VitA、D、E、K 和脂类消化产物（除开中短链脂肪酸）
- **单糖**
  - Na⁺-继发性主动转运（但果糖为载体易化扩散）
  - 吸收速度：己糖（半乳糖和葡萄糖＞果糖＞甘露糖 "半个葡萄果然甜"）＞戊糖如核糖（2007）
- **氨基酸或寡肽**
  - 氨基酸：Na⁺-继发性主动转运（吸收速度：中性＞碱性＞酸性 "中间酸"）
  - 寡肽：H⁺-继发性主动转运（更快，2010）"寡人爱卿更快"
- **脂类消化产物和脂溶性维生素（2017、2020）**
  - 肠腔：
    - 甘油三酯 —乳化作用（胆盐等）、胰脂肪酶（辅脂酶）、防清除→ 甘油一酯、脂肪酸
    - 胆固醇、磷脂、VitA/D/E/K —胆盐→ 混合微胶粒
  - 静水层 → 小肠上皮细胞：
    - 乳糜微粒（CM）→ 毛细淋巴管 → 胸导管 → 血液循环
    - 胆固醇酯、磷脂、VitA/D/E/K ← apoB48
    - 甘油一酯 → 甘油三酯 ← 长链脂肪酸
    - 中短链脂肪酸 → 毛细血管
    - 胆盐（回肠被吸收）
- **铁（2007、2013）**
  - 代谢：吸收（2价 "xi"）→ 运输（3价 "yun"）→ 利用（2价 "li"）→ 储存（3价 "chu"）
  - 体内缺铁、VitC、HCl 促吸收；谷类、乳类、茶抑制吸收
- **钙（2006、2011、2013）**
  - 对钙需求量大、VitD（最重要）、HCl、葡萄糖、氨基酸、脂肪酸、乳酸促吸收
  - 草酸、磷酸、植酸抑制吸收 "大力水手的肌肉都是沉淀"
