# 医学知识库使用说明

本库由《临床医学综合能力（西医）思维导图》PDF（278 页）经 AI 视觉识别转写而成，共 5 个学科、192 个章节文件。

以上及下文的题目、章节数量描述的是原始资料整理批次，不代表当前生产数据库数量。这些材料并非人卫教材原文，不能因为被导入知识库就视为已经完成教材核验。

## 教材依据与发布状态

- 医学结论以人民卫生出版社第十版相应教材为主要依据。旧题库答案、导图和口诀用于辅助学习；冲突时应明确标注来源差异并核对教材。
- 结构化教材出处字段已经上线，但历史卡片和章节仍主要只有 `source_file` 原始资料线索，当前尚无已核验的人卫第十版出处记录。后续需逐条补录教材书名、章节、页码、核验人和核验时间；未核实的页码不得补猜，不能将全库标为已按教材核验。
- 生产网页、App 和 AI 均读取 PostgreSQL 当前内容。管理员编辑章节、题目或卡片后，AI 后续检索直接使用同一记录；本目录只保留原始资料与校对线索。
- 教材出处保存在 `textbook_sources` 和 `content_citations`：可记录教材章节、小节、页码、说明及“待核验/已核验/存在争议”状态。未人工核对的旧内容不会自动标为已核验。

维护时先定位题目、卡片或章节，参考本目录中的原始线索，再对照人卫第十版教材。通过管理员编辑器保存正文与结构化出处后，核对应用展示和 AI 检索结果。部署方式见 [运维手册](../OPS.md)。

## 章节文件格式

每个文件带 front matter：

```yaml
---
tags: [生理学]
章节: 细胞电活动
考试频率: 细胞电活动（0~2题★★★）   # 原书粉色竖条：考察题数+星级
pdf页: [5, 6]                      # 对应原 PDF 页码（0 起）
---
```

正文中 `<!-- page_NNN -->` 注释标记每个原页边界，方便对照原图。

## 怎么用

**查询**：直接全文搜索（VS Code / Obsidian / 编辑器 Ctrl+Shift+F）关键词，如「肾病综合征」「慢波」。口诀、真题年份均已保留，也可搜年份（如「2023」）找考点。

**归类**：两套索引互补——`INDEX.md` 按学科→章节（忠实原书结构），`SYSTEM_INDEX.md` 按人体系统跨学科归类（如「肺炎」的病理机制 + 内科诊疗聚合一处）；每个文件 front matter 有 `tags` 和 `考试频率`（题数 + 星级），可按星级筛重点。

**记忆**：INDEX.md 顶部有「高频考点（★★★★ 及以上）」速查表；考频星级越高越是重点。

**AI 问答**：把这个文件夹作为上下文给 AI（Devin / Copilot / Claude Code 等），直接问「肝硬化有哪些并发症」——AI 检索 md 文件即可回答。原书所有口诀（如「肾伯伯怕脑瘤死了」）都在，可辅助记忆。

## 题库区说明

来源：万川刷题小程序账号导出（HYC 章节题/同步练习、老贺历年真题、执医真题、ttsx 讲义真题/口诀、模考押题等 44 个题库，共 70,407 题）。

- `题库/INDEX.md`：按学科分组的全部章节索引；每个 md 文件 = 一个题库章节，含题干、选项、答案、解析、官方统计（做过人数/正确率/难度）
- `题库/anki_all.tsv`：Anki 导入文件。导入方式：Anki → 文件 → 导入 → 选该文件；正面=题干+选项，背面=答案+解析，第三列标签为「题库 学科 章节」可按需筛选建牌组
- 共用题干（病例串）题在 md 中以引用块标注；Anki 中题干已合并进卡片正面
- 题目中的图片保留了原始 CDN 链接（需联网显示）

## 知识点区说明（考点精要层）

来源：上述题库解析经去重归并（70,784 → 53,232 道独立题）+ 思维导图笔记融合蒸馏，52 个分册。

- `知识点/INDEX.md`：全部分册索引
- `知识点/体征-疾病速查.md`：**体征→疾病反向速查表**（聚合各分册速查小节）。查"奇脉见于哪些病"这类问题直接 Ctrl+F 体征名
- 各分册内部按 `## 主题 → ### 核心考点/易混辨析/体征-疾病速查/数字·口诀` 组织；每条知识点标注来源题号 `[Qxxxxx]`（可到 `题库/` 搜原题+完整解析）
- `[争议]` = 不同来源/教材版本说法冲突；学习结论按人卫第十版教材核验，历史真题答案作为原题信息单独保留并解释差异

**推荐查询路径**：症状/体征类问题 → `体征-疾病速查.md`；系统复习 → `知识点/<学科>/`；原题核对 → `题库/`。

## 注意事项

- 原 PDF 为纯图片（无文字层），内容由视觉识别转写。绝大部分清晰可读，但个别极小字/口诀生造字可能有零星误差，存疑处标 `[?]`。
- 表格已转为 Markdown 表格，思维导图层级转为嵌套列表，箭头逻辑链保留 `→`。
- 如需校对某处，按 `pdf页` 字段回查原 PDF 对应页。
