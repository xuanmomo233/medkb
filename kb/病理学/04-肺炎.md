# 肺炎

> 考频：肺炎（0~2题★★★）｜学科：病理学

<!-- page_064 -->

细菌性肺炎：大叶性肺炎、小叶性肺炎、军团菌肺炎
间质性肺炎：病毒性肺炎、支原体肺炎、衣原体肺炎 "煎饼之一"（2013、2026）

| | 大叶性肺炎 | 小叶性/支气管肺炎 | 病毒性肺炎 |
|---|---|---|---|
| 微生物 | 肺炎链球菌等多见 | 肺炎链球菌、金葡菌等多见 | 病毒 |
| 好发 | 青壮年 | 卧床者、老幼弱 | |
| 性质 | 肺泡的纤维素性炎<br>（2002、2005、2021） | 细支气管及末梢肺组织的化脓性炎<br>（2002、2008、2021） | 间质性肺炎<br>（2004、2005、2006） |
| 特点 | 支气管不受累<br>胸膜多受累 | 常是某些疾病的并发症<br>（麻疹后/术后/吸入性/坠积性肺炎等 "最细码数"，2010） | 肺泡间隔明显增宽（2017）<br>血管扩张充血、间质水肿<br>淋巴细胞和单核细胞浸润 "林丹"<br>肺泡内透明膜<br>诊断依据-病毒包涵体（位于增生的上皮细胞和多核巨细胞） |
| 并发症 | 最常见：肺肉质变/机化性肺炎<br>（中性粒细胞渗出过少或功能缺陷，2009、2022）<br>最严重：感染性休克、败血症 | 多、严重 | |
