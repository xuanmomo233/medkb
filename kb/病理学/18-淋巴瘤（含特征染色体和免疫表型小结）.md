# 淋巴瘤（含特征染色体和免疫表型小结）

> 考频：淋巴瘤（含特征染色体和免疫表型小结）（0～3题★★★★）｜学科：病理学

<!-- page_079 -->

## 教材校注（人卫第10版摘要）

- 淋巴造血系统肿瘤需结合形态学、免疫表型、遗传学和临床表现综合分类；淋巴结反应性增生通常保留结构并有相应抗原刺激背景。
- 霍奇金淋巴瘤以少量Reed-Sternberg细胞及其变异细胞为诊断线索，周围常有多种炎细胞混合浸润；结节性淋巴细胞为主型具有爆米花样细胞，经典型可按结节硬化、混合细胞、富于淋巴细胞和淋巴细胞减少等亚型区分。
- 非霍奇金淋巴瘤包括B、T或NK细胞来源的多种实体；滤泡性淋巴瘤常与BCL2相关易位有关，弥漫大B细胞淋巴瘤侵袭性较强，双打击或双表达表型提示预后不良。
- 髓系肿瘤包括急性髓系白血病和骨髓增殖性肿瘤，诊断需结合外周血、骨髓形态及相关分子或染色体异常。
## 淋巴瘤——HL

- **HL**
  - 几乎B细胞来源（2024）
  - RS细胞（1997、2017）
    - 典型：双核（镜影细胞）或多核瘤巨细胞、核大、核仁明显呈红色、无核分裂象 "三大一红无分裂"
    - 不典型：霍奇金细胞（单核）、变异RS细胞（陷窝、爆米花、木乃伊/干尸细胞）
  - 结节性淋巴细胞为主型NLPHL：爆米花细胞，预后最好（2004、2012）
  - **CHL**
    - EBV感染、典型RS细胞、多种炎细胞混合浸润为背景（2010）

      | | 结节硬化型（1999、2007、2010） | 混合细胞型 | 富于淋巴细胞型 | 淋巴细胞减少型 |
      |---|---|---|---|---|
      | 特征 | 陷窝细胞 | 典型RS和单核RS | 大量淋巴细胞 | 典型RS或多形性瘤细胞 |
      | 特点 | EBV感染率低<br>青年妇女、纵隔肿块多见 "姐姐"<br>不转变为其他亚型 | | | EBV感染率接近100%<br>HIV者多见 |

    - 预后：富于淋巴细胞型＞结节硬化型＞混合细胞型＞淋巴细胞减少型 "结婚"（2016）
    - 发病率：
      - 《病理》：结节硬化型＞混合细胞型＞富于淋巴细胞型＞淋巴细胞减少型 "结婚"
      - 《内科》：混合细胞型＞结节硬化型＞富于淋巴细胞型＞淋巴细胞减少型 "婚戒"

## 淋巴瘤——NHL

- **NHL**
  - 弥漫大B（我国成人最常见）
    - 可由滤泡性转变而来：p53失活（2013）
    - 双表达（myc＋BCL2高表达）、双打击（myc＋BCL2或BCL6异位）→预后差
  - 滤泡性
    - 区分反应增生滤泡和肿瘤滤泡：
      - ①18号染色体的BCL2基因转位致BCL2蛋白高表达 "二人转"（2007）
      - ②肿瘤滤泡单克隆
  - 小淋巴/CLL（欧美成人最常见）"越小越成熟"
    - 幼淋巴细胞灶性成团形成 "增殖中心"（无CD10和BCL6）
    - 惰性（2000）
      - 《病理》：小淋巴、边缘区、滤泡性、淋巴浆、皮肤T、套
      - 《内科》：小淋巴、边缘区、滤泡性、淋巴浆、皮肤T "小便泡姜皮"
  - 淋巴母/前体（15岁以下最常见，2011、2020）
    - B-ALL：儿童更多见、常表现为白血病（血WBC↑）"baby"
    - T-ALL：青少年更多见、常表现为胸腺肿块 "teenage"
  - Burkitt（1997、2001、2008、2014、2020、2023、内2018）——高度侵袭性 "伯母"
    - EBV感染
    - ①地方性（非洲儿童最常见）：颌骨
    - ②散发性：回盲部形成腹腔巨大肿物
    - ③免疫缺陷性：淋巴结、骨髓
    - 瘤细胞间有胞质丰富的反应性巨噬细胞→满天星/星空现象（预后差，2005）
    - 侵犯骨髓、血液是ALL L3型
    - 对化疗非常敏感，单独用化疗即可治愈
  - T细胞来源 "T似蘑菇又像J 扭来扭去真可恶"（1999、2000、2008、2010）
    - T淋巴母/前体T/T-ALL、扭曲性/曲折核（1999）、恶性组织细胞增生症
    - 皮肤T/蕈样肉芽肿/Sezary综合征（2003）——脑回状细胞核、Pautrier微脓肿/鲍氏小脓肿 "上面吃了发霉的小鲍鱼PTSD了"
    - 间变性大（2026）——儿童、青少年多见
    - NK/T——EBV感染，鼻腔 "nose"

- **特征染色体（1998）**
  - t(14;18)：滤泡性、弥漫大B
  - t(11;18)：结外黏膜相关淋巴组织边缘区 MALT
  - t(11;14)：套
  - t(8;14)：Burkitt
  - t(2;5)：间变性大 “2+3=5”
  - t(15;17)：M3 型 AML（PML-RARA）“等差数列漂亮”
  - t(9;22)/Ph：CML（BCR-ABL）、急性白血病
- **特征免疫表型（2011、2012、2015、2017、2019、2022、内2007、2012）**
  - CHL：15/30
  - NLPHL：19/20/79a
  - 浆细胞骨髓瘤：38/138 “MM-3·8 妇女节”
  - 淋巴母/前体/ALL：CD34、TdT “撒种子要三思、蝌蚪-前体-母体”
  - 套：CD5/20、CyclinD1、BCL1
  - 边缘区：19/20/79a
  - 弥漫大B：19/20/79a、BCL2、生发中心型还可表达 CD10 和 BCL6 “长头发实属666”
  - 滤泡：10/19/20/79a、BCL2、BCL6
  - Burkitt：10/19/20/22/79a、BCL6、Ki67（肿瘤细胞增殖活性高）
  - 间变性大：30
  - 皮肤T/蕈样肉芽肿病/Sezary 综合征：2/3/4+、7/8-
  - NK/T：2/16/56 “一流物流寄来一双 NIKE 鞋”
  - M3 型 AML：13/33/117、9，不表达 CD34 和 HLA-DR
  - M5 型 AML：14
  - M7 型 AML：血小板 GP、41/61
