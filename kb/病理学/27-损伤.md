# 损伤

> 考频：损伤（10-4题★★★）｜学科：病理学

<!-- page_095 -->

可逆性损伤/变性：细胞或间质中出现异常物质或正常物质显著增多（2005）

|  | 病变部位 | 栗子 |
| --- | --- | --- |
| 水样变性 | 细胞 | 病毒性肝炎：胞浆疏松化、气球样变、内含红染细颗粒物（线粒体和内质网等细胞器肿胀扩张）“输了起哄”（2020、2022） |
| 脂肪变性 | 细胞（2020） | ①肝（最常见）：慢性右心衰→慢性肝淤血→槟榔肝（脂肪变性首先在小叶中央、集中在周边，2001）、丙肝、丁肝、酒精肝<br>②心：虎斑心“胖虎”（2001、2012、2024）<br>③肾：脂性肾病（近端小管上皮细胞，2001、2020）<br>④骨骼肌 |
| 玻璃样/透明变性（2002） | 细胞、间质 | ①纤维结缔组织（胶原蛋白沉积）：肉芽组织变瘢痕组织等（2025）<br>②血管壁（血浆蛋白沉积）：缓进型高血压、糖尿病的细小动脉壁（细小动脉硬化）（2022、2025）<br>③细胞内（2019、2021）——重吸收/玻璃样小体/滴：重吸收的尿蛋白（血浆蛋白）与溶酶体融合后沉积于肾近端小管上皮细胞内（1999）<br>Mallory小体（酒精肝的肝细胞内中间丝前角蛋白“酒干吗”，1999、2000、2007、2010、2013、2025）<br>Rusell小体（慢性炎症或骨髓瘤的浆细胞内粗面内质网沉积的免疫球蛋白） |
| 淀粉样变性（2000、2026） | 间质 | 甲状腺髓样癌、2型糖尿病、前列腺增生、阿尔茨海默病、骨髓瘤 |
| 粘液样变性 | 间质 | 甲减、风湿病、葡萄胎 |
| 病理性色素沉着（2023） | 细胞、间质 | ①脂褐素（消耗性色素“我吃我自己”）：萎缩的心肌和肝细胞<br>②含铁血黄素（巨噬细胞的溶酶体分解Hb“不要红细胞”）：肺泡腔内心衰细胞（慢性肺淤血/肺褐色硬化）、溶血、陈旧性出血（如卵巢巧克力囊肿）、大叶性肺炎<br>③黑色素：Addison病/原发性肾上腺皮质功能低下、色素痣、黑色素瘤、皮肤基底细胞癌<br>④胆色素：胆汁性肝硬化（肝细胞羽毛状/网状变性） |
| 病理性钙化（2001） | 细胞、间质 | ①营养不良性（常见）：坏死或即将坏死的组织、异物，如动脉粥样硬化斑块/粥瘤、血栓（静脉石/动脉石）、慢性虫卵、结核、心瓣膜病、瘢痕组织<br>②转移性（血钙↑）：胃、肾、正常血管、肺“为省学费转学了”（2004、2010、2011） |

<!-- page_096 -->

- **不可逆性损伤**
  - **坏死**
    - 细胞核：核固缩、核碎裂、核溶解、核染色质边集（1998、2019）
    - |  | 特点 | 好发 |
      | --- | --- | --- |
      | 凝固性坏死 | 轮廓保留、分界清楚（2016） | 心、肾、脾、肝、胰（2019） |
      | 液化性坏死 | 囊腔、脓肿（2019、2025、2026） | 脑（如乙脑筛状软化灶、高血压、动脉粥样硬化）、脊髓、肝（如病毒性肝炎溶解性坏死）（1998） |
      | 干酪样坏死 | 彻底无结构的凝固性坏死（嗜酸性红染颗粒物，2007） | 结核等（1998） |
      | 脂肪坏死 | 特殊的液化性坏死 | 急性重型胰腺炎（钙皂，2012）、女性乳房创伤 |
      | 纤维素/纤维蛋白样坏死（2016、2017、2018） | 结缔组织、血管壁胶原纤维坏死（2018、2021） | 急进型高血压、胃溃疡、风湿、类风湿、新月体性肾炎、重症急性肾炎、结节性多动脉炎、超急性排斥反应、SLE、SARS/MERS/COVID-19、1型糖尿病“高风亮节、喂狼超糖” |
      | 坏疽（1997） | 大片组织坏死后继发腐败菌感染（1998） | ①干性：肢体末端<br>②湿性（动静脉均闭塞）：阑尾、子宫、肺、肠、胆囊“男子非常胆大”（2015）<br>③气性：湿性坏疽+厌氧菌（气泡、捻发音） |
    - 结局
      - ①溶解吸收
      - ②分离排出
        - 糜烂、溃疡
        - 空洞
        - 窦道：如腰椎结核的脓液从背部病变处流出
        - 瘘管（两端相通“吸管”）：如阑尾切除术后切口处有肠内容物流出（2016）
      - ③机化和包裹：肉芽组织（如脓肿壁）（1996、2023）
      - ④营养不良性钙化
  - **凋亡（2000、2011、2017、2025、2026）**
    - 单个或小团细胞受基因调控的主动程序性死亡
    - 生理性或轻微病理性刺激（如病毒性肝炎嗜酸性坏死→嗜酸性小体/Councilman body，属于凋亡小体，1998）
    - 质膜完整（形态学与坏死明显区别）、无细胞自溶、无炎症反应、琼脂凝胶电泳呈梯状带
