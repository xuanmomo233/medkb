# 感染性心内膜炎

> 考频：感染性心内膜炎（0~1题☆☆☆）｜学科：病理学

<!-- page_066 -->


- **主要累及** → 二尖瓣＋主动脉瓣

| | 急性 | 亚急性（2004、2020） |
|---|---|---|
| 致病菌 | 金葡菌（最多见）、溶血性链球菌、肺炎链球菌等毒力较强的化脓菌 | 草绿色链球菌等毒力较弱 "小草很弱"（2006） |
| 病变部位 | 正常心瓣膜即可侵犯 | 病变心瓣膜（如风湿病） |
| 赘生物（含菌） | 易脱落形成栓子→败血性/感染性梗死 | 易脱落形成栓子→无菌性梗死（栓塞最多见于脑） |
| 受累瓣膜 | 瓣膜穿孔等 | 瓣膜变形等 |
| 变态反应 | 肾小球肾炎和Osler小结少见 | 肾小球肾炎和Osler小结多见 |

## 教材校注（人卫第10版摘要）

- 感染性心内膜炎是病原微生物经血行途径直接侵袭心内膜、尤其是心瓣膜的炎症性疾病，常伴赘生物形成。急性型多由毒力较强的化脓菌引起，亚急性型多由毒力较弱的链球菌引起，但病原谱并非绝对二分。
- 急性感染性心内膜炎主要侵犯二尖瓣和主动脉瓣，赘生物可破坏瓣膜并穿孔、破裂；赘生物脱落可造成感染性栓塞或转移性脓肿。亚急性病例可出现无菌性梗死、肾小球肾炎和Osler小结等超敏反应相关表现。
