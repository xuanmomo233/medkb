# 结核

> 考频：结核（0~2题★★★）｜学科：病理学

<!-- page_088 -->

- **结核结节/肉芽肿 “凌晨累死”（2006、2010、2022、2024、2025）**
  - 干酪样坏死（2013）→ 彻底的凝固性坏死，无结构嗜酸性红染颗粒物
## 继发性肺结核

| | | |
| --- | --- | --- |
| 局灶型肺结核（2005、2009、2015） | 非活动性 | 肺尖多见，境界清楚（增生为主） |
| 浸润型肺结核（最常见，2021） | 活动性 | 境界不清的云雾影（渗出为主），可有薄壁空洞 |
| 慢性纤维空洞型肺结核（2008） | 开放性（传染性强） | 厚壁空洞：内层（干酪样坏死物+大量结核杆菌）、中层（肉芽组织）、外层（纤维结缔组织）<br>广泛纤维化、肺门抬高、垂柳影、可并发慢性肺心病 |
| 干酪性肺炎（2015、2021） | 病情危重 | 虫蚀样空洞，可有大叶性实变 |
| 结核球（2005） | 结核瘤 | 境界清楚的纤维包裹干酪样坏死灶 |
| 结核性胸膜炎 | 湿性、干性 | 可致胸腔积液、胸膜增厚粘连 |

## 原发性肺结核 vs 继发性肺结核

| | 原发性肺结核 | 继发性肺结核（2001、2003、2014） |
| --- | --- | --- |
| 结核杆菌感染 | 初次、无免疫力 | 再次（内源复发为主）、有免疫力 |
| 好发 | 儿童 | 成人 |
| 病理特征 | 原发复合征（哑铃影）（1999、2015、2019）：<br>肺内原发灶：上叶下部、下叶上部近胸膜处（起始部位）<br>淋巴管炎<br>肺门淋巴结结核：肺门淋巴结肿大 | 病变常从右肺尖开始<br>上重下轻、上旧下新、较局限<br>常伴空洞 |
| 主要播散途径 | 淋巴道或血道 “TB 嚣张”（2002、2011） | 支气管（2002） |

- **继发性肺结核合并 AIDS**
  - ①好发于下叶
  - ②趋于原发性肺结核：常有肺门、纵隔淋巴结肿大，空洞少见
  - ③肉芽肿少见
  - ④PPD 常呈阴性或弱阳性
- **急性粟粒性肺结核（2006、2009、2017）**
  - 属于血源播散性结核
  - 双肺弥漫的三均匀（大小/密度/分布）粟粒影
- **肺外结核**
  - 肠结核（2000、2002、2010、2011、2013、2017）
    - 好发于回盲部
    - 肠黏膜淋巴管呈环形走向→环形溃疡（溃疡长轴与肠长轴垂直）→易致肠梗阻
  - 女性生殖系统结核以输卵管结核最常见
  - 骨与关节结核：冷/寒性脓肿（2023）
