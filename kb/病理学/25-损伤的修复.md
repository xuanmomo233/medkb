# 损伤的修复

> 考频：损伤的修复（10-1题★☆☆）｜学科：病理学

<!-- page_092 -->

## 教材校注（人卫第10版摘要）

- 再生能力取决于细胞的复制潜能；不稳定细胞持续更新，稳定细胞在损伤或刺激后可重新进入细胞周期，永久性细胞通常不能再生。
- 肉芽组织由新生毛细血管、成纤维细胞和炎细胞构成，随后逐渐纤维化形成瘢痕；肌成纤维细胞可促进伤口收缩。
- 皮肤创伤愈合包括炎症、增殖和重塑阶段，一期愈合组织缺损小、瘢痕少，二期愈合肉芽组织和瘢痕较多；感染、营养不良、血供不足和糖尿病可延迟愈合。


- **再生潜能（2005、2006、2008、2009、2025）**
  - 不稳定/持续分裂“三皮+造血”
    - ①皮肤表皮细胞
    - ②黏膜被覆上皮细胞（呼吸道/消化道/生殖道“道”）
    - ③间皮细胞（腹膜/胸膜/心包膜）
    - ④淋巴造血细胞
  - 稳定/静止 —— 腺体细胞（肝/胰/肾小管/汗腺）、血管内皮细胞、平滑肌细胞、纤维细胞、神经胶质细胞、骨细胞、软骨细胞
  - 永久/恒定 —— 神经元/神经细胞、心肌细胞、骨骼肌细胞
- **纤维性修复（纤维化）**
  - 如慢性炎症
  - **肉芽组织（无神经）**
    - 结构“新成员”（2005、2009、2012、2016、2019、2022）
      - ①大量新生毛细血管（内皮细胞）：毛细血管袢状弯曲→鲜红色细颗粒状
      - ②大量成纤维细胞/纤维母细胞（特征）：有收缩功能为肌成纤维细胞（促进伤口收缩）
      - ③数量不等的炎细胞（巨噬细胞为主-它能分泌生长因子。但急性血吸虫卵结节周围的肉芽组织以嗜酸性粒细胞为主）
    - 功能（1996、2023）
      - ①修复以填补组织缺损
      - ②抗感染保护创面
      - ③机化或包裹坏死组织、血栓、炎性渗出物、异物
    - 结局：发生玻璃样变性（胶原纤维等细胞外基质增多、而其余成分减少）→瘢痕组织（2019）
    - 经典干扰：肉芽组织 VS 肉芽肿
  - **骨折愈合（2012）**
    - |  | 肉芽组织 | 骨小梁 |
      | --- | --- | --- |
      | 血肿形成 | × | × |
      | 纤维性骨痂 | √ | × |
      | 骨性骨痂（排列紊乱的编织骨） | √ | √ |
      | 骨痂改建或再塑（板层骨） | × | √ |
  - **影响愈合**
    - 血供：提供营养利于愈合
    - 缺乏含硫氨基酸、VitC、锌→影响细胞外基质（胶原蛋白和弹性蛋白）形成→减弱伤口愈合强度（2009、2013）
    - 瘢痕疙瘩/蟹足肿与肥大细胞有关
  - **完全修复（1996、2003、2011、2014、2015、2016）**
    - 肝细胞点状坏死和嗜酸性坏死
    - 急性糜烂性胃炎
    - Ⅰ度烧伤（表皮浅层）、浅Ⅱ度烧伤
    - 骨折、肌腱断裂经功能恢复后
