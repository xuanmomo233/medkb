# 慢性胃炎、消化性溃疡、阑尾炎、胰腺疾病

> 考频：慢性胃炎、消化性溃疡、阑尾炎、胰腺疾病（9～11题★★★☆☆）｜学科：病理学

<!-- page_071 -->

## 教材校注（人卫第10版摘要）

- 慢性萎缩性胃炎以黏膜变薄、腺体减少或消失、肠上皮化生和慢性炎细胞浸润为核心；A型多与自身免疫相关，累及胃体和胃底，B型多与幽门螺杆菌相关，常以胃窦为主。
- 消化性溃疡本质是胃酸、胃蛋白酶攻击增强与黏膜防御屏障减弱的失衡；典型胃溃疡底部由内向外可见炎性渗出、坏死、肉芽组织和瘢痕层。出血、穿孔、幽门狭窄和癌变是主要并发症，十二指肠溃疡几乎不癌变。
- 急性阑尾炎由细菌感染和腔内阻塞共同参与，单纯性、蜂窝织炎性和坏疽性代表病变进展；坏疽性可穿孔并引起腹膜炎或阑尾周围脓肿。
- 急性胰腺炎的重型为出血坏死型，可见胰腺大片坏死、出血和胰周脂肪坏死，脂肪酸与钙结合形成钙皂。


- **慢性萎缩性胃炎**（2015）
  - 特征：黏膜变薄、皱襞变浅、黏膜下血管清晰可见、腺体变小和减少、胃小凹变浅及囊性扩张、淋巴细胞和浆细胞浸润（病程长者可形成淋巴滤泡）、纤维化（1996、2008、2014）
  - 腺上皮化生（2008）
    - 假幽门腺化生（2023）
    - 肠上皮化生（常见）（可有不典型/异型增生→可能癌变）
      - 完全型/小肠型/Ⅰ型：含有杯状、吸收、潘氏细胞
      - 不完全型/Ⅱ型：含有杯状细胞——胃型/Ⅱa型；结肠型/Ⅱb型→可能导致肠型胃癌
  - （2007、2026）

    | | A型胃炎 | B型胃炎（常见） |
    |---|---|---|
    | 病因 | 自身免疫 | Hp（常伴消化性溃疡） |
    | 抗壁细胞和内因子抗体 | + | - |
    | 好发部位 | 胃体、胃底 | 胃窦 |
    | 胃酸分泌 | 明显↓（缺乏） | 正常或↓ |
    | 血胃泌素 | ↑ | ↓ |
    | 血VitB₁₂ | ↓（常伴恶性贫血） | 正常 |

- **消化性溃疡**
  - 病因：Hp、防御屏障↓和侵袭因素↑等（2019）

    | | 胃溃疡 | 十二指肠溃疡（常见） |
    |---|---|---|
    | 好发年龄 | 中老年 | 青壮年 |
    | 好发部位 | 胃窦小弯侧 | 球部前壁 |

  - 胃溃疡
    - 圆形或椭圆形、多＜2cm、边缘整齐如刀切、底部平坦、深达肌层、阶梯状（贲门侧深＋幽门侧浅）、周围黏膜皱襞呈放射状向溃疡集中（溃疡底部瘢痕牵拉）
    - 溃疡底部由内向外（2007、2013）
      - ①炎性渗出层：中性粒细胞等白细胞、纤维素
      - ②坏死组织层：伊红坏死组织（纤维素样坏死）
      - ③肉芽组织层：大量新生毛细血管和成纤维细胞
      - ④瘢痕组织层：增殖性动脉内膜炎（管腔狭窄闭塞、血栓）→影响再生使溃疡不易愈合、但防止破裂出血
  - 并发症
    - ①出血：最常见
    - ②穿孔（2022）：胃溃疡好发于胃小弯、十二指肠溃疡好发于球部前壁
    - ③幽门狭窄
    - ④癌变：胃溃疡癌变率多＜1%（来自溃疡边缘）、十二指肠溃疡几乎不癌变

- **急性阑尾炎**
  - ①单纯性
  - ②化脓性（蜂窝织炎）
  - ③坏疽穿孔性→急性弥漫性腹膜炎、阑尾周围脓肿
  - （以上均）中性粒细胞等浸润

- **急性胰腺炎**
  - 水肿性/轻型（常见）
  - 出血坏死性/重型——胰腺大片凝固性坏死、胰腺周围脂肪坏死（特殊液化性坏死）、黄白色斑点（钙皂）

- **胰腺癌**
  - 好发部位：胰头
  - 最常见组织学类型：导管腺癌
