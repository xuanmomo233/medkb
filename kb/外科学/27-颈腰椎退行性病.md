# 颈腰椎退行性病

> 考频：颈腰椎退行性病 ★★★（0~4题）｜学科：外科学

<!-- page_223 -->

- 概述
  - 颈椎 1、2 无椎间盘，颈椎 3~7 有钩椎/Luschka 关节（2012）
  - 椎间盘结构：软骨终板、髓核、纤维环（2021）
  - 椎间盘易向后外侧突出
    - 第 m-n 椎间盘压迫第 n 神经根
    - 刺激或压迫神经根致疼痛：机械性压迫、化学性刺激、自身免疫性（2015）
  - 影像（2008、2009、2010、2015、2019）
    - X 线：生理曲度异常、骨质增生、钙化、椎间隙狭窄、椎间盘突出间隙不等宽等
    - CT：上述 X 线内容 + 观察椎间盘，但不能清楚观察神经和脊髓等受压情况
    - MRI：上述 CT 内容，清楚观察神经和脊髓等受压情况
- 颈椎病（2009、2011、2013、2014、2015、2016、2017、2023、2024）

| 分型 | 表现 | 治疗 |
| --- | --- | --- |
| 神经根型（最常见） | 颈肩痛 + 上肢放射痛，上肢感觉障碍（麻木）、运动障碍（无力）<br>Eaton 征、Spurling 征 "eason" | 首选保守<br>（按摩、颌枕带牵引等） |
| 脊髓型（最严重） | 持物不稳、踩棉花感 "飘"，四肢感觉、运动障碍，二便障碍<br>Hoffmann 征、Babinski 征 "哈巴儿" | 急诊手术<br>禁止按摩、颌枕带牵引 |
| 交感神经型 | 交感神经兴奋（心悸、出汗）或抑制的表现（心动过缓、血压↓），症状多体征少 | 首选保守 |
| 椎动脉型 | 猝倒、眩晕、视物模糊 | 首选保守 |
| 食管型 | 吞咽困难 | 首选保守 |

- 损伤平面判断

| --- | --- | --- | --- | --- |
| 运动障碍 | 肩、上臂外展 | 屈肘 | 伸肘 | 屈肘 "你过来啊" |

## 腰椎间盘突出症

- 腰痛（窦椎神经）+ 下肢放射痛（坐骨神经），腰部活动受限尤其前屈，腰椎侧凸 "内奸外患"（2018）
- 损伤平面判断（2007、2009、2010、2013、2024）
  - "L4L5S1 伸膝伸足屈足、膝反射没有踝反射，4-股四头肌 - 伸膝、自己摸"

|  | 运动障碍 | 感觉障碍 | 深反射障碍 |
| --- | --- | --- | --- |
| L4 | 伸膝 | 膝前、小腿前内、内踝 | 膝反射 |
| L5 | 伸踝、伸足 | 小腿外前、足背内 |  |
| S1 | 屈踝、屈足 | 小腿后、足外、外踝 | 踝/跟腱反射 |

- 膨出型、Schmorl 结节、经骨突出型：无神经根受压 → 直腿抬高（-）及加强（-），保守治疗 "紧箍不许摸不许碰"（2009、2010、2021）
- 突出型、脱出型、游离型：有神经根受压 → 直腿抬高（+）及加强（+），保守治疗 → 无效手术（2013）
  - 但二便障碍（马尾神经受压）急诊手术（2019）
- 鉴别诊断
  - 急性腰扭伤、梨状肌综合征 → 直腿抬高（+）及加强（-）"急性来不及加强"
  - 腰椎间盘膨出型、Schmorl 结节、经骨突出型、慢性腰肌劳损、第三腰椎横突综合征、腰椎管狭窄：症状多体征少、神经源性间歇性跛行（2019、2022）→ 直腿抬高（-）及加强（-）
