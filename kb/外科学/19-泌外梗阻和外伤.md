# 泌外梗阻和外伤

> 考频：泌外梗阻和外伤（9~12题★☆☆）｜学科：外科学

<!-- page_213 -->


- **前列腺增生（2024）**
  - 好发于移行带（与前列腺癌无关）"曾毅爱粥"
  - 尿频（最早），进行性排尿困难（最典型），劳累、饮酒等加重
  - 直肠指检中间沟变浅或消失（首选），影像学首选 B 超
  - 治疗（2023、2025）
    - ①观察随访
    - ②α-R阻断剂（特拉唑嗪）、5α还原酶抑制剂（非那雄胺）
    - ③经尿道前列腺切除术 TURP、经尿道前列腺切开术 TUIP、经尿道前列腺剜除术 EEP（前列腺体积80ml以上）
    - ④并发急性尿潴留：导尿（2013）
  - 并发症（2013、2021、2024）→ 尿潴留、急迫性或充溢性尿失禁、膀胱结石、感染、肾后性肾功能不全、膀胱假性憩室、无痛性血尿、腹外疝、痔疮

<!-- page_214 -->


- **泌尿系结石**
  - 成分（2010、2012）
    - 草酸钙（最常见）：X线高密度
    - 磷酸钙：鹿角样、X线高密度，酸化尿液＋抗感染 "灵感"
    - 尿酸盐、胱氨酸：X线不显影 "尿光了不显影"
  - 首选 B超→CT
  - 表现（2021）〔虚线标注：血尿与病变程度不一定相关〕
    - 疼痛 → ①肾结石：肾区、肋脊角 ②输尿管结石：绞痛 ③膀胱结石：排尿突然中断＋改变体位又排尿、膀胱刺激症
    - 血尿
  - 治疗
    - ＜0.6cm：药物＋饮水
    - 0.6~2cm的肾结石、输尿管上段结石：体外冲击波碎石 ESWL "饿/2死我了"
    - 0.6~2cm的输尿管中下段结石：输尿管镜碎石取石
    - ＞2cm的肾结石：经皮肾镜碎石取石
    - ＞2cm的输尿管结石：腹腔镜输尿管切开取石
  - 多发结石
    - ①双侧肾结石：先处理容易取出的一侧
    - ②双侧输尿管结石：双侧输尿管镜碎石取石，否则先处理梗阻严重的一侧
    - ③一侧肾结石、一侧输尿管结石：先处理输尿管结石

- **泌尿系外伤**
  - 男性尿道外伤最多见，金标准逆行尿道造影 "前骑球、后骨膜"

    |  | 前尿道 | 后尿道 |
    | --- | --- | --- |
    |  | 尿生殖膈以下 | 尿生殖膈以上（2014） |
    | 主要原因 | 会阴部骑跨 | 骨盆骨折（2015） |
    | 多损伤 | 尿道球部（2015） | 尿道膜部 |
    | 尿外渗、血肿 | 会阴、阴囊、阴茎、下腹壁 | 膀胱周围、耻骨后间隙 |
    | 其他 |  | 直肠指检肿痛、前列腺尖端浮动感 |

  - 膀胱破裂

    |  | 腹膜外型膀胱破裂 | 腹膜内型膀胱破裂 |
    | --- | --- | --- |
    |  | 前壁 | 后壁、顶部 |
    | 尿外渗、血肿 | 膀胱周围、耻骨后间隙 | 腹腔 |
    | 其他 | 下腹疼痛、压痛、肌紧张<br>直肠指检肿痛 | 全腹腹膜刺激征<br>可有移动性浊音 |
    | 手术 | 下腹正中切口 | 剖腹探查 |

  - 肾外伤（2022）→ 腰腹部疼痛＋血尿，影像学首选 CT<br>大出血、休克→手术探查同时抗休克

## 教材校注（人卫第10版摘要）

- 前列腺增生、尿路结石及泌尿系损伤需按各自病因评估；尿潴留、感染、肾功能受损或创伤性出血等会改变处理优先级。
- 结石治疗取决于成分、大小、位置、梗阻及感染；泌尿系损伤需先稳定生命体征并明确损伤部位和程度，再选择引流、修复或其他处理。
