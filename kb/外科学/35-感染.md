# 感染

> 考频：★★★感染（10~13题）｜学科：外科学

<!-- page_235 -->


- **概述**
  - 特异性感染：破伤风、结核、真菌如念珠菌、气性坏疽“凤姐真坏”
  - 外科用抗生素原则（2025）
    - ①不是所有外科感染都要用
    - ②用药也不能减免外科处理：去除感染灶＋通畅引流是外科治疗基本原则
    - ③有明确指征才预防性用药
    - ④联合用药要有明确指征：严重、混合、需长时间用药病原菌易耐药的感染、减少个别药物剂量以降低毒性反应

- **有芽孢厌氧菌：G+杆菌→外毒素（2017）**

  | | 破伤风（2007、2014、2017、2024） | 气性坏疽“化粪池”（2011） |
  | --- | --- | --- |
  | 病原菌 | 破伤风梭菌/杆菌 | 梭状芽胞杆菌（多为产气荚膜杆菌、水肿杆菌等混合“气水交加”） |
  | 表现 | 铁钉刺伤等<br>轻微刺激可诱发肌痉挛：咀嚼肌（张口困难/牙关紧闭）、苦笑面容、角弓反张、膈肌“咀嚼了才知道是苦的” | 肌坏死、明显肿痛<br>黑色、恶臭、大理石样斑纹、捻发感、皮下气肿<br>可有溶血性黄疸和血红蛋白尿（α毒素/卵磷脂酶） |
  | 预防关键 | 早期彻底清创切开引流（发病最主要的原因常是第一次清创不彻底） | 同左 |
  | 治疗关键 | ①防止窒息是关键（重症尽早气管切开）<br>②破伤风抗毒素TAT、破伤风免疫球蛋白TIG（最佳）可中和游离毒素 | 早期彻底清创切开引流 |
  | 伤口处理“痒死你” | 过氧化氢 | 过氧化氢或高锰酸钾 |
  | 抗生素 | 早期大剂量青霉素（在抗生素中作为首选）、甲硝唑<br>（氨基糖苷类抗生素无效） | 同左 |

- **脓肿切开引流小结：抓规律——脓肿尚未形成（没有波动感）暂不切开引流**

  | | 记特殊 |
  | --- | --- |
  | 破伤风、气性坏疽 | 早期彻底清创切开引流：预防发作的关键 |
  | 颌下蜂窝织炎（小儿多见） | 早期切开减压：避免窒息 |
  | 脓性指头炎、化脓性腱鞘炎和滑囊炎、掌深间隙感染 | 肿痛明显时切开引流<br>（脓性指头炎避免末节指骨坏死、骨髓炎） |
  | 丹毒 | 不切开引流（非化脓性炎） |
  | 寒性/冷脓肿<br>（结核，多无红、热） | 尽量不切开引流<br>仅寒性脓肿有混合感染、全身中毒症状明显（此时不能做病灶清除术）可考虑寒性脓肿切开引流“拿它开刀” |
