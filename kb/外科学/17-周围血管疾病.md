# 周围血管疾病

> 考频：周围血管疾病（9~12题☆☆☆）｜学科：外科学

<!-- page_211 -->

- **疼痛麻木、苍白寒冷、动脉搏动减弱消失**
  - 下垂患肢、保暖但不加热、抗板、抗凝、扩管（2008）
  - 急性 - 动脉栓塞
    - 5P综合征（疼痛、麻痹、苍白、无脉、感觉异常 "痛骂白无常"）
    - 急诊 Fogarty 球囊导管取栓、或切开动脉直接取栓；若坏死→溶栓
  - 慢性：经皮腔内血管成形术、旁路转流术等

    | 动脉硬化闭塞症 | 血栓闭塞性脉管炎（2008） |
    | --- | --- |
    | 中大动脉 | 中小动静脉 |
    | 男性多见，发病年龄多在45岁以上（常见/参考年龄，并非排除年轻患者的硬界值） | 青壮年男性多见 |
    | 高血脂、高血压、糖尿病、吸烟等 | 吸烟 "爱吸烟的小伙子" |

- **苍白发冷、青紫疼痛、潮红复原** → 雷诺综合征
  - 青壮年女性多见，多累及双侧手指 "美甲"
  - 肾上腺素能神经末梢阻断剂

- **肿胀暗红潮热、浅静脉迂曲扩张（如大隐静脉）**
  - 抬高患肢、弹力袜或绷带、抗板、抗凝、扩管
  - 原发性/单纯性下肢静脉曲张（2007）→ 持久站立、久坐、体力强度高
  - 下肢深静脉血栓形成（2011、2021）
    - 静脉损伤（胶原暴露）、血流缓慢（如长期制动）、血液高凝（如创伤/肿瘤）
    - 最严重 - 肺栓塞 "没形成则动、形成后别动"（2011、2021）
    - 经导管直接溶栓

- **试验（2015、2019）**
  - Buerger：动脉供血不足（主要是动脉硬化闭塞症、血栓闭塞性脉管炎 "B-闭塞"）、静脉逆流或回流障碍
  - Trendelenburg：大隐静脉瓣膜功能不全 "英文单词最长对应人体最长的浅静脉大隐静脉"
  - Pratt：交通静脉瓣膜功能不全 "tt-交替"
  - Perthes：深静脉阻塞如血栓（Perthes阳性——禁止结扎、剥脱、或向曲张浅静脉注射硬化剂）"person"（题库/记忆线索；本章现有精引仅覆盖pp324–325）
  - Homans：小腿深静脉血栓 "男神的小腿"
