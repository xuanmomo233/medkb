# 麻醉

> 考频：★☆☆麻醉（10~12题）｜学科：外科学

<!-- page_238 -->


- **全身麻醉（2007、2008、2010、2013）**
  - 吸入麻醉药
    - ①氧化亚氮：禁用于肠梗阻“笑破肚子”
    - ②地氟烷：适合心脏手术“心地善良”
    - ③七氟烷：呛咳屏气发生率低、可降血压“七里香”
  - 静脉麻醉药
    - ①依托咪酯：适合心脏手术“衣脱心动”
    - ②氯胺酮：小儿基础麻醉常用，镇痛强，适合休克、哮喘。可致幻觉噩梦、升高颅压/眼压/血压
    - ③异丙酚/丙泊酚、咪达唑仑、右旋美托咪定
  - 肌松药（无麻醉作用）
    - 竞争性（非去极化）→ 筒箭毒碱、维库溴铵（适合心肌缺血“维护心脏”）；新斯的明有效
    - 非竞争性（去极化）→ 琥珀胆碱：肌松出现前有肌纤维收缩；新斯的明无效
- **局部麻醉**
  - “咏麻：酯类普丁胆碱解、其余酰胺少过敏，普卡安全不表麻、丁卡表麻毒性大 利多全能慎腰麻、神经阻滞起效快，罗哌尤适硬膜外、分娩镇痛萝卜拔”
  - ①普鲁卡因毒性最小“普通-安全-逊”，适合局部浸润麻醉，不适合表面麻醉（2014）
  - ②丁卡因毒性最强，适合表面麻醉“钉子”，不适合局部浸润麻醉
  - ③罗哌卡因、布比卡因适合分娩镇痛（2014）
  - 一次限量（2024）→ 利多卡因表面100、神经和局部浸润400，丁卡因表面40、神经80，罗哌卡因和布比卡因150，普鲁卡因1000“和李医师钉死吧、摇我萝卜1000次”
  - 神经阻滞

    | | 颈丛 | 臂丛肌间沟径路 | 臂丛锁骨上径路 | 肋间 |
    | --- | --- | --- | --- | --- |
    | 易致高位硬膜外阻滞、全脊髓麻醉 | √ | √ | | |
    | 易致膈神经/喉返神经/颈交感神经麻痹 | √ | √ | √ | |
    | 易致气胸 | | | √ | √ |

- **椎管内麻醉**
  - 阻滞顺序（2013）：交感神经→副交感神经→感觉神经→运动神经→本体感觉/深感觉
  - 阻滞平面（2021）：T2胸骨角、T4乳头、T6剑突、T8肋弓、T10脐、T12耻骨联合上2~3cm/腹股沟平面
  - 麻醉平面调节：硬膜外阻滞-穿刺间隙；蛛网膜下腔阻滞-麻药剂量、患者体位“硬膜外打哪最重要、腰麻打多少最重要”（2009）
  - 骶管和鞍区麻醉可用于肛门、会阴部手术“肛麻：躺着吃里脊、坐在马鞍上、扇我下马威、睾开睾丸术”

    | | 骶管麻醉 | 鞍区麻醉 |
    | --- | --- | --- |
    | 本质 | 硬膜外麻醉（阻滞骶脊神经） | 蛛网膜下腔麻醉（阻滞骶尾神经） |
    | 体位 | 侧卧、俯卧位 | 坐位 |
    | 定位 | 骶管裂孔 | L3-L5椎体 |
    | 主要并发症 | 全脊髓麻醉、局麻药毒性反应、尿潴留 | 马尾综合征（二便障碍）、头痛、尿潴留 |

## 教材校注（人卫第10版摘要）

- 麻醉方式选择需综合手术需要、患者状态和风险；麻醉前评估、气道管理、循环呼吸监测及复苏准备是安全实施的重要环节。
- 全身、局部和椎管内麻醉的药理特点与并发症不同；麻醉平面和药物剂量应由麻醉专业人员依据实际情况调整。
