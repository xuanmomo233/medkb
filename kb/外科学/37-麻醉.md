# 麻醉

> 考频：★☆☆麻醉（10~12题）｜学科：外科学

> ：旧宽范围出处#235未逐条核验，不能替本图所有题库线索、年份和口诀背书。支持全身麻醉药物特点；第137–138页支持局麻药比较与剂量；第139–141页支持神经阻滞入路及对应风险；第143–145页支持椎管内阻滞平面、体位调节及鞍区定位；第146–148页支持腰麻、硬膜外及骶管并发症；第149页支持根据病情和手术要求调节麻醉深度。具体边界：第128页不支持七氟烷“可降血压”或氯胺酮“适用于哮喘”；第142页只明确交感神经最先、运动神经最迟及相对感觉平面的节段差，未给出副交感神经/本体感觉的完整固定顺序；第147页的腰麻并发症不可表述为鞍区麻醉特异风险；第149页不提供各药物剂量或麻醉平面的统一调整规则。年份仅表示考过年份，口诀仅为记忆辅助；的题库线索保留并标明。

- **全身麻醉（2007、2008、2010、2013）**
  - 吸入麻醉药
    - ①氧化亚氮：可升高体内封闭腔隙（如肠腔）压力，肠梗阻患者不宜应用“笑破肚子”
    - ②地氟烷：对心脏手术或心脏病患者行非心脏手术的麻醉可能更有利“心地善良”
    - ③七氟烷：对呼吸道无刺激、不增加气道分泌物并舒张气道平滑肌；维持麻醉浓度1.5%～2.5%时对循环系统影响较小（第128页）。题库线索“呛咳屏气发生率低、可降血压”，不能作为教材结论；“七里香”口诀保留。
  - 静脉麻醉药
    - ①依托咪酯：主要用于全麻诱导，适用于年老体弱和危重病人；一般剂量0.15～0.3mg/kg
    - ②氯胺酮：镇痛作用显著，常用于小儿基础麻醉；兴奋交感神经，使心率、血压及肺动脉压升高，可用于休克患者麻醉诱导；可增加脑血流量、颅内压及脑代谢率，颅内高压者慎用；可有幻觉、噩梦等精神症状及眼内压、颅内压升高（第128页）。题库线索“适用于哮喘”。
    - ③异丙酚/丙泊酚、咪达唑仑、右旋美托咪定
  - 肌松药不具镇静、镇痛作用，不能单独应用，应与其他全麻药联合应用；肌松药本身无麻醉作用。
    - 竞争性（非去极化）→ 筒箭毒碱、维库溴铵（维库溴铵适用于缺血性心脏病患者）；胆碱酯酶抑制药可拮抗
    - 非竞争性（去极化）→ 琥珀胆碱：肌松作用出现前可有肌纤维成束震颤；胆碱酯酶抑制药不能拮抗，反而增强
- **局部麻醉**
  - “咏麻：酯类普丁胆碱解、其余酰胺少过敏，普卡安全不表麻、丁卡表麻毒性大 利多全能慎腰麻、神经阻滞起效快，罗哌尤适硬膜外、分娩镇痛萝卜拔”
  - ①普鲁卡因毒性最小“普通-安全-逊”，适合局部浸润麻醉，不适合表面麻醉（2014）
  - ②丁卡因毒性最强，适合表面麻醉“钉子”，不适合局部浸润麻醉
  - ③罗哌卡因、布比卡因适合分娩镇痛（2014）
  - 一次限量（2024）→ 利多卡因表面100、神经和局部浸润400，丁卡因表面40、神经80，罗哌卡因和布比卡因150，普鲁卡因1000“和李医师钉死吧、摇我萝卜1000次”
  - 手指、足趾及阴茎等处使用局部麻醉药禁忌加用肾上腺素；注药量不宜过多（原页未给数值剂量），以免血管收缩或受压引起组织缺血坏死

- **椎管内麻醉**
  - 阻滞顺序（2013题库线索）：第十版明确交感神经最先被阻滞、运动神经最迟；交感阻滞平面通常较感觉平面高2～4节段，运动阻滞平面较感觉平面低1～4节段（第142页）。“副交感神经”“本体感觉/深感觉”的完整固定顺序未见原页直接表述。
  - 阻滞平面（2021）：T2胸骨角、T4乳头连线、T6剑突、T8肋缘、T10脐平脐线、T12耻骨联合上2–3cm
  - 麻醉平面调节：腰麻剂量为主要影响因素，穿刺间隙、体位、注药速度也可调节；硬膜外平面受药液容积、穿刺间隙、导管方向、注药方式及病人情况等影响（p145）。题库口诀“硬膜外打哪最重要”（2009）。
  - 骶管和鞍区麻醉可用于肛门、会阴部手术“肛麻：躺着吃里脊、坐在马鞍上、扇我下马威、睾开睾丸术”

    | | 骶管麻醉 | 鞍区麻醉 |
    | --- | --- | --- |
    | 本质 | 硬膜外麻醉（阻滞骶脊神经） | 蛛网膜下腔麻醉（阻滞骶尾神经） |
    | 体位 | 侧卧、俯卧位 | 坐位 |
    | 定位 | 骶管裂孔 | L4～5椎间隙 |
    | 主要并发症 | 局麻药毒性反应、误入蛛网膜下腔致全脊髓麻醉、术后尿潴留 | 腰麻相关头痛、尿潴留、马尾综合征；非鞍区麻醉特异风险 |

    注：将头痛、尿潴留及马尾综合征列在腰麻并发症中，并未称其为鞍区麻醉特异风险；列出的骶管麻醉并发症包括局麻药毒性反应、穿刺过深误入蛛网膜下腔导致全脊髓麻醉及术后尿潴留。

    注：还记载，腰麻后头痛可予平卧休息、镇痛和静脉补液；严重者可向硬膜外间隙注入生理盐水、5%葡萄糖溶液或右旋糖酐，必要时行硬膜外自体血充填。该页不支持题库线索中的“禁高张葡萄糖/甘露醇”表述。
