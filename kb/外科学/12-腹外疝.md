# 腹外疝

> 考频：★★☆腹外疝（10~3题）｜学科：外科学

<!-- page_203 -->


- 分类
  - 易复疝 → 小肠最常见
  - 难复疝“粘住了”（2015）
    - 大网膜最常见“小的难忘”
    - 滑疝（2022、2024）
      - 疝内容物成为疝囊一部分（切疝囊时避免误伤疝内容物，2022）
      - 疝内容物以盲肠、阑尾、乙状结肠、膀胱多见（右侧多见）
      - 常有消化不良、便秘
  - 嵌顿疝“卡住了”（疼痛明显、可肠梗阻）
    - Richter疝/肠管壁疝“人民币” → 嵌顿内容物仅为部分肠管壁；易误诊（局部肿块不明显、多无肠梗阻）
    - Littre疝 → 嵌顿内容物为小肠憩室如Meckel憩室
    - Maydl/逆行性嵌顿疝（2014、2026） → 嵌顿肠管包括几个肠袢、呈W形；即使疝囊肠管存活仍须将腹腔肠袢牵出检查以免遗漏坏死肠袢
    - Amyand疝 → 嵌顿内容物为阑尾“appendix”
  - 绞窄疝（血运障碍）（嵌顿疝发展而来）
  - 切口疝 → 经腹直肌切口最常见，切口感染是最常见原因（2015、2026）

- 治疗
  - 保守 → <1岁、<2岁脐疝、不耐受手术“小脐没必要”
  - 单纯疝囊高位结扎（2007、2019、2026） → >1岁婴幼儿、绞窄疝（并切除坏死肠管）“结扎大一窄”
  - 单纯疝修补/无张力疝修补如Rutkow、Stoppa、Lichtenstein法“亚狮龙”（2008、2022、2026）
    - ① 疼痛轻、恢复快、低复发、最常用
    - ② 但材料作为异物可引起感染
  - 疝囊高位结扎+修补（2009）
    - Ferguson法：加强前壁“Front”
    - Bassini法：最常用“BBB话最多”
    - McVay法：股疝、严重薄弱者，把腹内斜肌和联合腱缝合至耻骨梳韧带“摸屁股严重可耻”
    - Shouldice法：成人的大斜疝和直疝“应该大鞋子”，重点修补腹横筋膜和内环“横S征”
    - Halsted法

- 股疝（2026）
  - 腹股沟韧带下方包块，疝块小呈半球形、咳嗽冲击感不明显，中老年肥胖女性多见“不鸣则已一鸣惊人”
  - 最易嵌顿（2009、2017）

- 腹股沟疝

|  | 斜疝（最常见，2007、2009） | 直疝（2023） |
|---|---|---|
| 好发 | 儿童、青年男性 | 老年男性 |
| 突出途径 | 经腹股沟管内口（2015） | 经海氏/Hesselbach三角（腹壁下动脉、腹直肌外缘、腹股沟韧带） |
| 回纳疝块后压住内口/深环/腹环（腹股沟韧带中点上方2cm） | 疝块不再突出（鉴别关键） | 疝块仍可突出 |
| 疝块外形 | 椭圆或梨形、呈蒂柄状 | 半球形、基底较宽 |
| 进入阴囊 | 多√ | 几乎× |
| 咳嗽冲击感 | 多√ | 几乎× |
| 精索 | 在疝囊后方“小孩喜欢滑梯” | 在疝囊前外方 |
| 疝囊颈在腹壁下动脉 | 外侧（2015） | 内侧 |
| 嵌顿几率 | 多 | 少 |
