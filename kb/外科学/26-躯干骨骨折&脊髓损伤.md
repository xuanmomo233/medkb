## 躯干骨骨折 & 脊髓损伤

- 脊柱骨折概述
  - 好发于 T10-L2 "012"。成人 L1 以下骨折不会损伤脊髓（2007）
  - 诊断脊髓、神经、韧带、半月板等损伤首选 MRI "软软的"（2014、2018）
  - 脊柱骨折急救搬运：平托法、滚动法（2018）
- 颈椎骨折

|  | 屈曲型（2016） | 垂直压缩型 | 无骨折-脱位的过伸损伤 | 缢死者骨折（过伸损伤） | 齿状突骨折 | 寰-枢椎脱位 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  | Jefferson 骨折 "嬛嬛减肥"（C1 前后弓骨折） | Whiplash 挥鞭损伤等 | Hangman 骨折 "二叔上吊"（C2 椎弓根骨折） |  |  |
| 不手术 | 压缩 < 1/3 支具固定 | Halo 架或牵引固定 |  | 无移位 Halo 架或牵引固定 | Ⅰ、Ⅲ、无移位Ⅱ型 Halo 架固定 |  |
| 手术 | 压缩 > 1/3、或脱位 |  | 扩大椎管容积 | 有移位 | 有移位的Ⅱ型 | 寰枢椎融合术 |

- Chance 骨折 → 经椎体、椎弓、棘突的横向撕裂性骨折 "切水果连切-偶尔"
- 骨盆骨折
  - 骨盆分离试验与挤压试验阳性、双下肢不等长、会阴部瘀斑（耻骨和坐骨骨折的特征）
  - 并发症：失血性休克、后尿道尤其膜部、膀胱、直肠、坐骨神经等损伤（2015、2021）
- 脊髓损伤
  - 脊髓震荡 → 最轻微、可恢复
  - 不完全脊髓损伤（2025）
    - ①前脊髓综合征：最严重，下肢瘫痪重于上肢 "钱↓最严重"
    - ②后脊髓综合征：运动、痛温觉存在，而本体感觉障碍 "后-深"
    - ③脊髓中央管周围综合征：没有感觉分离，上肢瘫痪重于下肢 "中央-上级、不分离"
    - ④脊髓半切 B-S 综合征：同侧运动、本体感觉障碍，而对侧痛温觉障碍 "一同运动感深、对面感觉浅"
  - 完全脊髓损伤（2008、2014、2018）
    - 脊休克 2~4 周后软瘫变硬瘫（肌张力增高、腱反射亢进、病理征阳性）
    - C1-C4：四肢硬瘫
    - C5-T1：上肢软瘫、下肢硬瘫
    - T2-L1：上肢正常、下肢硬瘫
    - L2-S3：上肢正常、下肢软瘫
  - 脊髓圆锥、马尾神经损伤
    - 会阴部/鞍区感觉障碍、括约肌功能丧失（二便失禁）
    - 脊髓圆锥损伤运动正常，而马尾神经损伤运动障碍（软瘫）
  - 并发症（2008、2009、2022）
    - 坠积性肺炎、呼吸道感染、呼吸衰竭、尿潴留、泌尿生殖道感染和结石、压疮、自主神经功能紊乱（高热）
    - "想象肺肾脊柱两边、往外压、往内热"
  - 治疗
    - 6~8 小时是黄金时期：甲泼尼龙、高压氧疗
    - 手术指征：脊柱骨折-脱位、脊柱骨折复位不满意、碎骨片突入椎管、椎管内有活动性出血 "拖布入血"（2008、2014）
