## 下肢骨折和脱位 ★★★（0~3题）

|  | 髋关节脱位（2022、2026） | 股骨颈骨折（2007、2008、2010、2011、2016、2017、2019、2021） |
| --- | --- | --- |
| 好发部位 | 后脱位 |  |
| 好发年龄 |  | 中老年骨质疏松 |
| 分型移位 |  | 骨折线部位：头下型（股骨头仅有小凹动脉少量供血，缺血坏死机会大）、经颈型（股骨头供血不足，易缺血坏死或不愈合）、基底型（供血干扰较小、易愈合）；“头下型最重/基底型最轻”为题库比较线索<br>Pauwels 角：外展（< 30° 稳定）、内收（> 50° 不稳定）<br>移位程度（Garden）：Ⅰ 不完全骨折或嵌插骨折；Ⅱ 完全骨折不移位；Ⅲ 完全骨折部分移位；Ⅳ 完全骨折完全移位。注意：教材所述成人影像学研究显示，X线诊断为 Garden Ⅰ 型不完全骨折者，经 CT 检查均为完全骨折。<br>正常颈干角110°～140°；角度变大为髋外翻，变小为髋内翻"小医大四" |
| 临床表现 | 弹性固定、Shenton 线不连续<br>后脱位：屈曲内收内旋、臀部摸到股骨头、下肢缩短<br>前脱位：屈曲外展外旋、腹股沟摸到股骨头、下肢不定<br>"脱衣前是外衣、脱衣后是内衣" | 外旋畸形 45°~60°<br>下肢缩短（大转子上移）"NBS"：<br>超过 Nelaton 线、<br>Bryant 三角底边缩短、<br>Shoemaker征：题库线索 |
| 合并损伤 | 后脱位：坐骨神经损伤 | 股骨头坏死<br>脂肪栓塞（未找到股骨颈骨折特异性教材支持， |
| 保守治疗 | 后脱位 Epstein Ⅰ：Allis 提拉法 + 皮牵引/丁字鞋<br>（必须在全麻或腰麻下复位） | 年龄过大、全身情况差并有严重心肺肾肝等功能障碍不能耐受手术者：待手术期若24小时内能完成手术，可穿防旋鞋；若24小时内不能完成，给予皮肤牵引或股骨结节牵引（牵引重量为体重的1/11～1/7）；全身情况允许后尽早手术 |
| 手术治疗 | 后脱位Ⅱ-Ⅴ（合并关节内骨折）：切开复位 + 内固定 | 股骨颈骨折闭合复位内固定：可用3枚空心拉力螺钉或动力髋螺钉；置钉时股骨头旋转可联合使用<br>老年合并症多预期寿命短：半髋关节/股骨头置换术；老年合并症少预期寿命长的 Garden Ⅲ/Ⅳ：全髋关节置换术 |
