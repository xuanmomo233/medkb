# 休克

> 考频：★☆☆休克（10~11题）｜学科：外科学

<!-- page_240 -->


- 有效循环血量↓→组织灌注不足→氧供给不足和氧需求增加（本质）、炎症介质释放（特征）
- **治疗最关键/首选：一般补充血容量（2010、2013、2023）**
  - 补平衡盐等晶体液
  - 可联合人工胶体液（如羟乙基淀粉）、必要时输血
- **分度**
  - 休克早期/代偿期/轻度（2007、2022、2026）→ 失血量＜20%（＜800ml），收缩压正常或稍↑、舒张压↑、脉压↓
  - 休克期/失代偿期“看2”

    | | 中度 | 重度 |
    | --- | --- | --- |
    | 失血量 | 20%~40% | ＞40%（＞1600ml） |
    | 脉搏 | 100~200次/分 | 速（＞200）而弱（摸不清） |
    | 收缩压 | 90~70、脉压↓ | ＜70 |
    | 神志 | 尚清楚、表情淡漠 | 意识模糊、昏迷 |

- **监测**
  - 尿量 → ①尿量＜25ml/h且尿比重增加：血容量不足致肾血管收缩（肾前性肾衰）②血压正常但尿量仍少且尿比重低：肾性肾衰（2007）
  - 乳酸、碱剩余 → 评估缺氧、酸中毒、无氧代谢程度、预后
  - 中心静脉压CVP（5~10cmH₂O）→ 失血性休克补液原则

    | | CVP | BP |
    | --- | --- | --- |
    | 血容量严重不足：充分补液 | ↓ | ↓（＜90） |
    | 血容量不足：适当补液 | ↓ | 正常 |
    | 容量血管过度收缩：扩静脉 | ↑ | 正常 |
    | 心功能不全或血容量相对过多：强心、纠酸等 | ↑ | ↓ |
    | ①补液试验→BP↑：血容量不足<br>②补液试验→CVP↑：心功能不全 | 正常 | ↓ |

- **感染性休克（2007、2010、2025）**
  - 继发性腹膜炎（腹腔空腔脏器穿孔损伤等）、AOSC、绞窄性肠梗阻、泌尿系感染、重症胰腺炎等
  - 补充血容量/同时治疗感染灶 → 常需外科引流；在有效抗生素前提下早期大剂量短时间用糖皮质激素；纠酸、心血管活性药
