## 冠心病——检查

- **心电图**（2007、2019）
  - 发作时必做
  - 运动负荷试验禁忌症（2015）：ACS、明显心衰、严重心律失常、急性疾病
  - 连续动态监测 Holter：胸痛发作时相应时间 ST-T 改变、检出无痛性心肌缺血（隐匿型冠心病）
  - **定性**
    - 高耸 T 波：急性心梗超急性期
    - 倒置 T 波伴 ST 段改变：冠心病（2019、2024）
    - ST 段抬高：变异型心绞痛、STEMI
    - 病理 Q 波：STEMI
  - **定位**

    | 导联/冠脉 | 定位 |
    |---|---|
    | I、aVL | 高侧壁 |
    | II、III、aVF | 下壁/膈面 |
    | V₁V₂V₃ | 前间隔 |
    | V₃V₄V₅ | 局限前壁 |
    | V₅V₆V₇ | 前侧壁 |
    | V₁—V₅ | 广泛前壁 |
    | V₇—V₈ | 正后壁 |
    | 左前降支 | 左室前壁、侧壁、心尖、前间隔、二尖瓣前乳头肌 |
    | 左回旋支 | 左室侧壁、左心房 |
    | 右冠脉 | 右室、窦房结、房室结、后间隔、左室下壁 |

- **冠脉造影 DSA**（诊断冠心病金标准）、**冠脉 CTA**（诊断冠心病最常用）（2025）

- **心肌坏死标志物**（2010、2011、2014、2015、2021）
  - **SMB** → 2 小时内升高、恢复最早“红枣”，敏感性高、特异性低
  - **cTn** → 3~4 小时后升高、恢复最晚（1~2 周），特异性最高（最有价值）
  - **CK-MB** → 4 小时内升高，1~2 周内诊断再发心梗、较准确反映梗死范围、高峰 < 14 小时出现间接判断溶栓再通

- **核素心肌显像**：灌注缺损显示缺血或梗死区域（瘢痕）

- **超声心动图**：室壁运动节段性减弱；诊断急性心梗并发乳头肌功能失调或断裂、室壁瘤、心脏破裂、心梗后综合征

## STEMI（并发症）

- **心源性休克** → 主动脉内球囊反搏（2020、2024）

- **心律失常** → 前壁心梗易致室性心律失常、下壁心梗易致房室阻滞和心动过缓

- **乳头肌功能失调或断裂**（2011、2015）
  - 前壁心梗最常见并发症是乳头肌功能失调（抗缺血治疗后多好转）
    - 二尖瓣脱垂→心尖收缩中晚期喀喇音（额外心音/附加音）
    - 二闭→心尖收缩期吹风样杂音
  - 二尖瓣后乳头肌断裂多见于下壁心梗：急性二闭→急性左心衰

- **室壁瘤** → 左侧心界扩大、超声心动图反常搏动/矛盾运动、心电图 ST 段持续抬高

- **栓塞、猝死**

- **心脏破裂**
  - ①心室游离壁破裂（主要）：急性心脏压塞→心包穿刺；无脉性电活动
  - ②室间隔破裂：胸骨左缘 3~4 肋间收缩期杂音

- **急性左心衰**
  - 突发喘憋、端坐呼吸、咳粉红色泡沫痰、双肺湿啰音
  - **Killip 分级**（2007）“1 无 23 啰 4 休克”
    - II 级肺啰音 < 50%
    - III 级肺啰音 > 50%
    - IV 级心源性休克（收缩压 < 90、PAWP ≥ 18、CI ≤ 2.2）

- **心梗后 Dressler 综合征**（数周~数月）→ 心包炎、胸膜炎、肺炎
