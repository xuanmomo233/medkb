# 胃炎

> 考频：内科含诊断 胃炎（含胃酸小结&Hp小结）（0~2题★★☆☆）｜学科：内科学

<!-- page_139 -->


- **急性糜烂出血性胃炎**
  - NSAIDs、应激、饮酒后急性上腹痛 + 上消化道出血（NSAIDs 抑制 COX-1 → 前列腺素↓，2017）
  - 可能可能最可能
  - 急诊胃镜：诊断 + 止血
- **慢性胃炎**
  - Hp 感染（最常见）、十二指肠-胃反流、NSAIDs、饮酒、自身免疫等（2012）
  - 胃镜：黏膜变薄、皱襞稀疏平坦、黏膜下血管透见、腺体变小和减少、淋巴细胞和浆细胞浸润（出现中性粒细胞提示活动期）；腺上皮化生：肠上皮化生、假幽门腺化生
  - 可能可能最可能（2026）
  - （2007、2018、2019、2020、2022、2026）
  - **萎缩性胃炎**
    - |  | A 型/自身免疫性胃炎（2026） | B 型/多灶萎缩性胃炎 |
      | --- | --- | --- |
      | 发病率 | 低 | 高 |
      | 病因 | 自身免疫 | Hp |
      | 抗壁细胞和内因子抗体 | + | - |
      | 好发部位 | 胃底、胃体 | 胃窦“逗比” |
      | 胃酸分泌 | 明显↓（缺乏） | 正常或↓ |
      | 血胃泌素 | ↑ | ↓ |
      | 贫血 | 巨幼贫（VitB12↓，MCV > 100）<br>缺铁贫（HCl↓，MCV < 80） | 无恶性贫血 |
      | 伴消化性溃疡 | × | √ |
      | 治疗 | 糖皮质激素、注射 VitB12 | 根除 Hp |
  - **处理癌前情况** → 在根除 Hp 的前提下，补充维生素、硒；药物不能逆转的局灶重度异型增生和原位癌 → 胃镜黏膜下剥离术 + 定期随访
- **胃酸小结**
  - 胃酸明显减少/缺乏（MAO=0）：A 型胃炎、胃癌
  - 胃酸减少：B 型胃炎伴大量 G 细胞丧失
  - 胃酸正常或减少：B 型胃炎、胃溃疡Ⅱ/Ⅳ型
  - 胃酸增加：十二指肠溃疡、胃溃疡Ⅱ/Ⅲ型
  - 胃酸明显增加：胃泌素瘤
- **Hp 小结**
  - 慢性胃炎、消化性溃疡、胃癌、胃淋巴瘤
  - 首选、金标准、复查：非侵入性的尿素呼气试验（2014）
  - 快速尿素酶试验：侵入性检查首选（2014）
  - Hp 抗原：简单准确
  - Hp 抗体：复查不出现假阴性（不能判断根除，2012）
  - 四联：PPI + 铋剂 + 2 种抗生素（四环素、克拉霉素、喹诺酮类、甲硝唑和替硝唑、阿莫西林、氨苄西林、呋喃唑酮，“四克拉的痢子让花甲之年的阿莫娶到了羊夫人”，2015、2016）
  - 疗程 10~14 天；根除 Hp 至少 4 周后复查“2 种抗生素 - 疗程 2 周、四联疗法 - 4 周复查”
  - （大部分急性胃炎、胃食管反流病、A 型慢性萎缩性胃炎与 Hp 无关）
