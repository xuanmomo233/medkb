# 收缩性心衰

> 考频：内科含诊断 收缩性心衰（1~3题★★★★）｜学科：内科学

<!-- page_131 -->


- **分类**
  - 慢性心衰：冠心病（最主要）、高血压等
  - 急性心衰
  - 低排量心衰
  - 高排量心衰（脉压↑）：动静脉瘘、脚气病、严重贫血、甲亢、围生期心肌病“动脚评价人”（2011）
- **评定**
  - 分期
    - A 心衰危险因素阶段：只有心衰高危因素
    - B 前心衰阶段（心功能不全）：无心衰临床表现，有心脏结构改变（左心室肥厚、既往心肌梗死、脑钠肽升高等）
    - C 症状心衰阶段：有心衰临床表现
    - D 晚期心衰阶段：心源性恶病质
  - NYHA 分级（2013）（急性心梗心衰用 Killip 分级）
    - Ⅰ
    - Ⅱ 一般活动出现呼吸困难等心衰症状（NYHA Ⅱ 级相当于 C 期）
    - Ⅲ 夜间憋醒、需坐起后缓解“躺下去坐起来”
    - Ⅳ“躺都躺不下去”“白天查体半卧位”
  - 慢性心衰分度 → 6 分钟步行 < 150m、> 450m → 重、中、轻“150+450=6 分钟”（2010、2016）
- **诱因**
  - 呼吸道感染（最常见）、房颤、静脉输液等
- **病因**
  - 心肌损害
  - 负荷
    - 后负荷/压力负荷过重：高血压、主狭、肺动脉高压、肺狭等
    - 前负荷/容量负荷过重：心瓣膜关闭不全、动脉导管未闭、间隔缺损、伴回心血量增多的疾病等
    - 前负荷不足：二狭等
- **淤血**
  - 中老年活动后心悸气短（2007、2008、2009、2014、2015、2016、2017）可能可能最可能
    - **左心衰“必须关注肺”** → 咳嗽咳痰咯血、双肺湿啰音；心尖多向左下移位、心尖收缩期杂音、S1↓、奔马律、交替脉；呼吸困难：劳力性→夜间阵发性呼吸困难和端坐呼吸→急性肺水肿/心源性哮喘
    - **右心衰** → 消化道症状、劳力性呼吸困难、肝颈静脉回流征、肝大伴压痛、双下肢水肿、胸腹水；心尖多向左移位、胸骨左缘 4~5 肋间收缩期杂音、奔马律、奇脉/吸停脉；左心衰发展到右心衰后患者呼吸困难等肺淤血症状反而会减轻

- **反应心功能**
  - 首选超声心动图（2007）：LVEF ≤ 40%
  - 金标准右心漂浮 Swan-Ganz 导管：左心衰 PCWP ≥ 18、CI ≤ 2.2
  - 脑钠肽（2017、2022）→ 增高程度与严重程度正相关→评估心衰预后；NT-proBNP 正常可基本排除急性心衰、< 125 可基本排除慢性心衰
  - X 线（2020）：肺门增大、上肺纹理增多、Kerley B 线（慢性间质性肺水肿）、肺门蝴蝶征（急性肺泡性肺水肿）
- **急性左心衰**
  - 高血压急症、急性心梗、急性心肌炎、急性瓣膜关闭不全等病史，突发呼吸困难、端坐呼吸、双肺湿啰音、咳粉红色泡沫痰
  - 可能可能最可能
  - 治疗（2022、2023）
    - 湿暖型最常见（有明显淤血、无明显低灌注）→ 血管扩张剂：硝普钠（高血压急症首选；二狭不用）、硝酸酯类、乌拉地尔、rhBNP“肖肖无奈”；利尿剂：呋塞米、托拉塞米、布美他尼
    - 湿冷型最严重（有明显淤血、有明显低灌注）→ 收缩压 > 90：血管扩张剂、利尿剂→正性肌力药；收缩压 < 90：正性肌力药（β-R 激动剂、磷酸二酯酶抑制剂、左西孟旦、毛花苷丙“按拢猛干”）
    - 吗啡、高流量给氧、半卧或端坐位、抗凝等
- **慢性心衰的治疗（2008、2017、2018、2021、2024、2026）**
  - 降低死亡率（抗重构）：ACEI/ARB/ARNI（沙库巴曲缬沙坦）、β-R 拮抗剂、醛固酮受体拮抗剂、SGLT-2i（格列净）、sGC 刺激剂（维立西呱）、伊伐布雷定（窦房结 If 电流抑制剂 - 房颤不用）、CRT（适合收缩不同步、LVEF ≤ 35%、完左）、ICD（预防恶性心律失常所致猝死）“ABQ 等五朵金花”
  - |  | 用 | 不用（2007、2009、2015、2016） | 注意 |
    | --- | --- | --- | --- |
    | ACEI/ARB/ARNI | 糖尿病、蛋白尿、痛风（ARB）<br>慢性心衰、扩心病、冠心病、高血压 | ①均不用：血 Cr > 265、血钾 > 5.5、双肾动脉狭窄、妊娠、低血压“机甲吓人地”<br>②不用 ACEI：血管性水肿、不耐受干咳、痛风 | 不要将它们合用 |

## 教材校注（人卫第10版摘要）

- 心力衰竭是心脏结构和/或功能异常导致收缩或充盈障碍，并造成心排血量下降和/或心腔压力升高的一组临床综合征；收缩性心衰属于心衰表型之一。
- 超声心动图用于评估结构和射血分数，利钠肽可辅助诊断及预后评估。急性心衰处置与慢性心衰改善预后的长期治疗目标不同，药物须结合血压、灌注、淤血、肾功能及禁忌证选择。
