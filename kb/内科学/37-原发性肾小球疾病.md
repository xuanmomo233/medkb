# 原发性肾小球疾病

> 考频：内科含诊断原发性肾小球疾病（1~6题★★★★）｜学科：内科学

<!-- page_156 -->


**急性肾炎综合征**：血尿（必备且突出、＞3/HP）、蛋白尿、水肿和高血压（GFR↓致水钠潴留→多从眼睑颜面部开始 "憋出来的"）（2010、2016、2018、2019、2021、2023、2024、2026）

| | 急性肾炎（2010、2014、2016、2020、2023） | 急进性肾炎（2010、2022） |
|---|---|---|
| 名字 | 急性弥漫增生性肾炎<br>毛细血管内增生性肾炎（2016）<br>链球菌感染后性肾炎（2011） | 快速进行性肾炎<br>毛细血管外增生性肾炎<br>新月体性肾炎 |
| 增生 | 内皮细胞、系膜细胞 | 肾小囊壁层上皮细胞 "闭月" |
| 机制和荧光 | 原位或循环免疫复合物（2011）<br>颗粒状 | Ⅰ-抗基膜型 GBM（原位）：线状<br>Ⅱ-免疫复合物型（原位或循环）：颗粒状<br>Ⅲ-免疫反应缺乏型（ANCA）：无荧光 "3 型安卡无免疫" |
| 好发年龄 | 儿童、青年 | 青年、中老年 |
| 前驱感染 | 多有，起病前 1~3 周上感等 | 多有，起病前 1~3 周上感等 |
| 肾功能减退 | 多不明显（Cr 多＜200、贫血多无或轻） | 早期急剧恶化（Cr＞200、贫血有甚至中度及以上） |
| 补体 C3 | ↓且 8 周内恢复（特点） | Ⅱ型持续↓ |
| 治疗 | 对症<br>（不用激素+环磷酰胺，2016） | 强化疗法配合泼尼松+环磷酰胺<br>①血浆置换强化：Ⅰ、Ⅲ型，肺出血如 Goodpasture 首选血浆置换 "好怕医生抽血"<br>②甲泼尼龙冲击强化：Ⅱ、Ⅲ型 "三心二意激素强" |

**肾病综合征**：大量蛋白尿（必备、多 +++ 或 ≥3.5）、低蛋白血症（必备、＜30）、水肿（血浆胶渗压↓）、高脂血症（2010、2015、2020、2024、2026）

| | 脂性肾病（2011、2020） | 膜性肾病（2015） | 系膜增生性肾炎 | 系膜毛细血管性肾炎 |
|---|---|---|---|---|
| 名字 | 微小病变性肾病，足突病 "足球小子脏" | "中老年历经磨难吃鸡丁" | | 膜增生性肾炎 |
| 病理 | 光镜肾小球无明显异常（2023）<br>近端小管脂肪变性<br>肾小囊脏层上皮细胞足突融合消失 | 基膜明显增厚<br>钉状突起、梳齿样、虫蚀样空隙<br>肾小囊脏层上皮细胞足突融合消失 | 系膜细胞和基质增生 | 系膜细胞和基质增生<br>并插入基膜和内皮间致双轨/分层征 |
| 免疫荧光 | 无（T 细胞免疫） | 颗粒状 | 颗粒状 | 颗粒状 |
| 好发年龄 | 儿童（最常见）、青年 | 中老年 | 青年 | 青年 |
| 表现 | 典型肾病综合征（2011、2020） | 最易肾静脉血栓 | 几乎伴血尿 | 几乎伴血尿、C3 持续↓ |
| 初治 | 单用激素<br>（8~12 周好转，2011、2020） | 激素+环磷酰胺<br>（2015） | 单用激素 | 激素+环磷酰胺<br>（疗效差） |

- **继发性**
  - 急进性肾炎（2011）—— Ⅰ型：肺出血-肾炎 Goodpasture 综合征；Ⅱ型：急性肾炎、SLE、过敏性紫癜；Ⅲ型：显微镜下多血管炎、Wegener 肉芽肿 "自制三鲜肉"
  - 肾病综合征（2016、2024）
    - 儿童和青年多见 —— 过敏性紫癜：IgA 沉积为主，双下肢对称出血点（2019）；SLE：育龄期女性多见；乙肝：膜性肾病最常见
    - 中老年多见 —— 骨髓瘤、淋巴瘤、糖尿病、淀粉样变性 "遂宁糖粉"
- **概述**
  - 金标准：穿刺活检（2010、2012、2015、2016、2019、2024、2025）
  - 容量依赖型高血压先利尿消肿降压（2020）
  - 针对蛋白尿+高血压：ACEI/ARB
  - **肾病综合征的并发症（2013、2021）**
    - 血栓、栓塞（2007、2014、2015）—— 膜性肾病肾静脉最常见：突发腰痛、血尿或蛋白尿加重、肾脏增大；首选 B 超、最佳肾静脉造影；白蛋白＜20 预防性抗凝、辅以抗板
    - 蛋白质及脂代谢紊乱 —— 肝代偿增加蛋白合成的能力＜丢失和分解
    - 感染 —— 无需预防性用抗生素
    - 急性肾损伤（少见）—— 脂性肾病最常见
- **IgA 肾病（2014、2015、2017、2019）**
  - 肾小球源性血尿最常见的原因（2012、2013）
    青年多见，前驱感染 1~3 天后明显血尿
  - 多种病理类型、以系膜增生性肾炎最常见（2014）
  - ①单纯血尿（主要）：对症（不用激素+环磷酰胺）
    ②伴蛋白尿和/或高血压：ACEI/ARB 尿蛋白＜0.5、若无效可给激素

<!-- page_158 -->


- **慢性肾炎综合征**
  （血尿、蛋白尿、水肿、高血压＞3 个月）
  （2007、2009、2013、2019、2025）
  - 慢性/硬化性/终末肾炎
  - 双肾体积早期正常
    后期对称缩小（B 超长径＜10cm）
  - 不以消除肾炎综合征为目标
    收缩压＜120、尿蛋白＜1
    不用激素+环磷酰胺
- **无症状性血尿和/或蛋白尿**
  （隐匿性肾炎）
  - 无水肿、高血压、肾功能损害
    仅血尿/仅蛋白尿/仅血尿+蛋白尿
  - 定期随访（不用激素+环磷酰胺）

## 教材校注（人卫第10版摘要）

- 原发性肾小球疾病可呈肾炎综合征、肾病综合征、无症状性血尿/蛋白尿或急进性肾炎等临床类型；确诊和分型需综合尿检、肾功能、免疫学及必要时肾活检。
- 急性肾炎、急进性肾炎、IgA肾病、肾病综合征和慢性肾小球肾炎的病理机制与治疗差异明显，免疫抑制治疗须基于病理类型、活动度和禁忌证决定。
