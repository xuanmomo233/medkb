# 肺结核

> 考频：肺结核（0~3题★★★）｜学科：内科学

<!-- page_115 -->


- 长期低热、多盗汗、咯血（多为痰中带血-与毛细血管有关）
  - ①浸润型肺结核（最常见的继发性肺结核）：境界不清的云雾影、可有薄壁空洞
  - ②慢纤空：厚壁空洞、广泛纤维化、肺门抬高、垂柳影、纵隔向患侧移位
  - ③干酪性肺炎：可高热，可有大叶性实变、虫蚀样空洞
  - 可能可能最可能（2020、2024）

- **检查**
  - PPD检出是否感染结核杆菌、并非检出结核病（2009、2015、2016）
    - PPD呈阴性或弱阳性：长期用激素或免疫抑制剂、癌症、严重细菌感染、粟粒性结核、麻疹、水痘、HIV、结核性脑膜炎、营养不良“苏一爱洗礼、麻豆爱挠痒”
  - X线→CT
    - 继发性肺结核好发于上叶尖后段、下叶背段和后基底段“勾肩搭背hou基友”（2012）
    - 合并艾滋病者好发于下叶（2016）
    - 多形性改变：空洞、渗出（斑点/片、实变等）、纤维条索、钙化、卫星灶等
  - 确诊（2023）
    - 首选痰涂片，金标准痰培养
    - 痰培养阳性（菌阳）→活动性肺结核“活性乳酸菌”，包括：
      - ①有传染性：痰涂片阳性（涂阳）→开放性肺结核（排菌量大）
      - ②无传染性：痰涂片阴性（涂阴）
    - 3次痰涂片＋1次痰培养阴性→菌阴性肺结核
  - 判断活动性→无活动性（全满足）：无任何症状（无发热等），痰检查不排菌，X线钙化/硬结/纤维化

- **治疗**
  - 早期、联合、全程、适量、短程、规律
  - 抗结核药举例（2015、2018）

    | | 特点 | 主要副作用 |
    |---|---|---|
    | 异烟肼（H） | 对A群最敏感“阿姨”，全杀 | 肝功损害、周围神经炎-手足麻（加VitB₆）“烟-炎，麻-6” |
    | 利福霉素类利福平（R）和利福喷丁 | 对C群最敏感“Selina”，全杀 | 肝功损害（若黄疸→停药） |
    | 吡嗪酰胺（Z） | 对B群最敏感“吡-B”，细胞内半杀 | 肝功损害、高尿酸“比内功滋尿” |
    | 链霉素（S） | 细胞外半杀 | 肾毒性、耳毒性 |
    | 乙胺丁醇（E） | 抑菌剂“乙-E-抑” | 视神经炎“丁-盯” |

  - 活动性肺结核初治：2HRZE/4HR（2个月强化期/4个月巩固期）“2个好人择偶变4个好人”
  - RR/MDR-TB（2014）
    - ①短程（首选）：9~12个月“就要儿子”
    - ②长程：≥4种抗结核药、18~20个月“180的20个儿子”、首选A组药利奈唑胺、贝达喹啉、左氧氟沙星/莫西沙星“你来北大散心吗”
