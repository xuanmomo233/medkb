# 心律失常

> 考频：内科含诊断 心律失常（1~3题★★★★）｜学科：内科学

<!-- page_134 -->


（左图：心电图波形示意图，标注 P 波、PR 段、QRS 波群、ST 段、T 波、U 波、PR 间期、QT 间期）

- **心率和心律** → RR 间距 < 3 个大格（心室率 > 100）、RR 间距 > 5 个大格（心室率 < 60）“小三大五”；房颤：RR 间距绝对不等（心律绝对不规则）
- **P 波**
  - 窦性 P 波：Ⅱ导联直立、aVR 导联倒置
  - 房早：提早出现 P'波
    交界早“双向奔赴”：逆行 P'波（可在提早出现的 QRS 波前、中、后）

## 教材校注（人卫第10版摘要）

- 心律失常指心脏冲动频率、节律、起源部位、传导速度或激动次序异常；可按发生部位分为室上性与室性，也可从冲动形成和传导异常理解机制。
- 心电图需结合病史、发作特点和血流动力学状态判读；快速心律失常造成血流动力学不稳定时应及时电治疗，室颤/室扑采用非同步除颤，同步电复律用于可识别R波的快速异位心律失常。
    阵发性室上速：逆行 P'波或无 P 波（2018）
  - 房扑：规则 F 波、固定比或不固定比下传（2018）
    房颤：不规则 f 波（350~600 次/分）、不固定比下传（2019）
  - 右心房大：肺型/高尖 P 波（≥ 0.25mV）
    左心房大：二尖瓣型/双峰 P 波（> 0.12s）
  - 窦性停搏：长 PP 间距与正常 PP 间距无倍数关系
    二度Ⅱ型窦房阻滞：长 PP 间距与正常 PP 间距有倍数关系
- **QRS 波**
  - 宽大畸形（≥ 0.12s）
    - 预激综合征：起始部粗钝（δ波）、后 ST-T 继发性改变（2021、2026）（但顺向型房室折返性心动过速 QRS 波多正常）
    - 室早：提早出现宽大畸形 QRS 波、前无 P 波、后 ST-T 继发性改变、完全性代偿间隙“前无 P 后倒 T”
    - 室速（连续 ≥ 3 个室早）—— 特征：心室夺获、室性融合波
    - 室性逸搏及逸搏心律
    - 室内差异性传导
    - 完全变形：室扑（正弦波）、室颤
  - 高大 QRS 波 → 右心室大：RV1+SV5 ≥ 1.05mV、电轴右偏、顺钟向转位（V5 R/S ≤ 1）；左心室大：RV5+SV1 ≥ 4/3.5mV、电轴左偏、ST 段可压低
  - M 型 QRS 波 → 右束支阻滞：V1、V2 导联（常见）；左束支阻滞：V5、V6 导联
  - 病理 Q → 急性 ST 段抬高型心梗、急性心肌炎、扩张型心肌病、肥厚型心肌病等

- **QRS 波**
  - P 波后 QRS 波脱落
    - 二度Ⅰ型房室阻滞 → PR 间期进行性延长、RR 间期进行性缩短（PR 增量减小）直到一次 QRS 波脱落、受阻 P 波前的 PR 间期延长；包含受阻 P 波在内的 RR 间期 < 2 倍正常 PP 间期；最常见房室传导比 3:2 或 5:4，S1 逐渐减弱和心搏脱落（2008）
    - 二度Ⅱ型房室阻滞（2012）→ PR 间期基本恒定（正常或延长）；部分 P 波后无 QRS 波，S1 基本恒定伴间歇性心搏脱落
    - 三度/完全房室阻滞（如强心苷中毒、高钾血症、急性下壁心梗、急性心肌炎）→ S1 变化不定呈大炮音“三大炮”（2008）；阻滞在希氏束或以上：一般心室率 40~60、QRS 波形态正常、心律稳定；阻滞在希氏束以下：一般心室率 < 40、QRS 波宽大畸形、心律不稳定
- **PR 间期**
  - \> 0.2s → 房室阻滞（其中一度无 QRS 波脱落）
  - < 0.12s → 预激综合征（2021）、交界早（P'R 间期）
  - PR 间期不固定→房室分离 → 室速：心室率明显 > 心房率；三度房室阻滞：心房率 > 心室率；生理性干扰
- **ST 段**
  - 压低 ≥ 0.1mV（心内膜缺血损伤）→ 心绞痛：暂时；急性非 ST 段抬高型心梗
  - 抬高 → 变异型心绞痛：暂时；急性 ST 段抬高型心梗；急性心包炎：弓背向下（除 aVR 和 V1 导联外）；急性心梗并发室壁瘤：持续
  - 鱼钩样改变 → 洋地黄效应等
- **T 波**
  - 倒置 → 冠心病、预激综合征（2021）、某些室性心律失常
  - 高耸 → 急性心梗超急性期、高钾血症
- **U 波**
  - 明显 → 低钾血症；尖端扭转型室速：QT 间期延长，补镁治疗
- **多无须治疗（2012、2016）** → “小场面”（偶发、无症状等）
- **快速型/血压低（休克）→ 电击**
  - R 波存在 → 同步直流电复律
  - R 波不存在 → 非同步直流电复律/除颤（室扑室颤）
  - 已用强心苷禁止电复律

- **严重缓慢型：起搏器（2023、2024）**
  - VDD：窦房结功能正常 + 严重房室阻滞
  - DDD：病窦 + 严重房室阻滞
  - AAI：病窦 + 房室传导正常
  - （慢性房颤不用 AAI、DDD）
- **血压正常→用药**
  - **yyds**
    - β-R 拮抗剂（Ⅱ）→ 房扑房颤（控心率首选）、阵发性室上速等
    - 胺碘酮（Ⅲ，2007、2014、2018）→ 房扑房颤、阵发性室上速、急性心梗所致室早室速等
  - **室早** → 器质性心脏病、低钾血症、强心苷中毒等（2018、2025）
  - **阵发性室上速（2025）**
    - 心电生理检查最佳：慢快型房室结折返（多由房早触发）
    - 突发突止、心率一般 160~250 次/分、心律绝对规则
    - 刺激迷走神经（按摩一侧颈动脉窦、Valsalva 等）无效首选腺苷，次选维拉帕米、地尔硫卓等，有收缩性心衰用强心苷
    - 预激综合征伴室上速禁用强心苷
  - **房颤“怕栓怕快”（2010、2026）**
    - 病因：二狭、甲亢等（2011、2020）
    - 体征（2010、2012、2019、2020）→ 心律绝对不齐、S1 强弱不等、脉搏短绌（P < 心率）听不到 S4、二狭心尖舒张晚期杂音可消失
    - 根治：导管消融（2023）
    - 长期抗凝（2017、2018）
      - 有瓣膜病 → 华法林（维持 INR 在 2~3）“林 123”
      - 无瓣膜病 → CHA2DS2-VASc：男 0 分或女 1 分不抗凝（心衰、高血压、≥ 75 岁、糖尿病、脑卒中/栓塞/TIA、血管疾病、65~74 岁、女）达比加群、利伐沙班，左心耳封堵（HAS-BLED ≥ 3 分）
    - 控心率（2009）→ β-R 拮抗剂（首选）、非二氢吡啶 CCB、强心苷等；强心苷用药史 + 心律规则 + 心室率慢 → 三度房室阻滞
    - 转复并维持窦性心律（2013）→ 导管消融、胺碘酮、普罗帕酮、伊布利特等；若房颤持续 > 48 小时：抗凝 3 周/肝素紧急/TEE - 转复 - 抗凝 4 周（直接转复可致脑栓塞、肠系膜上动脉栓塞等）
    - 预激综合征伴房颤 → ①首选电复律，或伊布利特、普罗帕酮“普通的伊布”；②禁用强心苷、维拉帕米、地尔硫卓、β-R 拮抗剂、胺碘酮
