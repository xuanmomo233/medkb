# 心律失常

> 考频：内科含诊断 心律失常（1~3题★★★★）｜学科：内科学

<!-- page_134 -->

（左图：心电图波形示意图，标注 P 波、PR 段、QRS 波群、ST 段、T 波、U 波、PR 间期、QT 间期）

- **心率和心律** → 标准走纸速度 25 mm/s、心律规则时，每个大格为 0.2 秒，心率 = 60/RR 秒数 = 300/RR 大格数；因此 RR 间距 < 3 个大格对应心室率 > 100 次/分，> 5 个大格对应 < 60 次/分。“小三大五”是依据教材图示与公式推算的记忆法，不是教材原文；心律不规则时不能用单个 RR 代表平均心率。房颤：RR 间距绝对不等（心律绝对不规则）
- **P 波**
  - 窦性 P 波：Ⅰ、Ⅱ、aVF、V4~V6 导联向上，aVR 导联向下；其余导联可呈双向、倒置或低平，不能把所有导联的 P 波都要求为直立。
  - 房早：提早出现 P'波
    房室交界性期前收缩的逆行 P′ 波可位于 QRS 波之前（PR 间期 < 0.12 秒）、QRS 波之中或之后（RP 间期 < 0.20 秒）；“双向奔赴”仅为记忆线索

    阵发性室上速：逆行 P'波或无 P 波（2018）
  - 房扑：规则 F 波、固定比或不固定比下传（2018）；明确将有症状且抗心律失常药物治疗无效的室上速（包括房扑）列为导管消融适应证
    房颤：不规则 f 波（350~600 次/分）、不固定比下传（2019）
    - 典型预激/WPW 的心电特征包括 PR < 0.12 秒、QRS ≥ 0.12 秒、起始部预激波（δ波）及继发性 ST-T 改变；预激程度影响形态与时限，少数患者 QRS 可 < 0.12 秒（2021、2026）。顺向型房室折返性心动过速发作时 QRS 形态通常正常；极少数合并束支阻滞或室内差异性传导时也可呈宽 QRS，不能把“通常正常”当作排除所有宽 QRS 发作的规则。
    - 室早：提早出现宽大畸形 QRS 波，时限常超过 0.12 秒，T 波方向与 QRS 主波相反；其后可出现完全性代偿间歇，但间位性（插入性）室早可无其后停顿。应综合判读，不能把完全代偿间歇等特征当作每例必有。原导图口诀拆分：“后倒 T”若指 T 波与 QRS 主波方向相反，由直接支持；“前无 P 波”未由明确列为室早的普遍特征，且第208页图示不能扩写为所有室早的必要条件；“前无 P 后倒 T”及“前无 P 波、后 ST-T 继发性改变”作为完整诊断组合仍属线索。
    - 二度Ⅰ型房室阻滞（文氏阻滞）→ P 波规律出现，PR 间期逐渐延长，直至 P 波下传受阻、脱漏 1 个 QRS 波群；最常见房室传导比例为 3:2 和 5:4；S1 强度逐渐减弱并有心搏脱漏（2008）。
    - 二度Ⅱ型房室阻滞（2012）→ PR 间期恒定，部分 P 波后无 QRS 波群；S1 强度恒定，伴间歇性心搏脱漏。
    - 三度/完全房室阻滞 → P 波与 QRS 波群各自成节律、互不相关，心房率快于心室率；S1 强度经常变化，间或出现响亮亢进的第一心音（大炮音），“三大炮”为记忆口诀，不表示每次心搏均有大炮音（2008）。
  - < 0.12s → 预激综合征（2021）、交界早（P'R 间期）
  - 倒置 → 冠心病、预激综合征（2021）、某些室性心律失常（不能背书冠心病、预激或整组病种对应）
- **是否无需药物治疗须限定病情（2012、2016）** → “小场面”为原导图记忆提示：无器质性心脏病且无明显症状或症状轻微的室早可不予药物治疗；无器质性心脏病的非持续性室速在无症状、无血流动力学影响时可按室早处理。持续性室速均需治疗，不能只凭“偶发、无症状”一概不处理。
- **严重缓慢型：起搏器（2023、2024）**
    - β-R 拮抗剂（Ⅱ）→ 房颤控心室率药物之一（#2135）；题库口诀并列“房扑房颤”的房扑部分为线索，p203该段仅支持房颤，不外推至房扑；阵发性室上速等另按具体药物表和禁忌边界核对。
    - 胺碘酮（Ⅲ，2007、2014、2018）→ 房扑房颤、阵发性室上速（适用边界见下）；室性快速性心律失常中的应用须按具体类型判断，教材药物表中单形或多形室速的相应条件为血流动力学稳定且无 QT 延长，不能扩展为尖端扭转型室速也适用。
  - **室早的病因与诱因线索（2018、2025）** → 可见于器质性心脏病，也可见于心脏结构、功能正常者；电解质紊乱及洋地黄类等药物因素需结合病情评估，急性缺血时需纠正低钾、低镁。原导图“强心苷中毒”作为室早病因的具体断言仍****：第208页“药物因素”不等同于中毒，第209页明确列洋地黄中毒的是室速病因，不能移作室早的逐句证据。
  - **阵发性室上速（2025）**
  - **房颤“怕栓怕快”（2010、2026）**
    - 病因：二狭、甲亢等（2011、2020；未具体限定二尖瓣狭窄，也不支持年份或病因排序）
    - 体征（2010、2012、2019、2020）→ 心律绝对不齐、S1 强弱不等、脉搏短绌（P < 心率）；“听不到 S4、二狭心尖舒张晚期杂音可消失”
    - 长期抗凝（2017、2018）
    - 控心率（2009）→ β-R 拮抗剂、非二氢吡啶 CCB、强心苷及部分抗心律失常药物均是选项，不能概括为所有病人的统一首选。无症状且左室收缩功能正常者静息心室率目标 <110 次/分；症状明显或心动过速性心肌病者目标为静息 <80 次/分、中等运动 <110 次/分。射血分数下降型心衰优先 β-R 拮抗剂，控制不达标或有禁忌时再考虑强心苷和/或胺碘酮。强心苷中毒可致心律失常，但单凭“曾用强心苷”不能诊断三度房室阻滞。
    - 转复并维持窦性心律（2013）→ 药物复律、电复律或导管消融；药物主要为Ⅰc类（普罗帕酮）及Ⅲ类（胺碘酮、伊布利特、决奈达隆、索他洛尔），须结合有无器质性心脏病选择。持续 >48 小时者复律前抗凝 3 周，或经食管超声排除心房血栓后复律，复律后继续抗凝 4 周；紧急复律可用肝素或低分子肝素抗凝。
