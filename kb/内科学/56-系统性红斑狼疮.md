# 系统性红斑狼疮

> 考频：内科含诊断·系统性红斑狼疮（92题★★★★）｜学科：内科学

<!-- page_181 -->


- **自身抗体**
  - 抗核抗体谱（2007）
    - dsDNA（标记）：确诊和判断活动性最佳，狼疮肾
    - ANA：筛查
    - 与活动性无关 "ASSS"
    - ENA "血沉ESR"（2016）
      - Sm（标记）：早期或不典型者诊断（特异性最高 "绑起来最特别"）
      - SSA：继发干燥综合征、平滑肌受累、光过敏、皮损、白细胞↓、血管炎、新生儿狼疮 "平滑干光白眼狼"（2009）
      - SSB：继发干燥综合征
      - RNP：雷诺现象、肺动脉高压 "混混人品被高空摩击"
      - rRNP：神经精神狼疮（2014）
  - 抗磷脂抗体 "没狼心瓜皮哎、血栓流产"
    - 抗心磷脂抗体、狼疮抗凝物（梅毒血清试验假阳性）、抗β₂糖蛋白抗体/β₂-GPI（2007、2025）
    - 血管血栓形成（可发生在所有血管）、习惯性自发性流产、血小板↓（2011、2022、2023）
  - 抗组织细胞抗体
    - 抗红细胞抗体（Coombs试验，2010）、抗血小板抗体、抗神经元抗体
    - 活动期可伴一系或全血细胞↓、网织红↑
  - 可有 RF、ANCA
- **诊断标准**　（青年女性多见 + 发热 + 多系统损害（2013、2024））
  - "咏狼：脸上长斑口腔烂　浆膜关节会发炎　脱发贫血有癫痫　主要死因肾病变　ANA筛阳互补ds Sm磷脂"（2007、2018、2022）
  - ①皮肤狼疮：皮疹（鼻梁和双颧颊部蝶形红斑、盘状红斑等）
  - ②口腔或鼻咽部溃疡（一般不痛）
  - ③浆膜炎
  - ④滑膜炎：非侵蚀性关节炎
  - ⑤脱发
  - ⑥一系或全血细胞↓
  - ⑦NPLE：癫痫、精神异常等
  - ⑧肾：蛋白尿或红细胞管型
  - ⑨ANA、抗dsDNA、抗Sm、抗磷脂抗体、低补体、Coombs试验
- **治疗（2024）**
  - 糖皮质激素 + 环磷酰胺或吗替麦考酚酯（急性危重型如严重急进性肾炎、中枢神经损害、溶血性贫血、血小板减少性紫癜用大剂量甲泼尼龙冲击疗法）
  - 羟氯喹：背景/基础治疗 "羟基"
