# 急性白血病

> 考频：内科含诊断·急性白血病（0~3题★★★）｜学科：内科学

<!-- page_167 -->


- 贫血出血或发热（2014）、胸骨压痛（2022）、肝脾肿大
- 可能可能最可能

- **AML**
  - Auer 小体 "非淋非 0"（2015）、酶（MPO/POX、NSE）、CD13/33 等
  - 治疗（除 M3）
    - IA、DA、HA "买益达哈"（2025）
    - 高三尖杉酯碱只治疗 AML
  - 急粒部分分化 M2（2018、2020）
    - 骨髓原粒细胞 30%~89%
    - t(8;21)(q22;q22) → RUNX1-RUNX1T1（AML-ETO）"Ph 染色体 -1，找 2"
    - 最易绿色瘤
    - MPO/POX(-)~(+)、NSE(-)~(+)
  - 急早幼粒 M3/APL "等差数列漂亮"
    - t(15;17)(q22;q12) → PML-RARA → 全反式维甲酸 + 砷剂 + 蒽环类药
    - 最易 DIC（2016）
    - MPO/POX 强(+)、NSE(-)~(+)、成堆 Auer 小体 "三喜球"（2016）
    - CD13/33/117、9，不表达 CD34 和 HLA-DR "海澜之家男人的衣柜不是早幼粒衣柜"（2007、2016）
    - NAP↓（2009）
  - 急单 M5（2025）
    - 骨髓各阶段单核细胞 ≥ 80% "五八同域"
    - 最易牙龈增生肿胀和皮肤紫蓝色结节 "2 绿 3D 我是鸭皮"（2023、2025）
    - MPO/POX(-)~(+)、NSE(+) 且 NaF 抑制(+) "S 医我服了"
    - CD14 "单身要死"
  - 急巨核 M7 → 血小板 GP、CD41/61 "巨鸡死了"

- **ALL（儿童多见）**
  - 糖原染色 PAS(+) 且成块或粗颗粒状 "吉林吃汤圆"（2013）、NAP↑
  - 治疗
    - VP、DVP、DVLP "儿童 VIP"（2013）
    - 左旋门冬酰胺酶只治疗 ALL
  - L1：小细胞（≤12）"幺儿-儿童急淋"
  - L2：大细胞（＞12）
  - L3/Burkitt 型：大细胞（＞12）、明显空泡 "三大炮"
  - 最易淋巴结肿大（多无痛，2022）
    - NK 细胞：CD16/56
    - B 细胞：CD10/19/20/79a 等
    - T 细胞：CD ≤ 10 等，纵隔淋巴结肿大

- 化疗缓解期易并发（2007、2011）

| 中枢白血病（最常见髓外浸润部位） | 睾丸白血病（次常见髓外浸润部位） |
| --- | --- |
| 头痛呕吐 | 多为一侧无痛性肿大 |
| 鞘内注射甲氨蝶呤等 | 双侧睾丸局部放疗等 |

- **检查（2022）**
  - 发现急性白血病的线索 → Hb 和血小板↓而白细胞↑（也可全血细胞↓）
  - 确诊急性白血病的关键 → 骨髓穿刺细胞学检查：多增生活跃；原始细胞 ≥ 30%（FAB）或 ≥ 20%（WHO）"H3、H-II"
