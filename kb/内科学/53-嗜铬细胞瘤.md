# 嗜铬细胞瘤

> 考频：嗜铬细胞瘤（0~3题★★☆）｜学科：内科学

<!-- page_178 -->

- **90%**
  - 90%发生在肾上腺髓质（其次为腹主动脉旁，2008）
  - 90%呈散发性（主要分泌去甲肾上腺素，2025）
  - 90%为良性肿瘤（可治愈）
- **阵发性高血压** "乱七八糟"、心悸、多汗、头痛、便秘
  - 可能可能最可能（2015、2018）
- **其他激素**
  - ①生长抑素、阿片肽→便秘
  - ②血清素、胃动素、血管活性肠肽→腹泻 "腹泻清胃肠"
  - ③神经肽Y →血管收缩、面部苍白 "Y-white"
  - ④P物质、舒血管肠肽、肾上腺髓质素→血管舒张、面部潮红、低血压 "放屁舒服随后脸红"
- **检查**
  - 发作期：血、尿儿茶酚胺及其代谢物
  - 间歇期：胰高血糖素激发试验
  - 肿瘤定位：影像学（2018）
- **手术**（2007）
  - β-R拮抗剂 "三不"：不常规用、不单独用、不会先用
  - 术前：常规用α-R拮抗剂（酚苄明、XX唑嗪，2018）
  - 术中：若急骤血压升高→酚妥拉明（首选）或硝普钠控制在160/100
