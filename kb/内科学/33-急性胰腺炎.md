# 急性胰腺炎

> 考频：内科+外科 急性胰腺炎（1~4题★★★★）｜学科：内科学

<!-- page_150 -->


病因：胆石症（我国最常见）、饮酒、ERCP、房颤、糖皮质激素等
暴饮暴食突发上腹偏左痛、向左肩及腰背放射、呕吐不减轻、弯腰抱膝减轻
血淀粉酶/脂肪酶↑（重症者可↑、正常、↓）
（内 2008、2010、2012、2022，外 2008、2009、2014、2015、2016、2021、2023、2024、2026）

| | 水肿型（多见） | 出血坏死型 |
|---|---|---|
| 渗出 | 无或轻度局限<br>腹膜刺激征 | 可有明显广泛腹膜刺激征<br>明显腹胀、肠鸣音↓↓、移动性浊音 |
| 出血 | 无 | 血性腹水、G-T 征或 Cullen 征（脐周，外 2024） |
| 发热 | 无或轻 | 持续 |
| 血 WBC↑ | 无或轻 | 明显 |
| 并发胰腺感染 | | T＞38.5℃、血 WBC＞16、ANC 或 WON 气泡征 |
| 全身并发症 | 无 | 休克、SIRS、ARDS、AKI 等<br>ACS：≥20 诊断、≥25 手术（外 2013、2016、2017） |

- **上腹触及囊性包块**
  - 假性囊肿：病程 1 个月左右（纤维增生包裹均匀液性密度）；＞6cm 等保守治疗待 6~8 周→引流术（如囊肿空肠 R-Y 吻合等内引流）（外 2009、2010、2011、2014）
  - 包裹性坏死：纤维增生包裹不均匀混杂密度
- **检查**
  - **诊断首选：血淀粉酶**（内 2008、2010、2011、2022、2023　外 2022）
    - 与诊断准确率有关、与严重程度无关
    - 血淀粉酶升高最早、持续最短（血脂肪酶适合发病 1 周血淀粉酶已恢复者）
  - **与严重程度有关（外 2018）**
    - 诊断重症胰腺炎最佳：腹水淀粉酶（内 2012）
    - 血钙常＜2、血糖（后期）常＞11.1、血 WBC＞16 等（内 2024）
    - **CT**
      - 诊断最佳影像学（外 2009、2016）
      - 明确坏死程度、并发症、决定手术方案最佳（外 2015）
      - 胰腺增大、边界不清、胰周积液；胰腺不规则液性低密度区（胰腺坏死）、不均匀强化

<!-- page_151 -->


- **去除病因、控制炎症、抑制胰液、维持肠道、防治感染**
  - 【即使重症胰腺炎应尽可能内科及微创治疗】
    - 最基本：禁食补液、胃肠减压
      （内 2010、2012、2015、2022，外 2014、2016、2018、2021）
    - 生长抑素/奥曲肽、加贝酯（抑制胰酶活性）、奥美拉唑或西咪替丁
      肠功能恢复后尽早肠内营养：鼻-空肠管、空肠造瘘
      谷氨酰胺（保护肠粘膜屏障）
    - 胰腺坏死＞30% 可预防性静注碳青霉烯类（培南）
      降阶梯：碳青霉烯类、三代头孢/喹诺酮类+甲硝唑
      坏死组织清除和外引流术（外 2008、2017、2025）
- **对比**
  - 高脂血症与急性胰腺炎互为因果
  - 高钙血症是急性胰腺炎病因之一，低钙血症是急性胰腺炎结果之一
  - ERCP 可致急性胰腺炎（外 2010、2012）
    胆总管下端结石嵌顿致梗阻（胆总管扩张＞1cm）或胆道感染尽早 EST+取石+ENBD（外 2017、2025）
  - 诊断胰腺炎的影像检查：CT 最佳、B 超首选（外 2014）
  - 《内科》：禁用吗啡（内 2012，外 2023）、阿托品
    《外科》：可用阿托品
  - 急性胰腺炎抑制胰酶，慢性胰腺炎补充胰酶（得每通）
