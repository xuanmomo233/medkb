# 淋巴瘤

> 考频：淋巴瘤（0~3题★★★）｜学科：内科学

<!-- page_169 -->

- **治疗（2012）**
  - NHL → 化疗为主（CHOP）；胃 MALT 还需抗 Hp
  - HL → Ⅰ、Ⅱ期：化疗+放疗；Ⅲ、Ⅳ期：化疗为主（ABVD）"hello everybody"（2019）
  - （以上）CD20：加用利妥昔单抗 "二美丽"

- **分期 "1 是 1、同是 2、对是 3"（2010、2014、2019）**
  - 发热＞38℃、盗汗、6 个月内体重下降＞10% 任意之一 → B 组 "淋-盗汗、巴-38、瘤-石榴-6 个月"
  - Ⅰ期 → 1 组淋巴结
  - Ⅱ期 → 膈肌同侧 ≥ 2 组淋巴结（如两侧颈部各有多个淋巴结受累-2 组淋巴结）
  - Ⅲ期 → 膈肌上下组淋巴结 → 可累及脾 IIIS（查体触及或影像）
  - Ⅳ期 → 骨髓（骨髓穿刺）、或肝（影像或病理）；1 个结外器官多部、或非区域淋巴结（如胸水）；多个结外器官（如剖腹探查见胃与胰头及腹膜粘连）

进行性、无痛性淋巴结肿大，淋巴结活检确诊（2017）

| | HL | NHL |
| --- | --- | --- |
| 发病率 | 低 | 高 |
| 首发部位 | 淋巴结（颈部淋巴结最常见） | 2/3 淋巴结、1/3 结外器官组织（累及胃肠道时以回肠最多） |
| 淋巴结扩散 | 由近及远向周围淋巴结扩散 | 可呈跳跃性 |
| 向白血病转化 | 无 | 有 |
| 预后 | 好 | 差 |
