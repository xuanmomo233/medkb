# 溶血性贫血

> 考频：内科含诊断·溶血性贫血（0~3题★★★）｜学科：内科学

<!-- page_161 -->


- **分类**
  - 红细胞自身异常（2011）
    - 膜
      - 遗传性球形红细胞增多症
      - 阵发性睡眠性血红蛋白尿 PNH（获得性）
    - 酶（遗传性）
      - 糖酵解丙酮酸激酶缺乏症
      - 磷酸戊糖途径 G6PD 缺乏症 → 既可血管内、也可血管外溶血 "脸皮厚"
    - 珠蛋白（遗传性）
      - 结构：镰刀形 → 既可血管内、也可血管外溶血 "脸皮厚"
      - 数量：地中海贫血
  - 红细胞外部异常
    - 免疫：自身免疫（自免溶、SLE、病毒、药物）、同种免疫（血型不合输血、新生儿溶血）
    - 血管
      - 微血管病：TTP/HUS、DIC、败血症
      - 瓣膜病：钙化性主动脉瓣狭窄、人工心脏瓣膜
      - 血管壁受反复挤压：行军性血红蛋白尿
    - 生物
    - 理化

血管外溶血主要在脾脏，也可在骨髓（原位溶血：巨幼贫、MDS、β-地中海贫血 "BYD"，2007、2023）

| | 血管内溶血 | 血管外溶血 |
| --- | --- | --- |
| 栗子（2010） | 冷抗体型自免溶、蚕豆病、PNH、血型不合输血、输低渗液 "冷豆睡叔叔" | 遗传球、地贫、温抗体型自免溶、丙酮酸激酶缺乏症等 |
| 典型表现 | 贫血、血红蛋白尿（酱油浓茶色）、黄疸<br>急性为主：寒战发热、腰痛、AKI<br>慢性：含铁血黄素尿、脾大 | 大多起病慢<br>贫血、黄疸、脾大 |

- **检查（2008、2017）**
  - 骨髓红系增生明显活跃（2013、2023）
    - Ret 明显↑（可达 5%~20%）
    - 粒红比降低或倒置
    - 血涂片见有核红细胞（中晚幼为主），部分含 H-J 小体、Cabot 环
  - 红细胞破坏
    - 血管内溶血（2021）
      - 血结合珠蛋白/触珠蛋白明显↓、血游离 Hb 明显↑、血红蛋白尿、含铁血黄素尿/Rous 试验（慢性）
    - 溶血性黄疸：血 UCB↑、CB/TB＜0.2、胆素原↑（尿粪深）、尿胆红素 -（2015）
    - 红细胞寿命缩短（最可靠）
    - 血涂片见破碎和畸形红细胞↑

- **类型（若为遗传需关注家族史）**

| 类型 | 要点 |
| --- | --- |
| 遗传球 | 血涂片球形细胞↑、渗透脆性↑（0.62%NaCl 开始破裂）。切脾（≥6 岁以避免肺炎链球菌感染的 OPSI，2019） |
| G6PD 缺乏症 | G6PD 活性测定（确诊）、高铁血红蛋白还原试验 MHbRT |
| 珠蛋白生成障碍性贫血（2008） | 血红蛋白电泳 HbEP、异丙醇 "一只小猪游泳"、小细胞低色素（MCHC＜32%）、靶形红细胞 "地中海打靶"。HSCT 根治 |
| 自免溶（2017） | ①温：Coombs（诊断）、可有球形细胞↑。糖皮质激素（首选）、利妥昔单抗、切脾。Evans 综合征即温抗体型自免溶+ITP<br>②冷：冷凝集素。保暖、利妥昔单抗 |
| 阵发性睡眠性血红蛋白尿 PNH（2024） | 慢性起病，晨起酱油尿<br>流式细胞术 FLAER(-) 和 GPI 锚链膜蛋白 CD55/59↓（诊断）、酸溶血 Ham、蔗糖溶血、蛇毒因子溶血、Rous、NAP↓<br>可合并缺铁贫、与再障可相互转化（可全血细胞↓）、可肝静脉血栓形成（死因）<br>治疗：依库珠单抗抑制补体、HSCT 根治<br>"在依衣库打酱油的智障赶紧睡觉、老铁服啦我我就睡觉" |

## 教材校注（人卫第10版摘要）

- 溶血性贫血的判断依据包括红细胞寿命缩短及相应实验室证据，如网织红细胞、间接胆红素、乳酸脱氢酶、结合珠蛋白和外周血涂片等；需进一步区分血管内/外溶血及获得性/遗传性病因。
- 遗传性球形红细胞增多症、G6PD缺乏、珠蛋白生成障碍、自身免疫性溶血和PNH的诊断检查与治疗各不相同，应按病因选择，不应把所有溶血统一按糖皮质激素处理。
