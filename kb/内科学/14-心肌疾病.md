# 心肌疾病

> 考频：心肌疾病（1~3题★★★★）｜学科：内科学

<!-- page_123 -->

- 猝死（肥心病是青年运动猝死最常见的原因）：**ICD 预防**
- 房颤等心律失常、栓塞（附壁血栓脱落）、病理 Q 波、ST 段压低、T 波倒置
- 超声心动图（2009、2012、2018、2023）

| | **肥厚型梗阻性心肌病**（2009、2014、2022） | **扩张型心肌病**（2007、2012、2015、2017、2018、2021、2022） |
|---|---|---|
| 病因 | 常染色体显性遗传（家族史） | 病毒感染致免疫损害、遗传等 |
| 心脏特点 | 心室明显不对称肥厚<br>心室腔变小（左室显著）、左室舒张末压力↑<br>左室流出道梗阻、SAM 征<br>“没血可射” | **大**：各心腔可扩大——左室扩大最早最显著、心界常向两侧扩大<br>**小**：瓣口开放相对减小<br>**薄**：室壁变薄<br>**弱**：心肌收缩能力减弱、室壁运动普遍/弥漫减弱<br>“有血射不出” |
| 临床特点 | 劳力性呼吸困难、胸痛、运动晕厥 | 左心衰（肺淤血水肿）或全心衰 |
| 心脏杂音 | 胸骨左缘 3~4 肋间收缩期杂音，常喷射样<br>杂音↑：强心苷、硝酸酯类、站位、Valsava<br>杂音↓：β-R 拮抗剂、非二氢吡啶 CCB、蹲位卧位“蹲下、躺下”<br>心尖收缩期杂音 | 房室瓣反流：心尖/胸骨左缘 4~5 肋间收缩期杂音 |
| 所致心衰 | 主要是舒张性心衰（E/e' ≥ 15、E/A < 1.2） | 收缩性心衰（LVEF ≤ 40%） |
| 治疗 | β-R 拮抗剂（首选，2009）<br>非二氢吡啶 CCB、丙吡胺、西苯唑啉“BBBB”<br>心肌肌球蛋白抑制剂玛伐凯泰<br>禁用强心苷、硝酸酯类 | 同慢性心衰，首选 β-R 拮抗剂<br>伴快速房颤可用强心苷 |

- 颈静脉怒张等体循环回流障碍，心界不大或稍大，舒张性心衰
- 超声心动图

| | **限制型心肌病** | **缩窄性心包炎** |
|---|---|---|
| 病因 | 淀粉样变等 | 结核、急性非特异性心包炎等 |
| 病理 | 心内膜心肌纤维化 | 心包粘连增厚、钙化 |
| 体征 | 无奇脉（2012） | 可有奇脉、心包叩击音（特点）、负性心尖搏动、室间隔抖动征 |

- **病毒性心肌炎**
  - 过半病人发病前1～3周有发热、全身酸痛、咽痛、呕吐、腹泻等上呼吸道或肠道病毒感染前驱症状；轻者可有胸闷胸痛、心悸气促，重者可出现急性左心衰、肺水肿及心源性休克；心率增快可与体温不平行。第286页另记拟急性冠脉综合征型心电图表现可酷似急性心梗；“钟摆律”，作为题库线索（2021题库年份）。
  - 可能可能可能（2012、2020）
  - 金标准：心肌活检（柯萨奇 B 组病毒等）<br>病理 Q 波、心肌坏死标志物（cTn、CK-MB）↑

- **病毒性心肌炎边界**：支持过半患者1～3周前驱症状、轻者胸闷胸痛/心悸气促、重者急性左心衰/肺水肿/心源性休克、心率增快可与体温不平行，以及拟急性冠脉综合征型心电图酷似急性心梗；不支持“钟摆律”一词或题库年份。
