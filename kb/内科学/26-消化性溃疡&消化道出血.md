## 消化性溃疡 & 消化道出血

- **慢性、周期性/季节性、节律性上腹痛**
- |  | 胃溃疡 | 十二指肠溃疡（更多见） |
  | --- | --- | --- |
  | 节律性 | 餐后痛（进食→疼痛→缓解）（2021、2025） | 饥饿痛（疼痛→进食→缓解）、夜间痛（2011、2021）“青年 12 点容易饿、吃了宵夜就缓解了” |
  | Hp 感染 | √ | √ |
  | 好发年龄 | 中老年 | 青壮年（2014） |
  | 好发部位 | 胃窦小弯侧（胃小弯角切迹） | 球部前壁 |
  | 发病机制 | 屏障功能减弱为主 | 侵袭因素增强为主 |
- **胃镜作为首选、金标准** → 诊断消化性溃疡及并发出血/幽门梗阻/癌变、残胃癌（2011、2013、2014、2025）
- （上消化道出血最常见：消化性溃疡（40%~50%，2021）；上消化道出血次常见：门脉高压食管胃底曲张静脉破裂（20%~25%，2020、2021））
- **并发症**
  - **出血（最常见，2015）**
    - GU-胃小弯，DU-球部后壁（2012）
    - 肠鸣音↑（2008）
    - 粪隐血 -5ml、黑便 -50ml、呕血 -250ml、> 800~1000ml 可休克“一休哥”；呕血或黑便及颜色取决于速度（主要）、量（主要）、部位（2011、2015）
    - 90% 通过保守治疗控制出血 → ①休克：补充血容量（2014）；②未休克（2012、2013、2025）：内镜下仅见血凝块或溃疡不伴血迹：可仅用 PPI；内镜下见活动性动脉出血或裸露血管：PPI + 胃镜
  - **穿孔**
    - GU-胃小弯，DU 急性 - 球部前壁（常见）、DU 慢性 - 球部后壁
    - 突发上腹刀割样剧痛、腹膜刺激征（压痛/反跳痛/肌紧张呈板状腹）、以穿孔处最重（2026）；肠鸣音↓、肝浊音界缩小消失（最有价值体征，2021）；可有移动性浊音、可有转移性右下腹痛（2025）；若上腹触及包块：胃肠内容物被包裹 → 穿刺置管引流（2016）；若发热、右上腹痛、呃逆：膈下脓肿
    - （X 线图：膈肌、新月形游离气体）首选 X 线：膈下新月形游离气体（2017）；腹腔穿刺：抽出黄色浑浊含胆汁食物残渣
    - 首先禁食补液、胃肠减压；饱餐后或弥漫性腹膜炎 → 修补缝合术（争取 8 小时内，2017）

- **并发症**
  - **幽门梗阻（2026）**
    - 餐后很快腹痛、反复呕吐（隔夜酸宿食、不含胆汁）、低钾低氯碱中毒（2024、2026）、胃型和蠕动波、振水音（2026）
    - 首先禁食补液、胃减压和引流、高渗温盐水洗胃；缓解→痉挛或水肿性为主；不缓解→瘢痕性为主→胃大部切除术（术前用抗生素，2016）
  - **癌变**
    - GU-癌变率＜1%（边缘开始），DU-不癌变（2015）
    - GU 患者腹痛不规律、体重↓、保守治疗＞8 周无效（2013）、贫血、粪隐血可持续阳性、胃酸缺乏
    - 手术+化疗（2013）
- **内科治疗**　“无酸无溃疡、无Hp无复发”
  - **抑酸** —— PPI（首选/最佳/维持治疗）；P-CAB；H2-RA
  - **根除 Hp** —— PPI+铋剂+2 种抗生素
  - **保护黏膜** —— 铋剂、铝剂、米索前列醇
  - 预防 NSAIDs 所致消化性溃疡：PPI+米索前列醇（2007、2010）
- **胃大部切除术（2008、2009、2010）**
  - **术后早期并发症**
    - 出血
    - **胃瘫** —— 类似幽门梗阻但含胆汁、无胃蠕动波；禁止手术
    - 胃肠壁缺血坏死、吻合口漏或破裂
    - 十二指肠残端漏或破裂
    - **梗阻（2008、2013、2023）**：出现肠绞窄（腹膜炎）→手术，否则先保守治疗、无效再手术
      - （图示：残胃经吻合口连接输入袢与输出袢，食物与胆汁流向不同）
      - 吻合口梗阻：吐出大量食物
      - 输入袢梗阻：急性完全性：吐出少量食物，吐后不缓解；慢性不完全性：吐出大量胆汁
      - 输出袢梗阻：吐出大量食物+胆汁

| 梗阻类型 | 食物 | 胆汁 | 其他 |
|---|---|---|---|
| 急性完全性输入袢梗阻 | √ | × | 呕吐频繁、少量食物、呕吐后不缓解；闭袢性梗阻易肠绞窄 |
| 慢性不完全性输入袢梗阻 | × | √ | 呕吐大量胆汁、进食半小时左右明显 |
| 输出袢梗阻 | √ | √ | |
| 吻合口梗阻 | √ | × | |

- **胃大部切除术（2008、2009、2010）**　“亲姐爱杨洋”
  - **术后远期并发症**
    - **倾倒综合征**
      - 早期：进食后 30 分钟，低血压、可呕吐
      - 晚期：进食后 2~4 小时，低血糖、不呕吐
      - 低糖和高脂饮食、生长抑素，吻合口 3~4cm　“吻口三思”
    - **碱性反流性胃炎（2012）** —— 反流、烧心、含胆汁、呕吐后不缓解；胃-空肠 R-Y 术
    - **残胃癌** —— ＞5 年
    - 溃疡复发、吻合口溃疡
    - 营养性并发症
- **特殊类型**（多药物治疗差、手术易复发）
  - 胃十二指肠复合溃疡（II 型 GU）
  - **高位溃疡（IV 型 GU）** —— 不易幽门梗阻；NSAIDs；与胃癌类似（中老年、＞2cm、贫血、体重↓、胃酸不高）
  - 巨大溃疡
  - （2009、2018、2019）

| | 幽门管溃疡 | 十二指肠球后溃疡 |
|---|---|---|
| 定义 | III 型 GU“三通管” | 十二指肠 2、3 部 |
| 症状 | 餐后立即疼痛呕吐 | 典型节律性（夜间痛） |
| 幽门梗阻 | 最易 | 不易 |
| 出血 | 易 | 最易 |
| 穿孔 | 易 | 易慢性穿透（背部痛）<br>可致淀粉酶↑、梗阻性黄疸 |

- 儿童期溃疡
- 难治性溃疡

## 教材校注（人卫第10版摘要）

- 消化性溃疡是胃或十二指肠黏膜缺损并穿透黏膜肌层；胃镜用于明确病变部位、评估良恶性及并发症，活动性出血或裸露血管需内镜止血并结合抑酸治疗。
- 消化道出血先按出血部位、循环状态及病因评估；急性期不宜使用可能妨碍后续内镜/介入/手术的钡剂造影，止血治疗按病灶和严重程度选择内镜、介入或手术。
