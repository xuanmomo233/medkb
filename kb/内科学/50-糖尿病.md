- **MODY "young"**（β细胞功能基因缺陷，2024）
  - 发病＜25岁、常染色体显性遗传（#2011）
  - 无酮症倾向、至少5年内不需用胰岛素（#2011）

可有三多一少（多尿、多饮、多食、体重减轻）、视物模糊（屈光度改变）（2024）

| | T1DM 1A（2019） | T2DM（多见） |
|---|---|---|
| 感性认识 | 胰岛素绝对缺乏 | 胰岛素抵抗、β细胞功能缺陷 |
| 机制 | 自身免疫：GADA等 | 复杂 |
| 起病情况 | 青少年患者多起病较急；部分成人起病缓慢（2014；#2232）；“LADA”标签及具体诊断标准待单独追溯 | 可发生于任何年龄，多见成人、常在40岁后起病，且起病隐匿（#2232）；年龄是流行特点，不是分型界值 |
| 主要死因 | 肾病 | 心脑血管疾病 |
| 起病初期 | 多数T1DM患者起病初期需要胰岛素治疗（#2232）；部分初治患者可出现短暂缓解（蜜月期）（#2232）<br>（LADA多数不需胰岛素） | 早期部分患者可仅通过生活方式干预控制血糖，多数患者需在此基础上使用降糖药；随着β细胞分泌功能进行性下降，部分患者需胰岛素控制高血糖但不依赖外源性胰岛素维持生命，病情进展后相当一部分患者需胰岛素控制血糖并维持生命（#2232）。旧速记“多数不需胰岛素”仍。<br>（新诊断T2DM基线HbA1c ≥ 9.0% 或 FPG ≥ 11.1 mmol/L时，可直接采用短期胰岛素强化（#2234）；"911"为记忆口诀） |
| C肽/胰岛素（2014） | C肽定量；原页支持基础胰岛素偏低、糖刺激后分泌曲线低平（2017；#2232） | 原页支持胰岛素分泌模式不定、餐后峰值延迟（#2232） |

- **并发症**
  - 感染：糖尿病患者容易并发各种感染；血糖控制差者更易发生，也更严重（#2012）
  - **急性并发症**（2016）"血压低而尿量多"

- **并发症**
  - 慢性并发症
    - 特异：微血管病变（病史＞10年，2009）
      - 糖尿病肾病
        - 高度特异：结节性肾小球硬化 K-W结节 "gentleman"
        - 终末期可进展为弥漫性肾小球硬化（常见，但特异性较低）
        - 不用糖皮质激素（2010）
      - 糖尿病视网膜病变——"微信摇一摇、先硬后软、二十个异常心；新生命（4-重获新生）、长大、离开父母"
        - NPDR：I 微血管瘤；II 出血、硬性渗出、或棉绒斑；III ≥20个出血点、静脉串珠样、或微血管异常 →重度（#2012）；重度NPDR应尽早全视网膜激光光凝（#2018；2015为考情线索）
        - PDR：IV 新生血管（#2012；2023为考情线索）；V 纤维血管膜；VI 牵拉性视网膜脱离（#2012）；存在威胁视力情况时（如视网膜受牵拉或脱离）宜尽早行玻璃体切割术（#2018）
        - 出现PDR时常伴糖尿病肾脏病（DKD）和神经病变（#2012）；这是原文所述的常见伴随，不代表必然共病
      - 糖尿病心肌病
    - ASCVD——冠心病、脑卒中、大瘢痕肾、动脉硬化闭塞症等
    - 神经系统并发症
      - 中枢神经
      - 周围神经——远端对称多发神经病变：袜/手套式分布，电生理检查神经传导减慢；自主神经：心肌、平滑肌（尿潴留或失禁等）、腺体（2023）
    - 糖尿病足（2011）
- **检查**
  - 确诊标准 "711"——瞬间血浆血糖达标一项（#2013；2014）
    - 三多一少等典型症状＋
    - ①空腹血糖 FPG ≥ 7
    - ②OGTT 2小时 ≥ 11.1
    - ③随机 ≥ 11.1
    - ④HbA1c ≥ 6.5%
  - 平均血糖控制情况
    - 糖化血红蛋白 HbA1c：2~3个月内（2014）；不能反应瞬时血糖水平、不能反应血糖波动情况、不能确定是否发生过低血糖
    - 糖化白蛋白/果糖胺：2~3周内

## 糖尿病——治疗

- 控制目标
  - HbA1c ＜7%、BP＜130/80、BMI＜24
  - LDL-C：合并ASCVD ＜1.4、高风险 ＜1.8、低中危 ＜2.6；首选他汀类，TG＞5.6时先考虑贝特类等以降低急性胰腺炎风险（口诀为记忆线索）
- 胰岛素
  - 适应症（2014、2023）——T1DM、严重糖尿病并发症、手术、妊娠、分娩；T2DM可在生活方式及较大剂量多种降糖药联合后血糖仍未达标时考虑起始胰岛素（#2016）。“HbA1c ≥ 7%”作为所有患者固定阈值
  - T1DM多次注射方案（#2016）：基础胰岛素占全天剂量约40%–60%，其余分配至餐时；每餐前20–30分钟注射短效胰岛素或餐前即刻注射速效类似物，睡前注射中效或长效胰岛素。“3短1长”仅为该方案的记忆概括，不泛化为所有患者的固定处方（2009、2023）
  - 胰岛素替代治疗后早晨空腹血糖仍高的可能原因包括夜间胰岛素剂量不足、黎明现象（夜间血糖控制良好且无低血糖，仅黎明短时间出现高血糖）和Somogyi现象（夜间未察觉低血糖后出现反跳性高血糖）；夜间多次测定血糖有助鉴别（#2016）。
  - （本页未给出3.9～6、4～8点阈值或具体调药动作，2009、2020）：①整个夜间高血糖→夜间胰岛素应用不足→增加夜间胰岛素；②夜间血糖3.9~6 →黎明现象→约4~8点给胰岛素；③夜间血糖＜3.9 →Somogyi效应→减少夜间胰岛素

T2DM治疗路径和降糖方案应依据病情特征及患者偏好、需求等个体化制定；健康生活方式应贯穿糖尿病治疗始终（#2014）

- 不良反应
  - 最易发生低血糖：胰岛素＞磺酰脲类＞格列奈类（2007）
  - 胃肠道不良反应：二甲双胍的主要不良反应为消化道反应，随餐服用、从小剂量开始并逐渐加量可减少；α-糖苷酶抑制剂常见胃肠道反应，从小剂量开始并逐渐加量可减少（#2015）；2007仅作考情记录。
  - 可致体重增加：胰岛素、磺酰脲类、格列奈类、噻唑烷二酮类、西格列他钠（2026）
- 伴随疾病
  - T2DM伴ASCVD——双胍类、SGLT-2i（体重↓）、GLP-1RA司美格鲁肽/度拉糖肽（体重↓）"3个G"
  - 伴心衰、高血压（很高危）、肾病等（2023）——ACEI/ARB
  - 伴房颤——非瓣膜性房颤按CHA₂DS₂-VASc评分评估血栓栓塞风险；合并中重度二尖瓣狭窄或机械瓣置换者无需评分，直接选择华法林抗凝（#3202）
  - 伴急性膀胱炎——糖尿病患者可采用较长疗程，抗感染治疗7天（#3203）
- 昏迷鉴别：HHS、DKA、脑水肿、乳酸酸中毒、低血糖（皮肤湿冷）

- 支持糖尿病诊断标准、无典型症状时复核以及HbA1c和糖化白蛋白所反映的时间范围。原表中“瞬间达标”等口诀只是记忆法。
- 原对照表中的T1DM＜40岁、T2DM＞40岁、HHS＞50岁等年龄切点，尿糖“强阳性”、糖尿病肾病不用糖皮质激素、固定药物排序/体型偏好、旧版个体控制目标，以及超出（#3202）和第503页（#3203）具体适用范围的房颤/膀胱炎处置，当前原页核对范围不能逐项支持；保留为题库或复习线索。DKA补钾早先记录的K＜3.5及K＞5.5数值不由第745页支持，现已按该页规则修订为K＜3.3 mmol/L先补钾、升至3.3 mmol/L后开始胰岛素，以及治疗前血钾高于正常时暂缓补钾。PDR与糖尿病肾脏病及神经病变常见伴随则由支持（#2012），但不应理解为必然共病。，不据此推定知识点年份或口诀内容来自教材。
