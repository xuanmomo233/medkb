# 糖尿病

> 考频：内科含诊断 糖尿病（0~4题★★★）｜学科：内科学

<!-- page_173 -->


- **MODY "young"**（β细胞功能基因缺陷，2024）
  - 发病＜25岁、常染色体显性遗传
  - 无酮症倾向、至少5年内不需用胰岛素

可有三多一少（多尿、多饮、多食、体重减轻）、视物模糊（屈光度改变）（2024）

| | T1DM 1A（2019） | T2DM（多见） |
|---|---|---|
| 感性认识 | 胰岛素绝对缺乏 | 胰岛素抵抗、β细胞功能缺陷 |
| 机制 | 自身免疫：GADA等 | 复杂 |
| 起病情况 | ＜40岁瘦瘦多见（2014）<br>青少年起病急、症状明显<br>成年人起病慢、早期症状不明显（LADA）<br>临床表现变化很大 | ＞40岁胖胖多见<br>起病慢 |
| 主要死因 | 肾病 | 心脑血管疾病 |
| 起病初期 | 多数需胰岛素、可经历蜜月期<br>（LADA多数不需胰岛素） | 多数不需胰岛素<br>（新诊断基线HbA1c ≥ 9% 或 FPG ≥ 11.1 短期给胰岛素 "911"） |
| C肽/胰岛素（2014） | ↓、曲线低平（2017） | 不定、高峰延迟 |

- **并发症**
  - 感染
  - **急性并发症**（2016）"血压低而尿量多"

| | DKA（2016、2019、2025） | HHS（2015） |
|---|---|---|
| 多见于 | T1DM（2014） | ＞50岁 T2DM |
| 糖 | 血糖多11.1~33.3、尿糖强阳性 | 血糖多33.3~66.8、尿糖强阳性 |
| 酮体 | 尿酮强阳性、呼出气烂苹果味 | 尿酮阴性或弱阳性 |
| 酸中毒 | 有，Kussmaul深快呼吸 | 多无 |
| 血浆渗透压 | 正常或轻度↑ | ＞320（最重要，2015） |
| 补液（生理盐水）是关键<br>（2012、2015、2016、2022、2023） | NS+RI →血糖降至13.9 →加G "先盐后糖、医生救我"<br>1~2h内补NS 1000~2000ml | NS+RI →血糖降至16.7 →加G "尿[?]上岸要录取我"<br>24h补液量可达6000~10000ml<br>输NS后若无休克/渗透压＞350/血钠＞155可输低渗液 |
| 胰岛素（2022、2023） | 静注小剂量RI 0.1U/kg·h | 同左（0.05~0.1U/kg·h） |
| 补钾（2017、2022）<br>（RI促进K⁺转入细胞） | K⁺＜3.5 →立即补钾<br>K⁺正常＋尿量＞40 →立即补钾<br>K⁺正常＋尿量＜30 →待尿量增加后补钾 "见尿补钾"<br>K⁺＞5.5 →暂缓补钾 | 同左 |
| 补碱（2022、2023） | pH≤6.9才补，否则Hb和氧亲和力↑、低钾血症（2017）<br>碱中毒、脑脊液酸中毒、脑水肿（慎用甘露醇） | 多不补 |

- **并发症**
  - 慢性并发症
    - 特异：微血管病变（病史＞10年，2009）
      - 糖尿病肾病
        - 最特异：结节性肾小球硬化 K-W结节 "gentleman"
        - 最常见、对肾功能影响最大：弥漫性肾小球硬化
        - 不用糖皮质激素（2010）
      - 糖尿病视网膜病变——"微信摇一摇、先硬后软、二十个异常心；新生命（4-重获新生）、长大、离开父母"
        - NPDR：I 微血管瘤；II 出血、硬性渗出、或棉绒斑；III ≥20个出血点、静脉串珠样、或微血管异常 →重度→光凝（2015）
        - PDR：IV 新生血管（2023）；V 纤维血管膜；VI 牵拉性视网膜脱离 →玻璃体切割术
        - 出现PDR常伴糖肾和神经病变
      - 糖尿病心肌病
    - ASCVD——冠心病、脑卒中、大瘢痕肾、动脉硬化闭塞症等
    - 神经系统并发症
      - 中枢神经
      - 周围神经——远端对称多发神经病变：袜/手套式分布，电生理检查神经传导减慢；自主神经：心肌、平滑肌（尿潴留或失禁等）、腺体（2023）
    - 糖尿病足（2011）
- **检查**
  - 确诊标准 "711"——瞬间血浆血糖达标一项（2014）
    - 三多一少等典型症状＋
    - ①空腹血糖 FPG ≥ 7
    - ②OGTT 2小时 ≥ 11.1
    - ③随机 ≥ 11.1
    - ④HbA1c ≥ 6.5%
  - 平均血糖控制情况
    - 糖化血红蛋白 HbA1c：2~3个月内（2014）；不能反应瞬时血糖水平、不能反应血糖波动情况、不能确定是否发生过低血糖
    - 糖化白蛋白/果糖胺：2~3周内

## 糖尿病——治疗

- 控制目标
  - HbA1c ＜7%、BP＜130/80、BMI＜24
  - LDL-C：未合并ASCVD ＜2.6、合并ASCVD ＜1.8 "爱点肉、一点吧"；首选他汀类（但TG＞5.6先用贝特类以防急性胰腺炎 "我妻贝特"）
- 胰岛素
  - 适应症（2014、2023）——T1DM、T2DM多种方式治疗后HbA1c ≥ 7%、严重糖尿病并发症、手术、妊娠、分娩
  - "3短1长"（2009、2023）——三餐饭前给短效胰岛素或速效胰岛素类似物、睡前给长效胰岛素
  - 早晨空腹血糖仍高（2009、2020）
    - ①整个夜间高血糖→夜间胰岛素应用不足→增加夜间胰岛素
    - ②夜间血糖3.9~6 →黎明现象→约4~8点给胰岛素
    - ③夜间血糖＜3.9 →Somogyi效应→减少夜间胰岛素

T2DM肥胖（BMI ≥ 25）症状不重首选饮食运动疗法、否则首选双胍类

| | 药物 | 机制 | 备注 |
|---|---|---|---|
| 双胍类 | 二甲双胍 | AMPK（GLP-1↑、肝糖原分解↓、肠摄取糖↓等） | T2DM一线和基础药，很适合胖胖、胰岛素抵抗明显者<br>禁用：GFR＜30（可致乳酸酸中毒，2010、2017） |
| GLP-1受体激动剂 | 艾塞那肽 | GLP-1：促胰岛素分泌（2025） | 很适合T2DM胖胖、胰岛素抵抗明显者 |
| DPP-4抑制剂 | 格列汀 | GLP-1：促胰岛素分泌 | T2DM "打屁屁就听话" |
| SGLT-2抑制剂 | 格列净 | 抑制糖在近端小管吸收 "受够了血糖干净" | T2DM "降糖降压降脂等、护肾护心" |
| α-糖苷酶抑制剂 | 阿卡波糖 | 延缓糖在小肠吸收（与食物同服 "阿卡波糖拌饭"） | 很适合T2DM胖胖或餐后高血糖 "糖-固体"（2009） |
| 格列奈类 | 格列奈 | 促胰岛素分泌 | 很适合T2DM瘦瘦或餐后高血糖 "奶-液体"（2013） |
| 磺酰脲类 | 格列XX | 促胰岛素分泌 | 只能用于T2DM瘦瘦<br>格列喹酮在中度肾功能不全也能用（2015） |
| 噻唑烷二酮类 | 格列酮 | PPAR | 很适合T2DM胖胖、胰岛素抵抗明显者<br>禁用：心衰 "心塞" |

- 不良反应
  - 最易发生低血糖：胰岛素＞磺酰脲类＞格列奈类（2007）
  - 易发生胃肠道反应：α-糖苷酶抑制剂、双胍类等（2007）
  - 可致体重增加：胰岛素、磺酰脲类、格列奈类、噻唑烷二酮类、西格列他钠（2026）
- 伴随疾病
  - T2DM伴ASCVD——双胍类、SGLT-2i（体重↓）、GLP-1RA司美格鲁肽/度拉糖肽（体重↓）"3个G"
  - 伴心衰、高血压（很高危）、肾病等（2023）——ACEI/ARB
  - 伴房颤——有瓣膜病→华法林长期抗凝；无瓣膜病→CHA2DS2-VASc评分
  - 伴急性膀胱炎——7日疗程
- 昏迷鉴别：HHS、DKA、脑水肿、乳酸酸中毒、低血糖（皮肤湿冷）
