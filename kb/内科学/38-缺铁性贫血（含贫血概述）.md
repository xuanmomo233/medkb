# 缺铁性贫血（含贫血概述）

> 考频：内科含诊断缺铁性贫血（含贫血概述）（0~4题★★★★）｜学科：内科学

<!-- page_159 -->


- **铁代谢（2013）** —— 2 价铁：吸收（十二指肠及空肠上段）、利用（合成 Hb 等）"xi、li"；3 价铁：运输（血清铁）、储存（铁蛋白和含铁血黄素）"yun、chu"
- **病因（2007、2009、2014、2020、2021）**
  - 铁丢失过多：慢性失血（如月经过多、痔疮、消化性溃疡、胃癌、ITP）、PNH 等
  - 铁摄入不足或需求增加：婴幼儿、青少年、孕妇、哺乳期
  - 铁吸收障碍：A 型胃炎、胃大部切除术后
- **临床表现（2010、2021）**
  - 一般贫血表现：乏力、头晕、心悸、苍白、左心扩大
    【对比：牛肉舌-巨幼贫（2017）】
  - 组织缺铁表现：异食癖、舌乳头萎缩呈镜面舌、P-V 综合征（吞咽困难）、匙状/勺状/反甲、易感染
- **诊断（2009、2014、2020、2022）**
  - 贮存铁耗尽（潜伏期）—— 血清铁蛋白↓（最敏感），骨髓小粒可染铁消失（最可靠），铁粒幼红细胞↓
  - 红细胞内铁缺乏 —— 有上述异常指标
    血清铁和转铁蛋白饱和度↓、总铁结合力↑、sTfR↑（红细胞 Hb 合成）、游离原卟啉 FEP↑、锌原卟啉 ZPP↑
  - 缺铁性贫血 —— 有上述异常指标
    Hb↓、MCV＜80、MCHC＜32%
    【Hb 男＜120、女＜110、孕妇＜100；＞90、60~90、30~59、＜30→轻、中、重、极重度 "三六九等"】
- **治疗（2007）**
  - 首选有机铁（2011）、口服铁
  - 补铁后最先升高：Ret（评价补铁是否有效，2021）
    2 周后 Hb 开始升高、2 月左右恢复正常（2012）
    Hb 正常后继续补铁 4~6 个月、待铁蛋白正常后停药 "仓库"
    "咏铁：网红十日高峰立、血红蛋白 2 周起、2 月正常别着急、半年才能停铁剂"
- **检查**
  - 骨髓 —— 红系增生活跃、核老浆幼，骨髓细胞外铁（骨髓储存铁）和细胞内铁（铁粒幼红细胞）↓
  - 血象
    - 小细胞低色素性贫血：红细胞体积小、中央淡染区扩大
    - 【贫血分类】（2014、2017、2020）

      | | MCV | MCHC | 栗子 |
      |---|---|---|---|
      | 大细胞性 "核" | ＞100 | | 巨幼贫 |
      | 小细胞低色素性 | ＜80 | ＜32%（320g/L）"三年二班跑800米" | 缺铁贫、ITP、地贫、铁粒幼 |
      | 正细胞性 | 80~100 | | 多数溶贫（除地贫/遗传球）、再障、白血病、肾性贫血 |

    - RBC 正常或↓、WBC 多正常、Plt 多正常或↑（严重全血细胞可↓，2021）
      【可有全血细胞↓（2012）】—— 再障、PNH、巨幼贫、MDS、Evans 综合征、SLE、明显脾亢
      少数白血病、淋巴瘤骨髓浸润、骨髓瘤、放化疗
    - Ret 正常或↑ —— 【抓住小宝藏（2016、2019）】

      | Ret 正常值 0.5%~1.5%，判断骨髓红系增生 | |
      |---|---|
      | 明显↑ | 溶血、巨幼贫原位溶血、急性失血 |
      | ↓ | 再障（＜1%、严重＜0.5%）、多数 MDS、白血病 |
      | 正常或↑ | 缺铁贫、巨幼贫：补充原料后迅速↑<br>ITP、少数 MDS |
