# 中毒

> 考频：中毒（1~3题★★★）｜学科：内科学

<!-- page_185 -->


- **中毒表现**
  - ①呼吸：加快（甲醇、水杨酸、刺激性气体）；减慢（吗啡、镇静催眠药）
  - ②瞳孔：扩大（阿托品、莨菪碱）；缩小（毛果芸香碱、新斯的明、有机磷、氨基甲酸酯、吗啡 "相信尔家的小马"）
  - ③皮肤黏膜灼伤痂皮：盐酸（棕色 "严重"）、硝酸（黄色 "小黄人"）、硫酸（黑色 "大黑牛"）
  - ④溶血性贫血和黄疸：硝基苯、苯胺、砷化氢 "小本生意黄了"
  - ⑤止凝血障碍和出血：蛇毒、敌鼠钠、溴敌隆、水杨酸、肝素、双香豆素 "蛇鼠一家亲"
  - ⑥皮肤发绀（亚硝酸、硝基苯、苯胺 "小小笨蛋"），发黄（毒蕈、四氯化碳、鱼胆 "毒死黄鱼"），樱桃红（CO）（2020、2024）
  - ⑦味道：有机磷（蒜 "磷酸"）、酮症酸中毒（烂苹果 "烂了发酸"）、氰化物（苦杏仁 "qin-xin"）（2018、2026）
- **洗胃禁忌**：强腐蚀性毒物、食管静脉曲张、昏迷、惊厥 "石破昏惊"
- **导泻禁用硫酸镁的情况**：肾衰、呼衰、昏迷、磷化锌和 OPI 中毒晚期 "深呼吸，心凌美晕了"
- **血液净化**
  - 血液灌流（最常用）：适合脂溶性、巴比妥类、百草枯等 "灌溉思登"
  - 血浆置换：适合 Goodpasture、急进性肾炎Ⅰ和Ⅲ型、生物毒（蛇/蕈）、砷化氢等 "换肾/生/砷"
  - 血液透析（2016）
    - 适合重铬酸盐、氯酸盐等 "投革履"
    - 禁忌：脂溶性（有机磷、导眠能/格鲁米特、短效的司可巴比妥）"领导/公司格外短浅不要透析"
- **中毒解救**

|  | 解毒药 |
| --- | --- |
| 铅 | 依地酸钙钠 EDTA "乞丐要一地钱"（2010、2017） |

| 吗啡等阿片类 | 纳洛酮 "那里痛"（2017） |

## 有机磷中毒

抑制胆碱酯酶（2008、2012、2015、2018、2019、2022、2025、2026）

|  | 表现 | 胆碱酯酶活力 "生我气喝农药" |
| --- | --- | --- |
| 轻度 | 仅 M 样症状 "小桥流水慢悠悠"（心率↓、视物模糊、针尖样瞳孔、腹痛腹泻、大小便失禁、大汗流泪流涎、肺啰音等） | 50%~70% |
| 中度 | M+N 样症状（肌纤维颤动等） | 30%~50% |
| 重度 | M+N 样症状伴脑水肿、抽搐、昏迷、呼吸肌麻痹、肺水肿之一 "脑 hu 了" | <30% |

- **治疗**
  - 迅速清除毒物和紧急复苏是关键：碳酸氢钠禁用于敌百虫、高锰酸钾禁用于对硫磷（2023）
  - 解毒药
    - 胆碱酯酶复活药：氯解磷定（恢复胆碱酯酶活性、缓解外周 N 样症状）"绿帽子喝农药"
    - 中枢性抗胆碱药：东莨菪碱（缓解中枢症状）"中东"
    - 外周性抗胆碱药：阿托品、山莨菪碱（缓解外周 M 样症状）→ 使用阿托品后（2007、2019）
      - 阿托品化 → 瞳孔扩大、心率↑（90~100）、肺啰音消失、口干、无汗、颜面潮红 "你是我的阿托品"
      - 阿托品中毒 "验尿中" → 瞳孔明显扩大、尿潴留、中枢症状
- ①中间型综合征：中毒后约 1~4 天，胆碱酯酶 <30%（胆碱酯酶复活药用量不足）"易中天"
- ②迟发性多发神经病：症状消失后约 2~3 周，胆碱酯酶活力正常、神经靶酯酶异常 "周星驰把妹 1234"

## 教材校注（人卫第10版摘要）

- 急性中毒救治先评估气道、呼吸、循环并尽早脱离毒源，再依据毒物种类、剂量、途径和时间选择去污、特异解毒剂及支持治疗；洗胃和催吐并非通用措施，存在明确禁忌证。
- 有机磷中毒需识别胆碱能表现并结合胆碱酯酶活性评估；阿托品针对毒蕈碱样效应，胆碱酯酶复活剂用于相应适应证，剂量调整以临床反应为依据并防止阿托品中毒。
