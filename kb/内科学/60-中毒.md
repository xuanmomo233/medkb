# 中毒

> 考频：中毒（1~3题★★★）｜学科：内科学

> **：**本导图保留题库考点、年份和记忆口诀。下列精确页码只支持对应校注列明的内容；未列入原页核验范围的解毒药适应证、血液净化选择及扩展判断仍属线索，不据此认定为教材原文。年份是考情索引，口诀是记忆辅助。

- **中毒表现**
  - ①呼吸：加快（甲醇、水杨酸、刺激性气体）；减慢（吗啡、镇静催眠药）
  - ②瞳孔：扩大（阿托品、莨菪碱，#2032）；缩小（有机磷、氨基甲酸酯，#2032；阿片类中毒可出现昏迷、呼吸抑制和瞳孔缩小“三联征”（#16814）；鉴别诊断所列“OPI”指有机磷杀虫药，不作阿片类出处；毛果芸香碱、新斯的明仍；“相信尔家的小马”仅作记忆线索）
  - ③皮肤黏膜灼伤痂皮：盐酸（棕色 "严重"）、硝酸（黄色 "小黄人"）、硫酸（黑色 "大黑牛"）
  - ④溶血性贫血和黄疸：硝基苯、苯胺、砷化氢 "小本生意黄了"
  - ⑤止凝血障碍和出血：蛇毒、敌鼠钠、溴敌隆、水杨酸、肝素、双香豆素 "蛇鼠一家亲"
  - ⑥皮肤发绀（亚硝酸盐、硝基苯、苯胺；#2032；“小小笨蛋”），发黄（毒蕈、四氯化碳、鱼胆；#2032；“毒死黄鱼”），樱桃红（CO；#2032）（2020、2024）
  - ⑦味道：有机磷（蒜 "磷酸"）、酮症酸中毒（烂苹果 "烂了发酸"）、氰化物（苦杏仁 "qin-xin"）（2018、2026）
- **洗胃禁忌**：强腐蚀性毒物、食管静脉曲张、昏迷、惊厥（#2034） "石破昏惊"
- **导泻禁用硫酸镁的情况**：肾衰、呼衰、昏迷、磷化锌和 OPI 中毒晚期（#2034；“深呼吸，心凌美晕了”仅为记忆提示）
- **血液净化**
  - 血液灌流（#2034）：原页称其为目前最常用的中毒抢救措施，可吸附脂溶性或蛋白结合毒物，并列举可清除巴比妥类、百草枯；“灌溉思登”仅为记忆提示，不外推到其他未列毒物。
  - 血浆置换：急进性肾小球肾炎治疗中，（#2514）明确适用于Ⅰ型和Ⅲ型；Goodpasture综合征在该页列为继发性急进性肾炎，但未被单独列为血浆置换适应证。中毒相关用途见（#2499）：生物毒（蛇/蕈）、砷化氢等 "换肾/生/砷"
  - 血液透析（#2034）（2016）
    - 氯酸盐、重铬酸盐中毒首选血液透析（#2034）"投革履"
    - 短效巴比妥类、格鲁米特和有机磷因脂溶性，一般不进行血液透析（#2034）"领导/公司格外短浅不要透析"
- **中毒解救**

## 有机磷中毒

抑制胆碱酯酶（#2035）（2008、2012、2015、2018、2019、2022、2025、2026）

|  | 表现（#2035） | 胆碱酯酶活力 "生我气喝农药" |
| --- | --- | --- |
| 轻度 | 仅 M 样症状（#2035：瞳孔缩小、腹痛腹泻、大小便失禁、大汗/流泪/流涎、气道分泌物增多，可有咳嗽、气促、呼吸困难及干/湿肺啰音）；“小桥流水慢悠悠”为记忆口诀；心率↓、视物模糊、针尖样描述未见于原页， | 50%~70% |
| 中度 | M+N 样症状（肌纤维颤动等） | 30%~50% |
| 重度 | M+N 样症状伴脑水肿、抽搐、昏迷、呼吸肌麻痹、肺水肿之一 "脑 hu 了" | <30% |

- **治疗**
  - 迅速清除毒物和紧急复苏是关键：碳酸氢钠禁用于敌百虫、高锰酸钾禁用于对硫磷（#2035；洗胃液禁忌仅限相应毒物配对）（2023）
  - 解毒药（#2035）
    - 胆碱酯酶复活药：氯解磷定（恢复胆碱酯酶活性、缓解外周 N 样症状）"绿帽子喝农药"
    - 中枢性抗胆碱药：东莨菪碱（缓解中枢症状）"中东"
    - 外周性抗胆碱药：阿托品、山莨菪碱（缓解外周 M 样症状）→ 使用阿托品后（2007、2019）
      - 阿托品化指征：口干、皮肤干燥、心率增快（90~100次/分）、肺部湿啰音消失；瞳孔明显扩大、神志模糊、烦躁不安、抽搐、昏迷、尿潴留属阿托品中毒，应立即停用阿托品。“无汗、颜面潮红”及口诀“你是我的阿托品”仍。
      - 阿托品中毒 "验尿中" → 瞳孔明显扩大、尿潴留、中枢症状
- ①中间型综合征：急性重度OPI中毒后24～96小时且胆碱酯酶复活药用量不足时可发生；全血/红细胞ChE可低于30%"易中天"
  - ②迟发性多发神经病：急性中、重度OPI中毒症状消失后2～3周可出现；全血/红细胞ChE可正常，可能与神经靶酯酶老化有关"周星驰把妹 1234"

- 支持中毒定义、急慢性分类、毒物进入/代谢/排泄机制及常见临床表现（包括痂皮颜色、瞳孔、特殊气味、呼吸和神经系统表现）；明确记载一氧化碳中毒时皮肤黏膜呈樱桃红色，发绀相关毒物写作亚硝酸盐、苯胺或硝基苯。直接列出阿片类中毒昏迷、呼吸抑制和瞳孔缩小“三联征”；p904鉴别诊断所列“OPI”指有机磷杀虫药，不作为阿片类出处。毛果芸香碱、新斯的明仍。口诀只作记忆线索，不将其中每个并列例子都归为教材逐字原文。
- 导图中的年份和口诀仍作为考情/记忆线索保留，不代表教材原文。铁、镍、铊→去铁胺、铋及其他未列明金属对应、镇静催眠药→高锰酸钾系统解毒剂，以及毛果芸香碱、新斯的明的具体缩瞳对应仍。本次将阿片类中毒“三联征”出处改为并澄清p904的OPI含义；补齐p890的M样症状标记和待追边界，并将亚硝酸改为原页用词“亚硝酸盐”。
