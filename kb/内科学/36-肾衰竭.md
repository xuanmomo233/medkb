# 肾衰竭

> 考频：肾衰竭（0~3题★★★★）｜学科：内科学

<!-- page_154 -->
## 急性肾损伤

- **病因分类**
  - ①肾前性（最常见）：大失血、液体丢失过多、肝硬化、心衰、机械通气等→有效循环血量↓
  - ②肾性（如 ATN）：肾缺血、肾中毒、原尿外漏、肾小管阻塞
  - ③肾后性：尿路梗阻
- **肾前性 AKI 与 ATN 鉴别（2007、2008、2012、2016）**

  | | 肾前性 AKI | ATN |
  |---|---|---|
  | 尿比重 | ＞1.018 | ＜1.012 |
  | 尿渗透压 | ＞500 | ＜250 |
  | 尿肌酐/血肌酐、血尿素氮/血肌酐 | ＞ | ＜ |
  | 尿钠 | ＜10 | ＞20 |
  | 钠排泄分数、肾衰指数 | ＜ | ＞ |
  | 尿沉渣 | 透明管型 | 棕色颗粒管型 |

- **确诊**：GFR（疑诊肾性 AKI 但不能明确病因需活检）
- **进展/维持期** —— 高钾（主要死因）、高镁、高磷、低钙、低钠、低氯
  水中毒、代谢性酸中毒（2009、2016、2022）
  "三高三低两中毒、贾玲美爱吃醋"
- 纠酸时注意防止游离钙降低所致手足抽搐（2018）
- （透析指征）K⁺＞6.5、pH＜7.2
  严重尿毒症（心包炎/脑病/癫痫）
  利尿无效的严重肺水肿（呼吸困难）
  （2020）

## 慢性肾衰竭

- （透析指征）K⁺＞6.5、pH＜7.2
  严重尿毒症（心包炎/脑病/癫痫）
  利尿无效的严重肺水肿（呼吸困难）
  （2020）
- **毒素**：尿素氮（小）、PTH（中）、蛋白质（大）
- 慢性肾炎（我国最常见）、糖尿病肾病（欧美最常见）等病史
  间断水肿、蛋白尿、高血压、贫血（EPO↓）、出血（血小板功能减低）
  最先出现消化系统表现，最主要死因是心衰
  可能可能最可能（2009、2013、2016）
- **ACEI/ARB**：血压＜130/80（若尿白蛋白/肌酐＜30 或透析：血压＜140/90）
- **治疗肾性贫血**：EPO、罗沙司他（模拟 HIF "罗森的番茄沙司"）、铁、叶酸
- **限磷**：不含钙的磷结合剂司维拉姆、碳酸镧
- **骨营养不良（2015、2025）**
  - 高转化性骨病（最常见）—— PTH 过高：骨质疏松、易骨折、骨骼囊样缺损、纤维囊性骨炎
  - 低转化性骨病 —— ①骨再生不良：PTH 相对偏低、成骨因子不足 ②骨软化症：骨化三醇不足、铝中毒
  - 混合性骨病
- **慢性肾脏病分期（2009）**

  | | CKD1 | CKD2/代偿期 | CKD3/失代偿期 | CKD4/肾衰期 | CKD5/尿毒症期 |
  |---|---|---|---|---|---|
  | GFR | ≥90 | 60~89 | 30~59 | 15~29 | ＜15 或透析 |
  | 血 Cr | | ＜177 | ＜442 | ＜707 | ≥707 |

## 教材校注（人卫第10版摘要）

- 急性肾损伤需结合肌酐变化和尿量判断，并按肾前性、肾性、肾后性分析病因；慢性肾衰竭则结合病程、eGFR及并发症评估，不能将两者仅凭一次肌酐结果混为一谈。
- 肾脏替代治疗包括血液透析、腹膜透析和肾移植；启动时机需结合难以纠正的内环境紊乱、容量负荷及尿毒症表现综合决策。
