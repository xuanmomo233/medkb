# DNA损伤

> 考频：DNA损伤（10~11题★☆☆☆☆）｜学科：生物化学

<!-- page_278 -->


- **概述**——DNA 突变：一级结构改变
- **损伤类型举例**（2003）
  - ①碱基损伤与糖基破坏：亚硝胺致脱氨基（C→U，A→I）
  - ②碱基错配：U 替代 T 参入 DNA
  - ③链的断裂：电离辐射
  - ④链的共价交联：紫外线致嘧啶二聚体（1997）
- **碱基置换/点突变**（2002）
  - ①同义突变：摆动性＋简并性
  - ②错义突变：氨基酸置换（镰刀形红细胞贫血 Hb 的 β 链谷氨酸被缬氨酸取代，2010、2014、2015、2016）
  - ③无义突变：终止密码子不编码氨基酸
- **碱基插入或缺失**（2002）
  - ①移码/框移突变（密码子连续性）
  - ②增加或缺失氨基酸
- **损伤修复**（2019）
  - 最简单-直接修复
    - ①光裂合酶/光复活酶修复嘧啶二聚体
    - ②DNA 连接酶修复单链断裂
  - 最普遍-切除修复 “识切补连”（1998、1999）
    - ①碱基切除修复（p53 参与）：糖苷酶识别并去除碱基→AP 核酸内切酶去除磷酸戊糖→DNApol→DNA 连接酶
    - ②核苷酸切除修复（识别损伤对双螺旋造成的扭曲如嘧啶二聚体）：大肠杆菌 Uvr、人 XP 蛋白质、DNApol、DNA 连接酶
    - ③碱基错配修复（特殊的碱基切除修复）
  - 双链断裂-重组修复（2023）
    - ①同源重组修复：RecA、BRCA
    - ②非同源重组修复/末端连接修复：DNA-PK、XRCC4
  - 双链广泛损伤-跨越损伤 DNA 合成
    - ①重组跨越损伤修复：RecA
    - ②合成跨越损伤修复/SOS 修复：DNApol Ⅳ/Ⅴ，活性低、特异性差、出错率高（2013）
  - 缺陷与疾病

    | 缺陷 | 疾病 |
    |---|---|
    | 核苷酸切除修复 | 着色性干皮病 XP、毛发二硫键营养不良症、Cockayne 综合征 |
    | 错配修复 | 遗传性非息肉病性结肠癌 “非错不可霉死了”（2004） |
    | 重组修复 | 遗传性乳腺癌、Bloom 综合征 “重装假体” |
    | 跨越损伤 DNA 合成修复 | Fanconi 贫血 “约饭” |

## 教材校注（人卫第10版摘要）

- DNA损伤可由多种因素导致，类型包括碱基损伤、错配、链断裂及共价交联；修复途径包括直接修复、切除修复、错配修复、同源重组/非同源末端连接及跨越损伤合成等。
- 不同修复途径识别的损伤类型和保真度不同，修复缺陷可增加特定疾病风险。教材定位：第二十一章第一至三节，纸书第403–416页。
- 疾病关联按具体修复缺陷理解，不将口诀当作因果机制。
