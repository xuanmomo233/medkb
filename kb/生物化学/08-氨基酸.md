# 氨基酸

> 考频：氨基酸（0~2题）★★☆☆☆｜学科：生物化学

<!-- page_253 -->


- 无旋光性 → Gly "甘氨酸干净得连旋光性都没有了"
- 亚氨基酸 → Pro "葡萄牙"（2000）
- 非极性 → Val、Ile、Leu、Ala、Gly、Phe、Pro、Met "携一两饼干飞奔复旦：疏水-上岸"（2011）
- 极性
  - 酸性（含2个羧基）：Glu、Asp（1997、2008）→ pI小（生理情况带负电）"小阿姨酸水"
  - 碱性：Lys、Arg、His "捡来金猪"（2004）→ pI大（生理情况带正电，2015）
  - 部分中性
- 支链（骨骼肌代谢）→ Val、Ile、Leu "只借一两"
- 生糖或生酮（1997、2001、2008、2009）
  - ① 生酮兼生糖：Ile、Phe、Tyr、Trp、Thr "一本落色书"
  - ② 生酮：Leu、Lys
  - ③ 生糖
- 不能转氨基 → Pro、Thr、Lys "不服输来"
- 必需（只能从食物获取）（2006、2011、2021）
  - His、Val、Ile、Leu、Phe、Met、Trp、Thr、Lys "猪必需写一两本单色书来"
  - 条件／半必需：Tyr、Arg、Cys "老精光"
- 不组成人体蛋白质（1999、2009）→ 鸟氨酸、瓜氨酸、精氨酸代琥珀酸、同型半胱氨酸 "鸟瓜同性惊呆虎"
- 含硫氨基酸 → 硫酸根（PAPS）（1998、2025、2026）
  - 同型半胱氨酸、Met
  - 胱氨酸：组成蛋白质却无密码子（翻译后加工修饰）
  - Cys（极性最强）
    - → 牛磺酸（1996、2003、2011）
    - 组成谷胱甘肽
      - GSH：由Glu、Cys、Gly组成的三肽（含2个肽键）
      - 特性：还原性、嗜核性、维[?]性、协[?]性 "还是威胁"

<!-- page_254 -->


- **SAM循环**（1996、2017、2022）
  - 提供活性甲基合成：肾上腺素、肌酸、肉碱、胆碱（卵磷脂和神经鞘磷脂）等 "一荤一素一鸡一蛋"
  - 需转甲基酶（辅因子VitB₁₂）
- **芳香族（紫外吸收性质）**（2002）
  - Tyr、Phe、Trp "老本色"
  - 280nm：Tyr、Trp（吸光度最大）
  - 570nm：与茚三酮反应后
- **酪氨酸**（2002、2006、2007、2010、2012、2024）
  - ① → 多巴胺 → NA → Adr
  - ② → 黑色素（缺乏酪氨酸酶致白化病）
  - ③ → 尿黑酸 → 延胡索酸、乙酰乙酸（缺乏尿黑酸氧化酶致尿黑酸尿症）
  - 缺乏苯丙氨酸羟化酶或辅因子四氢生物蝶呤致苯丙酮尿症
- **一碳单位**（1997、1998、1999、2003、2005、2011、2013、2019、2026）
  - 载体：FH₄
  - 意义：参与合成嘌呤核苷酸、胸腺嘧啶核苷酸
  - 来自：Ser、Trp、His、Thr、Gly "施舍竹树竿"

## 教材校注（人卫第10版摘要）

- 蛋白质氨基酸以L-α-氨基酸为主，可按侧链结构与理化性质分类；甘氨酸无手性中心，脯氨酸的侧链与α-氨基相连。必需氨基酸需由膳食提供，教材亦说明氨基酸的两性解离与等电点等性质。教材定位：第一章第一节，纸书第8–12页。
- 分类口诀仅辅助记忆；具体分类以侧链性质和教材定义为准。
