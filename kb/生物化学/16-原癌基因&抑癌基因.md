# 原癌基因&抑癌基因

> 考频：原癌基因&抑癌基因（0~2题★☆☆☆）｜学科：生物化学

<!-- page_266 -->
## 原癌基因 & 抑癌基因

- **原癌基因**
  - 正常存在、高度保守<br>正性调控（促进细胞增殖/生长/分化）<br>分布广泛（在最简单的真核生物单细胞酵母至人类的正常细胞都存在）（2007、2010）
  - 活化为癌基因"元神启动、放傀儡、换位、变其他英雄"（2013）
    - （某些病毒如逆转录病毒携带病毒癌基因）
    - ①获得启动子（起始转录）或增强子（增强启动子的效率）
    - ②染色体易位：原癌基因转位至强的启动子或增强子附近（Burkitt 淋巴瘤）；产生新的融合基因（CML）
    - ③基因扩增：小细胞肺癌 MYC 扩增、乳腺癌 HER2 扩增
    - ④基因突变（点突变最常见）：大肠癌、膀胱癌 RAS 突变
  - 原癌基因产物（2004、2007、2008、2010、2011、2014、2015、2023、2024）

| | |
|---|---|
| 生长因子（肽或蛋白质等） | SIS/PDGF、INT-2/FGF"姐妹上网" |
| 跨膜生长因子受体 | EGFR/HER1/ERBB1、HER2/ERBB2、FMS、KIT、TRK"福尔摩斯跨国杀她三个前女友" |
| 细胞内信号转导分子 | 胞质或核内酪氨酸激酶（SRC、ABL 等），MAPK 通路重要分子（RAS、RAF 等） |
| 转录因子 | FOS、JUN、MYC"狐狸精转变成了母夜叉" |
| 细胞周期调节蛋白 | CYCLIN D |

- **抑癌基因**
  - 失活机制"甲尸变"
    - ①启动子区 CpG 岛甲基化"关紧"
    - ②杂合性丢失（如 RB）
    - ③基因突变（如 P53）
  - P16、P21、P53、APC、PTEN、VHL、WT、NF、DCC、BRCA、RB 等（2007、2010、2012、2024、2025）
    - 突变最广泛 -P53"基因组卫士"编码产物是转录因子（2016、2026）
      - ①阻止细胞通过 G1/S 期检查点（使细胞滞留在 G1 期）
      - ②促进 DNA 损伤修复
      - ③诱导细胞凋亡或老化
    - 最早发现 -RB：高磷酸化 RB（失活）不能和转录因子 E2F 结合→细胞能通过 G1/S 期检查点
    - 双特异磷酸酶活性 -PTEN：水解 PIP3 →抑制 PI3K/AKT 信号通路
  - （"有 P 的多数是抑癌基因，但 PDGF 为原癌基因；有 R 的多数是原癌基因，但 RB、BRCA 为抑癌基因"）
