# 磷酸戊糖途径、糖原、糖异生

> 考频：★★☆☆磷酸戊糖途径、糖原、糖异生（10~2题）｜学科：生物化学

<!-- page_248 -->


（页首横幅：临床医学综合能力（西医）思维导图）

- **磷酸戊糖途径（胞浆）**
  - 起始物：G-6-P（2013、2024）
  - 【G-6-P 脱氢酶】→ 抑制剂：NADPH；缺陷：蚕豆病（2012）
  - 产物（2007）
    - 5-磷酸核糖：糖和核苷酸代谢联系枢纽（2000）
    - NADPH（2015）
      - 还原剂：维持 GSH 还原状态等（2025）
      - 参与生物转化
      - 参与物质代谢“胆汁酸” → 胆固醇的合成、分解；合成胆红素、脂肪酸、氨基酸、神经鞘磷脂、脱氧核苷酸、FH₄ 等
    - CO₂
- **糖原（胞浆）**
  - 合成
    - G → G-6-P → G-1-P → UDPG →糖原（消耗 ATP+UTP，1999、2023）
    - 【糖原合酶】（2017）→ 只能延长直链（α-1,4-糖苷键“直-straight-s-4”）；激活剂：胰岛素（去磷酸化，1996）
  - 分解（1996、2003、2013、2024、2026）

    |  | 肝 | 肌肉 |
    |---|---|---|
    | 糖原→ G-1-P → G-6-P | → G | →无氧氧化（缺乏 G-6-P 酶） |
    | 意义 | 补充血糖（主要是 16 小时内） | 快速为肌肉收缩供能（净生成 3 个 ATP） |
    | 【磷酸化酶】（只能分解直链） | 激活剂：胰高血糖素（磷酸化） | 激活剂：肾上腺素（磷酸化） |

## 糖异生

- **糖异生**
  - 意义（1998）→ 空腹饥饿时肝补充血糖（最主要）、合成糖原（三碳途径）；长期饥饿时肾维持酸碱平衡
  - 原料（2000、2006）
    - 乳酸（→丙酮酸）→ 乳酸/Cori 循环：避免乳酸堆积、酸中毒、损失能量物质
    - 甘油（→3-磷酸甘油→磷酸二羟丙酮）→ 步骤和耗能最少（2001、2011）
    - 氨基酸（除开生酮氨基酸 Leu、Lys“同亮来”）
  - 关键酶“说话说鸡双磷 1、肌肉没有 G6P”（1998、1999、2003、2004、2007、2008、2010、2017、2023、2025）
    - 【丙酮酸羧化酶】（线粒体）→ 辅因子：生物素（VitB₇）“说话说生气呢”；激活剂：乙酰 CoA（主要来自脂肪酸，1997）
    - 【磷酸烯醇式丙酮酸羧激酶】（线粒体、胞浆）
    - 【果糖双磷酸酶-1】（胞浆）→ 抑制剂：F-1,6-DP、F-2,6-DP
    - 【G-6-P 酶】（胞浆）→ 肌肉没有
  - 胰高血糖素（2016）
    - ⊕果糖双磷酸酶-2、磷酸烯醇式丙酮酸羧激酶
    - ⊖磷酸果糖激酶-2、丙酮酸激酶（2016）
