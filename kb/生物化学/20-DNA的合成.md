# DNA的合成

> 考频：DNA的合成（10~22题★★★★☆）｜学科：生物化学

<!-- page_272 -->


- **复制**
  - **复制子**
    - 原核：单复制子（一个复制起始点，2019）
    - 真核：多复制子（解决庞大基因组复制问题，2000、2011、2014）
  - **复制特点**（2001、2006、2015、2019、2020）
    - ①半保留：母链两条链分别作为模板链
    - ②双向：模板 DNA 形成两个延伸方向相反的复制叉
    - ③半不连续：前导链、后随链（冈崎片段）
    - ④高保真性：半保留、复制叉、DNApol（正确选择碱基/核酸外切酶活性/校对功能）、修复系统
  - **DNA 聚合酶**

    | 原核（1996、2001、2009、2011、2019） | 真核（2007、2012、2020、2024） |
    |---|---|
    | DNApol Ⅰ——Klenow：5-3 聚合酶（填补空隙）、3-5 核酸外切酶（错配修复）<br>小片段：5-3 核酸外切酶（切除引物、修复损伤） | DNApol α：引物酶 |
    | DNApol Ⅱ——5-3 聚合酶（应急低保真复制）<br>3-5 核酸外切酶（错配修复） | DNApol β：应急低保真复制、错配修复 |
    | DNApol Ⅲ——5-3 聚合酶（延长子链最主要）<br>3-5 核酸外切酶（错配修复） | DNApol γ：mtDNA 的 D 环复制 “抖音” |
    |  | DNApol δ：延长后随链、错配修复 “δ-后” |
    |  | DNApol ε：延长前导链、错配修复 “ex-前任” |
  - **原核复制过程 “aim、break、company、guide”**（1996、1998、2002、2003、2004、2005、2006、2008、2009、2011、2016、2022、2025、2026）
    - **起始**
      - DnaA 辨认复制起始点（如 oriC 位于 DNA 上富含 AT 的重复序列）
      - 拓扑异构酶解开超螺旋以松弛 DNA 链（水解和连接单链或双链的磷酸二酯键）
      - DnaC 运送协助 DnaB（解旋酶）解开双螺旋/双链/氢键
      - SSB 结合单链 DNA “傻傻逼才单恋”
      - DnaB、DnaC、DnaG（引物酶）和复制起始点组成起始复合物/引发体以合成引物（短链 RNA）提供 3-OH
    - **延长**——同一个 DNApol Ⅲ按 5-3 方向、以四种 dNTP 为原料、将 dNMP 加入引物或延长的子链
    - **终止**
      - DNApol Ⅰ水解引物、并填补空隙 “谁水解谁填补”
      - DNA 连接酶连接单链缺口
  - 真核 DNApol 催化速率比原核生物慢
  - 引物、冈崎片段比原核生物短（2000、2011）
- **端粒**（2011）
  - ①端粒 DNA：真核染色体线性 DNA 的 3'末端
  - ②富含 GT（G 四联体）“舔狗”
  - ③端粒酶：RNA、逆转录酶、协同蛋白（2000、2016、2017、2021、2026）
  - ④维持染色体稳定性、保证 DNA 复制完整性
- **逆转录病毒**（2001、2009、2012）
  - ①5'→3'方向
  - ②RNA→RNA/DNA→单链 DNA→双链 DNA
  - ③逆转录酶：RDDP、DDDP、RNase H（没有 3-5 核酸外切酶活性）
  - ④引物：病毒 tRNA（1998）

## 教材校注（人卫第10版摘要）

- DNA复制以亲代DNA为模板，具有半保留、双向和半不连续等特征；DNA聚合酶按5′→3′方向延伸，并依赖引物提供3′-OH。原核与真核复制相关聚合酶、起始机制及引物处理存在差异。
- 端粒/端粒酶维护线性染色体末端复制；逆转录过程以RNA为模板合成DNA。教材定位：第十四章，纸书第255–271页。
