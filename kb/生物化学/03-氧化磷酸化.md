# 氧化磷酸化

> 考频：★★☆☆氧化磷酸化（10~2题）｜学科：生物化学

<!-- page_247 -->


- **线粒体**
  - 胞浆 H 穿梭进入线粒体（1997、1998、2008、2016、2021、2024、2025）
    - 脑、骨骼肌：α-磷酸甘油-磷酸二羟丙酮穿梭 → FADH₂“头脑简单四肢发达”
    - 肝、心、肾：苹果酸-天冬氨酸穿梭（草酰乙酸）→ NADH“吃苹果的天天喜性感”
  - 单递电子体：细胞色素 Cyt、铁硫蛋白 Fe-S“CF”（1996、2002、2015）
- **呼吸链**
  - 琥珀酸、脂酰 CoA 等 → FAD → Fe-S → 复合体II（←抑制剂：萎锈灵）→ CoQ
  - 主链：NADH+H⁺→FMN→Fe-S→CoQ→Cytb→Fe-S→Cytc1→Cytc→Cyta→Cyta3
    - 复合体I（NADH→CoQ）：抑制剂 鱼藤酮、粉蝶霉素、异戊巴比妥
    - 复合体III（CoQ→Cytc）：抑制剂 抗霉素、黏噻唑菌醇
    - 复合体IV（Cytc→Cyta3）：抑制剂 CN⁻ 和 N₃⁻、CO
  - （2003、2006、2009、2010、2015、2016、2020）
  - 电位低向高的组分依次传递（2009）
  - 不在复合体“醌醌不是 C 位”
    - Cytc（2006）→ 水溶性：与线粒体内膜结合疏松“水溶 C100”
    - CoQ/泛醌 → 脂溶性苯：在线粒体内膜自由扩散（2006）；Q 循环存在于复合体III（2019）
  - 质子泵
    - 复合体 I、III、IV（2015、2020、2023）
    - 化学渗透假说：质子顺浓度回流耦联生成 ATP（2018）
  - P/O 比值
    - 生成 ATP 数与消耗 1/2 O₂ 的比值（2017）
    - ①NADH：2.5（1996、1997）
    - ②FADH₂：1.5（1997、1998、2008、2015）
    - ③抗坏血酸：1
  - ATP 合酶（复合体 V）→ 亲水 F1：生成 ATP；疏水 F0：离子通道
- **调节（2018、2019）**
  - 最主要：ADP
  - mtDNA 突变
  - 线粒体内膜选择性协调转运 → 影响 H、ATP-ADP 转位酶等
  - 甲状腺激素（核受体）
    - ①诱导钠泵→利用 ATP↑→ADP↑→氧化磷酸化速率↑
    - ②诱导解偶联蛋白→基础代谢率和产热↑
  - 呼吸链抑制剂 → 如 CN 阻断 a-氧化型 a3、CO 阻断还原型 a3-O₂
  - 解偶联剂 - 氧利用继续但磷酸化停止（2007、2012、2014）
    - ①二硝基苯酚：能在线粒体内膜自由移动、破坏 H 的电化学梯度
    - ②新生儿棕色脂肪组织解偶联蛋白：形成质子通道
    - ③游离脂肪酸：促进 H 经解偶联蛋白回流
  - ATP 合酶抑制剂 → 寡霉素（结合 F0 的 c 亚基“黑寡妇蜘蛛布满了通道 wo c”）、DCCD（2021、2026）

## 教材校注（人卫第10版摘要）

- 呼吸链电子传递释放的能量驱动复合体 I、III、IV 将质子泵至线粒体膜间隙；复合体 II 不泵质子。质子经 ATP 合酶回流并驱动 ATP 合成，构成氧化磷酸化的偶联基础。
- 细胞色素 c 是水溶性、可移动的电子载体；辅酶 Q 是脂溶性载体。按教材采用的 P/O 值，NADH 和 FADH₂ 分别约对应 2.5 和 1.5 个 ATP。解偶联可使电子传递与 ATP 合成脱耦，不能等同于呼吸链被抑制。
