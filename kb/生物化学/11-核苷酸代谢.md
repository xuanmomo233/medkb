# 核苷酸代谢

> 考频：核苷酸代谢（0~2题）★★★☆☆｜学科：生物化学

<!-- page_258 -->


- **嘌呤核苷酸**
  - 合成
    - 从头合成
      - 嘌呤环原子来源：N₁ ← 天冬氨酸；C₂ ← 甲酰基（一碳单位）；N₃ ← 谷氨酰胺（酰胺基）；C₄、C₅、N₇ ← 甘氨酸；C₆ ← CO₂；C₈ ← 甲酰基（一碳单位）；N₉ ← 谷氨酰胺（酰胺基）
      - "嘌呤：天冬氨酸左肩起、谷氨酰胺来打底、一碳单位在两边、头顶干净CO₂"（1998、1999、2003、2004、2005、2006、2010、2011、2013、2017、2018、2021、2023）
      - 磷酸核糖 → PRPP → PRA → IMP（2015、2021、2024）
        - → 腺苷酸代琥珀酸 → AMP
        - → XMP → GMP
      - ① PRPP合成酶；② PRPP酰胺转移酶（2020、2026）
        - 抑制剂：IMP、AMP、GMP
        - AMP抑制AMP合成、GMP抑制GMP合成
        - GTP促进AMP合成、ATP促进GMP合成
      - 脱氧嘌呤核苷酸（二磷酸水平，1998、2009）：核糖核苷酸还原酶，NADPH
    - 补救合成（2016）
      - ① PRPP＋A/I/G：APRT、HGPRT（缺失致自毁容貌综合征 "liao niao 鸟都没有了脸也不要了"）（2022）
      - ② 腺嘌呤核苷＋磷酸：腺苷激酶
  - 分解 → 尿酸：黄嘌呤氧化酶 "尿是酸的黄的"（1997、2000）

<!-- page_259 -->


- **嘧啶核苷酸**
  - 合成
    - 从头合成
      - 嘧啶环原子来源：N₃、C₂ ← 氨基甲酰磷酸；N₁、C₄、C₅、C₆ ← 天冬氨酸
      - "左二全为氨甲酰（谷氨酰胺和CO₂）、右四全为天门冬"（1998、2001、2004、2006、2011、2013、2017、2021）
      - 磷酸核糖 → PRPP（2021）
      - CPS → 氨基甲酰天冬氨酸 → 乳清酸
        - → UDP → UTP → CTP → CDP → dCDP → dCMP → dUMP → dTMP（2014）
        - PRPP＋乳清酸 → UMP "优酸乳" → UDP → dUDP → dUMP → dTMP
      - 调节示意（虚线框内反馈）：ATP＋CO₂＋Gln → 氨基甲酰磷酸 → 氨基甲酰天冬氨酸 → UMP → UTP → CTP；ATP＋R-5'-P → PRPP → 参与UMP合成；嘌呤核苷酸⊖抑制、嘧啶核苷酸⊕促进PRPP环节；UMP等终产物⊖反馈抑制前面步骤
      - 关键酶：① PRPP合成酶；② CPS-Ⅱ（所有器官胞浆均有）在哺乳动物是关键酶（2014）；③ 天冬氨酸氨基甲酰转移酶在细菌是关键酶（2020）
      - 脱氧嘧啶核苷酸
        - ① 二磷酸水平（2006）：核糖核苷酸还原酶，NADPH
        - ② dUMP → dTMP：胸苷酸合酶，N₅,N₁₀-CH₂-FH₄（1996、1999、2006、2007、2008、2021）
    - 补救合成
      - ① PRPP＋U/T/乳清酸：嘧啶磷酸核糖转移酶
      - ② 尿嘧啶／脱氧胸腺嘧啶核苷＋磷酸：尿苷／胸苷激酶
  - 分解
    - C → U → β-丙氨酸、NH₃、CO₂ "出兵"
    - T → β-氨基异丁酸、NH₃、CO₂ "T-丁"（2002、2011）

## 教材校注（人卫第10版摘要）

- 嘌呤核苷酸可经从头合成或补救合成形成，IMP是AMP与GMP合成的共同中间体；嘧啶环先合成再与磷酸核糖结合。核苷酸分解产物及关键酶因嘌呤/嘧啶途径而异。
- 核糖核苷酸还原形成脱氧核苷酸，核苷酸代谢与核酸合成及能量、氮代谢相联系。教材定位：第十一章，纸书第217–228页。
