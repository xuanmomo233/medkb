# 维生素（含辅因子小结）

> 考频：维生素（含辅因子小结）（0~2题★★☆☆）｜学科：生物化学

<!-- page_265 -->


- **维生素**
  - 抗氧化：VitA/C/E"ACEI"（2013）
  - 脂溶性：VitA/D/E/K
    - 排泄少、易蓄积
    - 结合核受体→调节基因表达（2022）
  - VitPP（色氨酸可转变为 VitPP"摸PP-色"）
    - 抑制脂肪动员→VLDL 合成↓→治疗高胆固醇血症
    - 扩张血管、胃肠不适
- **维生素缺乏**
  - VitA：暗适应时间延长、夜盲症（2013）
  - VitB₁：脚气病
  - VitB₁₂、叶酸：巨幼贫
  - VitPP：癞皮病
  - VitC：坏血病"C坏了"
  - VitD：佝偻病"dog"
  - VitE：溶血性贫血"easy"
  - VitK：易出血

含腺嘌呤的辅因子：FAD、NAD、NADP、CoA、ACP 等（1996、2011、2023、2024、2025）

| | 衍生物 | 参与 |
|---|---|---|
| VitB₁ | 焦磷酸硫胺素 TPP | α-酮酸（丙酮酸、α-酮戊二酸等）脱羧（转移醛基"拳打脚踢"） |
| VitB₂/核黄素 | FMN、FAD | 生物氧化呼吸链的递氢体"唱双簧"<br>以 FAD 作辅因子的酶：琥珀酸脱氢酶、脂酰 CoA 脱氢酶、线粒体磷酸甘油脱氢酶、胆碱脱氢酶、黄嘌呤氧化酶、丙酮酸脱氢酶复合体"虎子有胆" |
| VitB₃/VitPP/烟酸/烟酰胺"3P实验" | NAD、NADP | 以 NAD 作辅因子的酶：多数脱氢酶<br>以 NADP 作辅因子的酶：G6PD、6-磷酸葡萄糖酸脱氢酶、苹果酸酶、谷氨酸脱氢酶（NAD 和 NADP） |
| VitB₅/泛酸/遍多酸 | ①辅酶 A（H~SCoA）<br>②酰基载体蛋白（H~SACP） | 递酰基 |
| VitB₆ | 磷酸吡哆醛 | 磷酸化酶（分解糖原）、转氨酶、氨基酸脱羧酶、ALA 合酶（合成血红素）"比多兽带遛弯集体喂糖回血" |
| VitB₇ | 生物素"说话啦生气啦" | 丙酮酸羧化酶（糖异生）、乙酰 CoA 羧化酶（合成脂肪酸） |
| 叶酸 | 四氢叶酸 FH₄ | 递一碳单位：从头合成嘌呤核苷酸、dUMP → dTMP |
| VitB₁₂ | 钴胺素（含金属"12K金"） | 转甲基酶：SAM 循环（同型半胱氨酸 +N₅-CH₃-FH₄ → 甲硫氨酸） |
| VitK | | γ-谷氨酰羧化酶 |
| VitC | | 羟化酶<br>（缺乏 VitC →羟化酶障碍→前胶原分子中脯氨酸、赖氨酸的羟化障碍→胶原蛋白成熟障碍→影响伤口愈合） |
