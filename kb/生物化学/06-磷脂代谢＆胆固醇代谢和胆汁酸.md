# 磷脂代谢＆胆固醇代谢和胆汁酸

> 考频：磷脂代谢＆胆固醇代谢和胆汁酸（0~2题）★★☆☆☆｜学科：生物化学

<!-- page_251 -->

- **磷脂**
  - 含胆碱（2001、2015）
    - 磷脂酰胆碱／卵磷脂、神经鞘磷脂合成需甲基化（SAM循环）
  - 合成（1996、2000、2004、2019、2024）
    - 肝的滑面内质网（2007）
    - 葡萄糖 → 3-磷酸甘油 → 磷脂酸
      - 磷脂酸 —磷脂酶→ 1,2-甘油二酯
        - ＋CDP乙醇胺 → 脑磷脂
        - ＋CDP胆碱 → 卵磷脂
        - ＋脂酰CoA → 甘油三酯
      - 磷脂酸 —胞苷酰转移酶→ CDP-甘油二酯
        - ＋肌醇 → 磷脂酰肌醇
        - ＋丝氨酸 → 磷脂酰丝氨酸
        - ＋磷脂酰甘油 → 心磷脂
  - 分解
    - ① 磷脂酶A1 → 溶血磷脂2
    - ② 磷脂酶A2 → 溶血磷脂1
    - ③ 磷脂酶C → 1,2-甘油二酯（1997）
    - ④ 磷脂酶D → 磷脂酸
    - 能产生溶血磷脂的酶：磷脂酶A1、磷脂酶A2、LCAT（2000）
- **胆固醇**
  - 酯化
    - ① 肝合成LCAT → 胆固醇在血浆酯化 "liver"（2001）
    - ② ACAT → 胆固醇在细胞酯化 "at the 细胞"（1996）
  - 合成
    - 部位：肝和小肠的滑面内质网、胞浆（2007）
    - 原料
      - ① 乙酰CoA：来自葡萄糖、脂肪酸、氨基酸，需经柠檬酸-丙酮酸循环从线粒体到胞浆
      - ② NADPH：来自柠檬酸-丙酮酸循环、磷酸戊糖途径（主要）
      - ③ ATP等
    - 步骤（2007、2010、2014、2016、2024）
      - 乙酰CoA —乙酰乙酰CoA硫解酶→ 乙酰乙酰CoA
      - 乙酰乙酰CoA —HMG CoA合酶→ HMG CoA
      - HMG CoA —【HMG CoA还原酶】→ 甲羟戊酸 → 鲨烯 → 胆固醇
    - 【HMG CoA还原酶】（2005、2010、2013、2015、2023）
      - 活性：午夜高、中午低
      - 激活剂：胰岛素（去磷酸化）、甲状腺激素
      - 抑制剂：胰高血糖素、糖皮质激素、胆固醇等、胆汁酸、他汀类药
  - 分解（2006、2026）
    - VitD₃（皮肤）
    - 类固醇激素：1,25-(OH)₂VitD₃、醛固酮、糖皮质激素、性激素（雄／雌／孕）（1998、2012）
    - 胆汁酸（主要，1999、2015）
      - 胆汁酸↑：【胆固醇7α-羟化酶】↓、【HMG CoA还原酶】↓（2016）
      - 甲状腺激素：【胆固醇7α-羟化酶】↑↑、【HMG CoA还原酶】↑ → 血胆固醇↓（2017）
    - 胆汁酸 "鹅卵石、牛肝菌"（1996、2008、2014、2020）
      - 初级：肝内质网 → 胆酸、鹅脱氧胆酸
      - 次级：肠道 → 脱氧胆酸、石胆酸 "脱裤滋屎（肠）"
      - 游离型
      - 结合型：与甘氨酸或牛磺酸结合

- 口诀和年份属于学习提示，不等同教材结论。
