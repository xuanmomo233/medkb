# 氨基酸代谢

> 考频：氨基酸代谢（0~2题）★★☆☆☆｜学科：生物化学

<!-- page_255 -->


- **转氨基**
  - 调节非必需氨基酸浓度
  - 转氨酶：辅因子-磷酸吡哆醛／VitB₆
  - Glu代谢最活跃
    - ① 天冬氨酸氨基转移酶AST：心肌损伤、肝损伤等↑
    - ② 丙氨酸氨基转移酶ALT：肝损伤等↑ "奥利奥饼干"
- **脱氨基**
  - 部位
    - 肝、肾、脑 "干甚L"
      - 联合脱氨基 ＝ 转氨基＋L-谷氨酸脱氢
      - 【L-谷氨酸脱氢酶】：唯一既能用NAD（VitPP）、又能用NADP（VitPP）作辅因子（2016）
    - 肌肉 "肌肉漂亮"
      - 联合脱氨基 ＝ 转氨基＋嘌呤核苷酸循环（2007、2014）
      - 【腺苷酸代琥珀酸合成酶】"吃天天闲得很"（2015）
      - 【腺苷脱氨酶ADA】：缺乏 → 联合免疫缺陷综合征
  - 产物
    - α-酮酸（1999、2002、2004、2006、2013）
      - ① → CO₂、H₂O、ATP
      - ② → 非必需氨基酸
      - ③ → 糖（除开Leu、Lys）
      - ④ → 脂
    - NH₃
      - 运输（1997、2000、2004、2007、2008、2012、2016、2018、2020、2021）
        - ① 脑或肌肉：谷氨酰胺（NH₃的储存、解毒、运输、肾小管分泌，2013）
        - ② 肌肉：丙氨酸-葡萄糖循环 "丙肝的"
      - 去路
        - 尿素 "天天精得很"（1998、2003、2010、2011、2014、2015、2016、2017、2019、2021、2023）
          - 仅肝（鸟氨酸循环）
          - 提供尿素的氨基：NH₃、天冬氨酸
          - 消耗：2个NH₃、4个高能磷酸键
          - 线粒体：NH₃＋CO₂＋ATP → 氨基甲酰磷酸，需【CPS-I】；CPS＋鸟氨酸 → 瓜氨酸，需OCT
          - 胞浆：瓜氨酸＋天冬氨酸 → 精氨酸代琥珀酸，需【精氨酸代琥珀酸合成酶】；精氨酸代琥珀酸 → 精氨酸＋延胡索酸；精氨酸 → 尿素＋鸟氨酸
          - Arg → 激活AGA合成酶 → AGA↑ → 激活【CPS-I】→ 启动尿素循环
          - 肝功能严重损伤或OCT遗传缺陷 → 尿素循环障碍 → 高血氨症
        - NH₄⁺、酰胺、非必需氨基酸（2009）
- **脱羧基**
  - 【氨基酸脱羧酶】：辅因子-磷酸吡哆醛／VitB₆
  - ① 谷氨酸 → γ-氨基丁酸GABA：属于抑制性神经递质 "尼古丁"（2001、2007）
  - ② 半胱氨酸 → 牛磺酸：参与构成结合型胆汁酸 "半-牛"
  - ③ 鸟氨酸 → 多胺（腐胺、亚精胺、精胺）：可辅助诊断肿瘤 "精卫填海、抚慰金"
  - ④ 组氨酸 → 组胺
  - ⑤ 色氨酸 → 5-HT
  - ⑥ 丝氨酸 → 乙醇胺 "死酒鬼"

## 教材校注（人卫第10版摘要）

- 氨基酸分解代谢以脱氨基为起点，转氨基反应常以磷酸吡哆醛为辅酶；氨可由谷氨酰胺、丙氨酸等形式转运，肝通过尿素合成清除氨。不同氨基酸碳骨架可进入糖、脂质或能量代谢。
- 个别氨基酸代谢包括脱羧产生生物活性胺、含硫氨基酸代谢及芳香族氨基酸分解。教材定位：第九章第二至四节，纸书第176–193页。
- 口诀和历年年份保留为学习层，不作为教材结论。
