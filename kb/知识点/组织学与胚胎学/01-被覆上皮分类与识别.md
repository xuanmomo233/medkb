# 组织学与胚胎学 · 被覆上皮分类与识别

## 上皮组织共同特征

- 上皮由排列紧密、形态规则的细胞和少量细胞外基质构成，具有明显极性：朝向体表或腔面的为游离面，朝向深部结缔组织的为基底面，细胞间相邻面为侧面。
- 上皮基底面附着于基膜并与结缔组织相连；上皮内大多无血管，营养由结缔组织血管提供并透过基膜进入上皮。
- 按功能分为被覆上皮和腺上皮；少量特化上皮还包括感觉上皮和肌上皮。被覆上皮按细胞层数和表层细胞形状分类。

## 被覆上皮分类速查

| 类型 | 识别要点与常见分布 |
| --- | --- |
| 单层扁平上皮 | 一层扁平细胞；心血管和淋巴管腔面称内皮，胸膜、心包膜和腹膜表面称间皮；肺泡及肾小囊壁层亦见。 |
| 单层立方上皮 | 一层近立方形细胞；常见于肾小管、甲状腺滤泡。 |
| 单层柱状上皮 | 一层柱状细胞；常见于胃、肠、胆囊和子宫腔面，具有吸收或分泌功能；肠上皮可散在杯状细胞。 |
| 假复层纤毛柱状上皮 | 细胞高矮不一、核不在同一水平，看似多层；各类细胞基底部均附着于基膜，实为单层，常见于呼吸道腔面。 |
| 复层扁平上皮 | 多层细胞，表层扁平；皮肤表皮为角化型，口腔大部、食管和阴道等为未角化型，耐摩擦且有较强再生修复能力。 |
| 复层柱状上皮 | 深部为一层或几层多边形细胞，浅部为较整齐的矮柱状细胞；见于结膜、男性尿道及部分腺大导管。 |
| 变移上皮 | 排尿管道上皮；膀胱空虚时较厚、层数较多、表层盖细胞较大且呈立方形，充盈扩张时变薄、层数减少、盖细胞变扁平。 |

## 常见易混点

- 假复层上皮“貌似复层”，判定要点是所有细胞基底部均附着于基膜，故归为单层上皮。
- “内皮”和“间皮”均属于单层扁平上皮，区别在于所在部位：前者衬于心血管/淋巴管腔面，后者覆盖浆膜表面。
- 复层扁平上皮的角化与否看表层：皮肤表皮角化；食管等腔面未角化。不能把部位与角化形式对调。
- 变移上皮形状和层数随排尿管道器官充盈状态变化，不是不同器官各自固定不变的“层数”。
