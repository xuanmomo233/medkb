# 外科学 · 外科感染 考点精要

> 由题库解析+导图笔记蒸馏聚合（175 条），来源标注 [Q题号]

## 核心考点

- **脓液鉴别**：金葡菌=稠厚黄无臭；溶血链球菌=稀薄淡红量多；大肠杆菌=稠厚无臭（+厌氧菌则粪臭）；铜绿=淡绿甜腥味；拟杆菌=恶臭普通培养阴性 `[Q170002, Q170046-49]`
- **金葡菌**：毒力与血浆凝固酶相关；多重耐药、倾向血行播散形成转移性脓肿；青霉素耐药率>90%→疑MRSA首选万古霉素 `[Q169998, Q170046, Q170030]`
- **疖vs痈**：疖=单个毛囊（中央脓栓）；痈=相邻多毛囊（多脓点）；糖尿病易生痈 `[Q170008-10]`
- **危险三角区**：鼻、上唇疖严禁挤压→经内眦静脉眼静脉入颅→海绵状静脉窦炎（寒战高热头痛昏迷） `[Q170009, Q170014]`
- **丹毒**：网状淋巴管炎，乙型溶血链球菌；下肢好发（足癣诱因），片状红斑鲜红中间稍淡界限清，很少化脓 `[Q170012-18]`
- **急性蜂窝织炎**：皮下疏松组织化脓感染，主要溶血链球菌，边界不清 `[Q170016]`
- **甲沟炎/指头炎**：金葡菌；指头炎末节跳痛需切开；示指腱鞘炎蔓延至鱼际间隙；掌深间隙感染手背肿但切口在掌面 `[Q170023-26, Q170031]`
- **脓毒症**：寒战高热或低温+脉细速；寒战发热时抽血培养阳性率最高；治疗关键处理原发灶 `[Q170035, Q170036, Q170041]`
- **G⁺ vs G⁻脓毒症**：G⁺寒战少见、稽留/弛张热、转移性脓肿多；G⁻内毒素→寒战间歇热、肢冷少尿、休克早而久，可"三低"（低体温、低白细胞、低血压） `[Q170034, Q170037, Q170039]`（正确率43%）
- **破伤风=毒血症**：梭菌只在伤口局部繁殖不入血，痉挛毒素经血播散，血培养阴性 `[Q170052, Q170053, Q170066]`
- **破伤风表现**：最初咀嚼肌（牙关紧闭苦笑面容）→面→颈→背→腹→四肢→膈肌；角弓反张；恐水非特异 `[Q170055, Q170056]`
- **破伤风死因**：膈肌持续痉挛窒息；控制痉挛保呼吸道通畅为治疗关键 `[Q170057, Q170063, Q170067]`
- **痉挛诱因**：光、声、接触、饮水；温度改变少见 `[Q170054]`（易错点）
- **破伤风防治**：TAT中和游离毒素须皮试（阳性脱敏注射）；人免疫球蛋白可直接肌注但价昂；儿童用百白破疫苗（类毒素）；避声光刺激 `[Q170058-61]`
- **气性坏疽**：梭状芽胞杆菌（产气荚膜梭菌70~80%）厌氧感染；潜伏期1~4天；胀裂样剧痛+浆液血性渗液+皮下捻发音+恶臭+大理石样花纹 `[Q170068-70, Q170077]`
- **气性坏疽防治**：最关键彻底清创；首选大剂量青霉素（每日≥1000万U）+高压氧；氨基糖苷类无效 `[Q170071, Q170073, Q170075, Q170076]`（正确率44%）
- **痈**：颈背部好发、多相邻毛囊多脓点、金葡菌、糖尿病易患 `[Q201262~201264]`；**丹毒**：乙型溶血性链球菌感染皮肤淋巴管网（非化脓性），下肢/面部边界清楚片状红疹，不切开引流，反复发作→象皮肿 `[Q115070]`；**蜂窝织炎**：皮下疏松结缔组织弥漫炎症、边界不清、脓液无恶臭 `[Q201141]`
- **气性坏疽**：梭状芽孢杆菌；伤口包扎过紧+剧烈疼痛+血性渗液+恶臭；预防关键早期彻底清创 `[Q201141]`
- **脓性指头炎**：末节指侧纵切口，远端不超甲沟1/2 `[Q201130]`；**破伤风**：最严重并发症=膈肌痉挛窒息；抗生素首选大剂量青霉素/甲硝唑 `[Q201252][Q73115]`
- **最易受损器官**：闭合性损伤依次脾、肾、小肠、肝、肠系膜；开放性依次肝、小肠、胃、结肠、大血管 `[Q222067]`
- **特异性感染**=破伤风、结核、真菌（念珠菌）、气性坏疽（"凤姐真坏"）`[Q103847]`
- **致病菌速记**：疖、痈、手部化脓性感染、急性乳腺炎=金葡菌；丹毒、蜂窝织炎=乙型溶血性链球菌 `[Q103883]`~`[Q103885]`
- **丹毒**：皮肤淋巴管网炎，边界清楚的片状红疹，下肢/面部好发；不切开引流；反复发作致象皮肿 `[Q103849]`
- **痈**：金葡菌、多相邻脓点、项背部多见；十字切口超边缘深达筋膜；唇痈（危险三角）严禁挤压切开→海绵状静脉窦炎 `[Q103851]` `[Q103864]`
- **脓性指头炎**：针刺样痛→跳痛→痛减（坏死）；末节指侧面纵切，不等波动感即切开防指骨缺血坏死/骨髓炎 `[Q103866]` `[Q103886]`
- **革兰阴性杆菌败血症**：可有寒战+稽留/弛张热；革兰阳性菌败血症一般无寒战 `[Q103854]` `[Q103855]`
- **破伤风**：破伤风梭菌（厌氧G+杆菌，芽孢态分布土壤）；痉挛毒素→毒血症；最先=咀嚼肌紧张→张口困难牙关紧闭→苦笑面容→角弓反张→膈肌痉挛；轻刺激诱发痉挛；死因多为窒息/心衰/肺部并发症；预防关键=早期彻底清创；TAT=中和游离毒素（仅早期有效）；治疗=麻醉控制痉挛下清创+中和毒素+控痉挛+保持呼吸道通畅（重者尽早气管切开）+大剂量青霉素/甲硝唑（氨基糖苷类无效）`[Q103856]` `[Q103857]` `[Q103858]` `[Q103859]` `[Q103869]` `[Q103892]` `[Q105848]`
- **气性坏疽**：产气荚膜梭菌等混合→外毒素致组织坏死恶性水肿；伤口肿胀剧痛+淡红渗液+皮下积气捻发感+恶臭+溶血性黄疸血红蛋白尿；立即急症彻底清创敞开+氧化剂冲洗+大剂量青霉素+高压氧，必要时截肢 `[Q103860]` `[Q105849]` `[Q234093]`（重复x1）
- **口底急性蜂窝织炎**最严重并发症=窒息 `[Q103852]`
- **疖/痈**：金葡菌；痈=相邻多毛囊、颈背部、糖尿病易发；**危险三角唇痈挤压→海绵状静脉窦炎**；表浅局限疖不用抗生素 `[Q73044-49]`
- **急性蜂窝织炎**：主因**溶血性链球菌**（透明质酸酶→不局限）；**口底颌下可窒息→及早切开减压** `[Q73053]`
- **丹毒**=网状淋巴管炎：乙型溶血性链球菌经足癣等侵入；下肢面部多见；**边界清楚片状红疹（周鲜红中淡红）**；很少化脓→**禁忌清创手术**；硫酸镁湿敷+青霉素，症状消失后续用3~5天 `[Q73075-77]`
- **脓性指头炎**：末节掌面脓腔高压→**指骨缺血坏死、骨髓炎**；侧方纵切口 `[Q226401]`；掌深间隙鉴别=**掌中凹是否存在**（掌中间隙感染消失、鱼际间隙存在）；切开须在掌面 `[Q73058-61]`
- **脓毒症**：G⁻杆菌已超G⁺（大肠杆菌最多见）；**金葡菌最易转移性脓肿**；G⁻菌"三低"（低温低白细胞低血压）；真菌败血症=寒战高热+淡漠嗜睡+休克、血培养难阳 `[Q73094-95]`
- **破伤风**：G⁺厌氧芽孢梭菌；**痉挛毒素**→肌紧张收缩基础上阵发痉挛；首发**咬肌（张口困难）**→苦笑→角弓反张→膈肌（**窒息最危险**）；诊断靠外伤史+典型表现；**预防关键=早期彻底清创**；TAT只中和游离毒素、皮试阳性→脱敏注射；免疫球蛋白无需皮试 `[Q189405, Q73064-67]`
- **气性坏疽**：厌氧梭状芽胞杆菌；潜伏期1~4天；**胀裂样剧痛+捻发音+恶臭血性渗出+皮肤发黑**、溶血性黄疸血红蛋白尿；**关键=急诊彻底清创**（多切口、切除受累肌肉、必要时截肢）而非抗生素；首选青霉素 `[Q73068-69, Q73088-90]`
- **抗菌原则**：不能替代引流等外科处理；停药指征=体温+白细胞正常+病情好转+病灶控制（不仅凭体温）`[Q226411]`；MRSA首选万古霉素 `[Q73084]`；特异性感染=破伤风、结核、真菌、气性坏疽 `[Q113400]`；需早期切开的厌氧感染=气性坏疽破伤风；不切开=丹毒、寒性脓肿 `[Q226414-415]`
- **脓性指头炎**→侧方纵行切口 `[Q128772]`；**气性坏疽**预防关键=尽早彻底清创（扩创+3%过氧化氢冲洗引流）`[Q128773, Q180305]`；**丹毒**=网状淋巴管炎、边界清、不化脓→不切开 `[Q3625, Q3626]`
- **疖/痈**：疖=单个毛囊；痈=相邻多个毛囊（金葡菌、项背部、糖尿病易发）；危险三角区（鼻、上唇）疖严禁挤压→经内眦静脉、眼静脉入海绵状静脉窦→寒战高热头痛呕吐昏迷 `[Q170006~170010, Q170014]`；痈切口=十字切口、超边缘、达筋膜、不一期缝合，唇痈不切开 `[Q170015, Q170011]`
- **丹毒**：网状淋巴管炎，乙型溶血性链球菌，足癣诱因，下肢片状红斑边缘清楚中间稍淡微隆起，不化脓不切开引流，反复发作→象皮肿 `[Q170012, Q170017, Q170018, Q76120, Q76121]`
- **蜂窝织炎**：皮下疏松结缔组织弥漫性化脓性炎症，边界不清，主要致病菌=溶血性链球菌；口底颌下蜂窝织炎可喉头水肿窒息→及早切开减压 `[Q170016, Q170008, Q76115]`；8版"蜂窝织炎非化脓性"表述错误 `[Q170013]`
- **手部感染**：甲沟炎=金葡菌，甲沟旁纵行切口，首选青霉素 `[Q170025, Q170027, Q170028]`；脓性指头炎=末节指腹、针刺样痛→剧烈跳痛→疼痛减轻提示缺血坏死，末节侧面纵行切口（近端不过指横纹、远端不过甲沟1/2），不治→末节指骨骨髓炎（最常见并发症，非败血症）`[Q170024, Q170031, Q170033, Q76114]`；化脓性腱鞘炎蔓延：示指→鱼际间隙，中指/环指→掌中间隙，拇指→桡侧滑囊，小指→尺侧滑囊 `[Q170023, 导图35]`；掌深间隙感染肿胀在手背但切口在掌面，首选青霉素 `[Q170026]`
- **脓液鉴别**：金葡菌=稠厚黄色无臭+局限性坏死+转移性脓肿（常考）；溶血性链球菌=稀薄淡红量多；大肠埃希菌=稠厚无臭（合并厌氧菌则恶臭粪臭）；铜绿假单胞菌=淡绿色甜腥味；拟杆菌等无芽胞厌氧菌=恶臭+普通培养阴性 `[Q170002, Q170020~170022, Q170046~170048]`
- **脓毒症**：骤起寒战高热或低温+心率快脉细+呼吸困难；抽血培养最佳时机=寒战发热时；G⁺脓毒症=稽留/弛张热、寒战少见、转移性脓肿多、休克晚；G⁻脓毒症=间歇热、三低（低温低白细胞低血压）、休克早而持久 `[Q170034~170042]`；治疗关键=处理原发感染灶；金葡菌血培养阳性且青霉素无效→疑MRSA首选万古霉素 `[Q170030]`；大面积烧伤创面最常见细菌=铜绿假单胞菌54% `[Q170049]`；真菌败血症 `[Q76119]`
- **破伤风**：破伤风梭菌（G⁺专性厌氧芽胞梭菌）伤口局部繁殖不入血=毒血症（痉挛毒素+溶血毒素），血培养阴性 `[Q170052, Q170053, Q170064, Q170066]`；潜伏期约7天；痉挛诱因=声、光、接触、饮水（温度改变少见）；最先受累=咀嚼肌（张口困难牙关紧闭）→面肌（苦笑）→颈背腹四肢→膈肌；最危险=膈肌痉挛窒息（主要死因）；并发症=心衰、肺感染（不能咳嗽）、肌断裂骨折尿潴留 `[Q170054~170057, Q170051, Q170067, Q171077]`；预防关键=彻底清创（非注射TAT）；TAT中和游离毒素、需皮试、阳性脱敏注射；破伤风免疫球蛋白（TIG）无需皮试、价贵、推荐应用；治疗关键=控制解除痉挛防窒息+保持呼吸道通畅+避声光刺激+严格隔离无菌操作 `[Q170058~170063, Q76116~76118]`
- **气性坏疽**：梭状芽胞杆菌（产气荚膜梭菌占70%~80%），潜伏期1~4天；伤后胀裂样剧痛+皮肤发黑大理石纹+恶臭+浆液血性渗液+肌肉熟肉状+皮下积气捻发音+溶血性黄疸；病因=伤口狭深清创不彻底（非包扎过紧）；预防=尽早彻底清创；治疗=急症清创+大剂量青霉素（>1000万U/d）+高压氧；氨基糖苷类无效 `[Q170068~170078]`
- **需早期切开引流**：破伤风、气性坏疽、颌下口底蜂窝织炎、脓性指头炎、腱鞘炎、滑囊炎、掌深间隙感染；**不可切开**：丹毒（不化脓）、寒性脓肿（结核，切口经久不愈）`[Q76115]`
- **预防用抗生素**：一般无菌手术不需预防性使用 `[Q170079]`；术前化疗后发热（乳癌根治术后）考虑感染 `[Q170001]`
- **骨关节炎**：关节软骨退变+继发骨质增生；原发性>50岁肥胖者膝负重关节；继发性=先天关节结构异常（发育性髋脱位）、关节面不平整、关节不稳；Heberden/Bouchard结节远端/近端配对为题库线索（未直接支持DIP/PIP定位）；X线=非对称关节间隙变窄+软骨下骨硬化囊变+骨赘 `[Q224360~224362]`
- **特异性感染病原体**：结核分枝杆菌、破伤风梭菌、念珠菌等 `[Q222371]`
- **痈**：相邻多个毛囊化脓感染，颈后项背好发、糖尿病者易发疖病痈；危险三角区唇痈→海绵状静脉窦炎（危险并发症）`[Q222372-78]`
- **丹毒**：乙型溶血性链球菌感染皮肤淋巴管网——下肢片状鲜红微隆起红斑、边界清楚、中间稍淡；不化脓、不需切开；反复发作→淋巴管阻塞→象皮肿 `[Q222379-82, Q222408-10, Q74420]`；急性管状淋巴管炎=向近心端延伸红线（红丝疔）`[Q222383]`；颌下蜂窝织炎可致喉头水肿窒息 `[Q222384]`
- **手部感染**：手掌感染手背肿胀更明显（淋巴经手背回流）；脓性指头炎金葡菌、末节侧面纵行切口；掌深间隙感染切口在掌面不超远侧掌横纹；甲沟炎首选青霉素（庆大霉素对G⁺菌无效）`[Q222387-93, Q222413-17, Q190574]`
