# 人卫第十版教材核验进度

本目录记录教材原文核验批次。生产数据库中的 `content_citations` 是应用和 AI 展示出处的唯一运行时数据源；这里仅保存可审计的进度说明。

## 核验原则

- 逐页查看本地正版教材原文，不能用题库解析、思维导图或培训资料代替。
- 同一批次同时核对正文与出处；内容没有完整核对前不得标记“已核验”。
- 记录纸书页码，并在说明中保留 PDF 页序，避免扫描版前置页造成页码偏移。
- 口诀、联想和历年考查年份属于学习层，不因教材核验而删除；与教材核心结论分层展示，并明确其用途。
- 概念混淆逐条判断：只修正与教材明确冲突、不准确或容易误解的具体表述，并说明概念边界，不做整章式“去噪”。
- 已有导图章节默认采用“导图速记在前、教材校注在后”的结构；原考点通过“需辨析”关联到具体校注，不以整段教材摘要覆盖原导图。
- 教材原文只用于核对和简要概括，不复制、发布大段原文。
- 已发布的教材页图仅能通过登录态接口 `/api/textbook-images/{source_key}/{book_page}.webp` 读取；不得放入公开 `/img` 目录，也不得在导图页图中混用。
- 章节页面中的导图原图和教材原图使用同一套图片画廊交互；二者只在资源来源与登录校验上区分，不为教材另设阅读入口。
- 页图按引用的纸书页码命名。生成时必须记录 PDF 页序偏移、核验抽样图像与引用范围一致；未核验或未生成的页不应补标为可查看。
