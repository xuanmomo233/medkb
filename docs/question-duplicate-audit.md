# 题库重复题核查记录

核查日期：2026-10-17。数据源为线上 PostgreSQL 生产题库；全站原有 69,405 道题，处理 1 条确认的同源重复后现为 69,404 道。

## 判定方法

将题型、材料题主干、题干、选项（保留选项顺序）和答案做 Unicode NFKC 归一化并忽略空白，五项完全相同才算“严格重复候选”。解析不纳入主键，但单独比较；不同题库、来源文件、学科归属和用户学习数据均保留为复核上下文。只按题干相同不认定重复，因为题库中有大量“下列正确的是”“应选用的药物是”等通用问法及共用材料题。

## 生产库扫描结果

- 严格重复候选：11,160 组，额外记录 11,563 条。
- 其中 10,512 组跨不同 `bank_group`，是同一道题被不同真题集、年份版或练习集分别收录。它们有独立题库归属，且 4,746 组解析不同；不能直接删除或合并。
- 648 组处于同一个 `bank_group`：598 组同一题库名、50 组同一题库组但不同题库名。绝大多数跨来源文件，通常是综合/分科索引或重复练习内容，暂不自动合并。
- 仍有3组严格重复位于同一来源文件，均来自 26XL 每日一练不同月份文件中的重复练习题（结肠癌、尿毒症纠酸后搐搦、Bryant 三角）。题目元信息和配图不同，可能是间隔复习安排；保留，不把重复练习误删为导入垃圾。
- 仅按题型、材料主干和题干扫描得到 12,451 组同题干记录；其中 1,291 组的选项或答案不同，不能仅据题干相同合并。
- 另发现25组题干和选项相同、答案不同的跨来源记录。这属于答案冲突候选而非严格重复；未自动改答案，需按题源或教材另行核对。

## 处置边界

本次只清理有同源证据且没有用户数据关联的一个确定冗余。跨题库收录、重复练习、解析不同或答案冲突的记录没有批量删除；它们的来源和练习语境有独立价值。答案冲突候选仍应作为后续内容校勘清单，不能把“题目重复”推断成“答案也相同”。
