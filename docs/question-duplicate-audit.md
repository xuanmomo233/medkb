### 严格重复：已建立身份映射，未删除题目

规范题优先考虑题目级出处、人工编辑记录、背卡关联、真题标志、解析完整度、作答量和较稳定的题目 ID。映射理由记录归一化字段一致及保留源记录，不把“身份合并”表述为删除题目。

在严格字段扫描外，另人工核实了8组同一考试题号的跨题库副本，新增14条身份映射：2021N6A、2022N6A、2022N116B、2022N117B、2023N116B、2023N117B、2019N118B、2016N153X。复核按考试代码及正确选项文本核对；确有选项顺序、年份标注格式或近义措辞差异时写明理由。新映射均保留原题、来源、背卡关联和历史记录；相关解析页同考点关系通过别名仍可访问。

### 同题干变式：已登记保守推荐关系

相同题型、材料主干和题干，选项虽有变化但正确选项文本一致，才登记为 `variant`。当前 1,156 组候选满足此条件，登记 1,216 条规范题之间的推荐关系。关系只用于解析下方的同质题推荐，不合并题目身份，也不替代用户作答进度。

## 复核与发布规则

1. 每批分类前重新从生产库扫描，并记录签名字段、归一化方式、命中与排除规则及扫描时间；不能沿用过期候选数量。
2. 严格重复只建立规范题映射，除非另有明确同源垃圾导入证据且确认没有任何学习数据关联，否则不删除原题。
3. `variant`、`same_concept`、`contrast` 必须有可读的关系理由；冲突项不进入推荐关系，直到完成来源校勘。
4. 题目级教材出处必须对应题干/答案所考查的具体断言和页码。章节级引用不自动下放成逐题引用；原题源和教材证据应分别保留。
5. 每次写生产库后核对原题数、来源记录、尝试数、映射/关系数及 API 对用户的返回；不要用仅仅“写入成功”替代功能核验。
